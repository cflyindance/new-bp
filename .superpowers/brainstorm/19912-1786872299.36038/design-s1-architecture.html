设计 §1 · 架构边界

独立 Product Catalog 域作为本地商品唯一真源

数据流
Demo 悬浮球
  └─ Menu 商品菜单  →  Catalog Shell（CRUD UI）
                         │
                         ▼
              Product Catalog（本地 SSOT）
              · products[]
              · groups[] / categories[]
              · placements[]（组+类 → productId）
                         │
          ┌──────────────┼──────────────┐
          ▼              ▼              ▼
   eMenu 调味选择器   前厅组类菜勾选   Kiosk 等本地业务
   （适配层只读）     （适配层只读）    （后续接入）

边界约定

  • 写：只允许 Catalog UI / Catalog API
  • 读：下游通过适配层取「选择器视图」或「eMenu menus 形状」
  • 不依赖：POS 主机真实菜单接口
  • 持久化：本地 seed + handler（对齐现有 emenu-local 模式）
