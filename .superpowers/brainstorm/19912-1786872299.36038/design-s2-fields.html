设计 §2 · 实体与字段

四类实体：Group / Category / Product / Placement；Product 承载近真 eMenu 字段

关系
CatalogMenuGroup (1) ──< CatalogMenuCategory
CatalogMenuCategory (1) + Product (1) ──< CatalogPlacement
Product (1) ──< optionGroups / comboSections（嵌在 Product 内，一期）

Group / Category / Placement（结构层）

Group:     id, name, sortOrder, status, hidden?, restaurantHourIds?, createdAt, updatedAt
Category:  id, groupId, name, sortOrder, status, hidden?, thumbPath?, taxIds?, createdAt, updatedAt
Placement: id, groupId, categoryId, productId, sortOrder, status
           · 唯一约束 (groupId, categoryId, productId)
           · 复合展示 key: d:{groupId}:{categoryId}:{productId}

Product（主数据 · 近真，对齐 transformItem）

身份:     id, code(itemNumber), name, nameI18n?, description, chineseDescription?
展示:     thumbPath, properties[]（标签/辣度/新品/推荐）
价格:     price, addPrice?, itemPrices[], defaultItemSizeId?, strikethroughPrice?, benefitPrice?, marketPriceItem?
售卖:     status, hiddenItem, outOfStock?, emenuSellable, kioskSellable?, addLimit?, preSelected?
税务:     taxIds?, qtyQualifyingForZeroRated?
口味:     optionGroups[] → { id, name, min, max, freeQuantity, subOptions[] }
套餐:     comboSections[] → { id, name, min/max, allowRepeatedItems, items[{saleItemId, ...}] }
元数据:   primaryCategoryId（主分类，可与某菜单类同 id）, sortOrder, createdAt, updatedAt

  • 调味 ADD/LESS 关系仍在 seasoning 域，通过 productId 关联 Catalog
