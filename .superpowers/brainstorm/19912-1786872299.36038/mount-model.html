同一道菜能否挂到多个组/类？

字段选了「接近 eMenu 真菜」。结构上还要定：菜对象是嵌在类里复制，还是全局 Product 再被多处引用。

A

全局 Product + 多挂载（推荐）

菜只存一份主数据；组/类里用 productId 引用。适合「招牌推荐」与正菜单同时出现，改价改名一处生效。

B

严格树嵌套、不复用

group → category → dish 对象直接嵌套。结构简单，但同一道菜出现两次会复制字段，易漂移。

C

主挂载 + 可选镜像位

每道菜有一个主类；其它位置只存「展示挂载」引用。兼顾主分类与多入口展示。

A / C 更贴主数据中心

  • 与现有调味 seed 的 productIds 一致
  • 后续选择器用复合 key 很自然

B 的代价

  • 字段厚时复制成本高
  • 不利于「一处改、处处用」
