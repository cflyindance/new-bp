Detail 里：调味 + 大小份，怎么一次走完？

目标：选完调味确认后，不要关掉再点加号才弹规格。点选你更顺畅的方案。

A · 同页两段
① 调味 Option
② 大小份 / 规格

A. 同一弹层分段

一个 Detail：上面调味、下面规格，底部一次加购。样式像现有详情，但调味区独立。

B · 两步向导
步骤1 调味
步骤2 规格
当前步内容

B. 两步向导

先选调味 →「下一步」→ 再选大小份 → 加购。弹层不关，步骤切换。

C · 智能接力
Detail：只选调味
有规格时自动进入
现有详情：选大小份 + 加购

C. 确认后自动接力

Detail 只负责调味；点确认若还有规格，不关流程，直接接上现有详情页继续选并加购。

推荐倾向

  • A：一次看清全部必选，步骤最少
  • 若规格区很长，可再考虑 B

需避免

  • 关 Detail → 再点加号 → 再弹规格（你提到的断点）
