设计 §4 · 边界与验收

本需求做什么 / 不做什么，以及怎么算做完。

范围内
  • 有关联显示 Detail
  • 共用 DishDialog + entrySource
  • Detail 在 Option 下追加调味区
  • 加号入口不展示调味
  • 无规格也可从 Detail 加购
  • 购物车行携带调味选择快照
范围外（本阶段不做）
  • 再造第二套详情页 UI
  • 从加号入口选调味
  • 改调味后台配置模型
  • 强制必选调味
  • 与配置 27/608「展示菜详情」混用为同一开关

验收要点

  1. 有关联菜显示 Detail；无关联不显示
  2. Detail 打开详情可见调味在 Option 下方；加购行含调味
  3. 加号打开详情（或有规格时）不可见调味；加购行无调味
  4. 同 Option 动作互斥仍生效
  5. 仅有调味、无规格时，Detail → 确认可加购
