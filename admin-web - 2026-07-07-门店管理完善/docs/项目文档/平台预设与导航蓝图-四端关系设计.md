> 版本：v1.1 · 2026-07-03

## 一、核心结论

**导航蓝图决定「能配什么」（树结构），平台预设决定「配不配、展不展」（勾选状态）；M 平台是源头，商家后台三视角共用同一套商家级预设数据，运行时再叠加 RBAC + 数据视角过滤。**

---

## 二、涉及的四端

| 端 | 说明 |
|----|------|
| **M 平台** | 企业级控制台：菜单路由配置（导航蓝图）+ 平台预设（企业级配置预设） |
| **商家后台 · 集团视角** | 连锁版布局 + 集团总部数据视角 |
| **商家后台 · 品牌多门店视角** | 连锁版布局 + 品牌数据视角 |
| **商家后台 · 门店版视角** | 门店版布局 + 单店数据 scope |

## 三、四层概念模型

```
L0 · 导航定义层
  NAV_MODULES + module-settings-catalog（系统默认目录）
  M 平台 · 菜单路由配置 · 导航蓝图（system / custom）

L1 · 结构同步层
  导航蓝图发布 → 同步到企业预设（syncBlueprintToEnterprisePresets）

L2 · 预设配置层
  M 平台 · 企业级平台预设（业态 × 产线 → selection）
  商家后台 · 商家级平台预设（业态 × 产线 → selection）

L3 · 运行时层
  引导上下文（platform-preset-context）
  侧栏 / 滑层 / 设置页可见性
```

### 3.1 各层职责

| 层级 | 职责 | 配置主体 | 存储键（演示期） |
|------|------|----------|------------------|
| **导航蓝图** | 一级～四级「菜单树结构」+ 结构态勾选 | M 平台 · 菜单路由配置 | `nav-blueprint-store` |
| **企业级预设** | 在蓝图树上，按业态×产线设「展示/隐藏」 | M 平台 · 平台预设 | `menusifu:enterprise-platform-preset-v1` |
| **商家级预设** | 企业下发的默认 + 商家局部覆盖 | 商家后台 · 平台预设 | `menusifu:platform-preset-v1` |
| **运行时上下文** | 当前会话生效哪几组业态×产线 | 首次引导 / 顶栏 | `menusifu:platform-preset-context-v1` |

## 四、导航蓝图 → M 平台平台预设

### 4.1 蓝图来源二选一

M 平台「菜单路由配置」中 `navigationSource` 决定**发布时生效的结构**：

| 蓝图选择 | 发布生效结构 | 同步到企业预设时的树 |
|----------|--------------|----------------------|
| **系统默认** | `systemStructureSelection` + 系统 seq 归属 | 系统预设导航树（含蓝图对系统树的结构勾选） |
| **自定义导航树** | `customStructureSelection` + 自定义节点 | 自定义导航蓝图树 |

**代码路径**：

- 发布：`publishNavBlueprint()` → 写入 `snapshots[blueprintId]`
- 解析生效模块：`resolveActiveBlueprintModules(blueprint)`（按 `navigationSource` 分支）
- 同步：`syncBlueprintToEnterprisePresets()` → `mergeSelectionWithBlueprintTree()` → 写入各「业态×产线」快照，并记录 `blueprintVersion`

### 4.2 M 平台 / 商家后台「配置预设」编辑页如何取树

```
已发布蓝图存在
  AND 预设快照.blueprintVersion === 已发布蓝图.version
    → 四列矩阵展示「蓝图树」（系统或自定义，取决于 navigationSource）
否则
    → 回退「系统默认 registry 树」（NAV_MODULES + catalog 全量）
```

**代码**：`resolvePlatformPresetTreeOptions(scope, snapshot)` + `buildPresetEditorPlatformPresetIndex()`（`platform-preset-tree.ts`）。企业级与商家级编辑页共用同一解析逻辑；商家侧 `blueprintVersion` 随企业同步 / 首次引导写入。

### 4.3 M 平台配置预设时在做什么

在**已确定的四级树**上，为每个「业态 × 产线」组合维护 `selection`：

- `enabled`：是否在侧栏/滑层展示
- `display` / `l4EditMode`：设置项展示与可编辑（L4）

**M 平台不直接驱动任何商家侧栏**；须先「保存并发布」企业级预设。

## 五、商家后台三视角与平台预设

### 5.1 三视角差异（运行时）

| 视角 | 触发条件 | 主要差异 |
|------|----------|----------|
| **门店版** | 顶栏布局 = 门店版 | 单店数据 scope；部分 L1 隐藏（如品牌管理） |
| **集团视角** | 连锁版 + 集团总部数据视角 | 可见 `group-store-list`、品牌管理等 |
| **品牌多门店视角** | 连锁版 + 品牌数据视角 | 可见 `brand-store-list`；隐藏部分集团专属模块 |

三视角**不是三套独立预设存储**，而是：

- **同一商家级 `selection` 数据**
- **同一运行时过滤链**
- **在 RBAC + 数据视角层再裁剪**哪些 L1/L2 能出现

### 5.2 商家后台「配置预设」的数据从哪来

| 维度 | 目标口径 | 当前实现 |
|------|----------|----------|
| **勾选数据（selection）** | 默认来自 M 平台企业预设（企业预设又来自导航蓝图同步） | ✅ 首次引导 `seedMerchantPresetsFromEnterprise()`；可手动「同步到商家后台」 |
| **四列编辑页的树结构** | 应与 M 平台已发布蓝图一致 | ✅ `blueprintVersion` 与已发布蓝图一致时用蓝图树；否则回退系统 registry 树（`describePlatformPresetTreeSource` 提示） |
| **selection 归一化 / 级联 / 发布 diff** | 与编辑页同一棵树 | ✅ `normalizeSelectionForSnapshot` / `cascadeEnableSelection` / `diffPresetSelections` 均传入同一 `treeOptions` |

**结论**：

- 商家后台三视角的「预设配置功能」在**数据默认值**上来自 M 平台（经企业预设下发）。
- 在**编辑页树结构**上，已与 M 平台企业编辑页对齐（Phase 1+2）；**运行时侧栏**仍读 `NAV_MODULES + selection`，自定义蓝图 L1 的侧栏渲染仍为后续演进项。

### 5.3 商家是否从「菜单路由配置」读蓝图

- **商家后台没有独立的菜单路由配置入口**（该能力仅在 M 平台）。
- 间接依赖关系：

```
M 平台导航蓝图 → 同步企业预设 → 下发商家预设 → 商家侧栏
```

## 六、端到端数据流

### 6.1 主流程

```
【M 平台管理员】
1. 菜单路由配置 → 选「系统默认」或「自定义导航树」→ 发布蓝图 vN
2. 「同步到企业预设」（写入各业态×产线结构 + blueprintVersion=N）
3. 平台预设 → 配置预设 → 按业态×产线勾选 → 发布企业预设 vM

【商家管理员（任意视角）】
4. （可选）平台预设 → 局部调整 → 发布商家预设
5. 或等待首次引导自动 seed

【新商家用户 · 首次引导】
6. 选择业态×产线
7. seedMerchantPresetsFromEnterprise（从企业已发布预设复制到商家 store）
8. applyPlatformPresetContext（写入 session 上下文）
9. 侧栏按预设展示；切换集团/品牌/门店视角 → 同一预设 + 视角规则 → 侧栏差异
```

### 6.2 同步方向与规则

```
M 平台发布导航蓝图
    ↓ 同步到企业预设（结构 + blueprintVersion）
M 平台发布企业级预设（selection）
    ↓ 单向：首次引导 / 手动「同步到商家后台」
商家级预设
    ↓ 运行时
侧栏 / 滑层 / 设置页
```

| 规则 | 说明 |
|------|------|
| 商家修改不回写 M 平台 | 企业级预设为上游 SSOT |
| 商家未自定义 | 企业发布后可覆盖商家对应 combo |
| 商家已自定义 | 保留商家版本（`shouldOverwriteOnEnterpriseSync`） |

### 6.3 首次引导（商家后台）

**代码**：`platform-preset-onboarding.ts`

1. 用户选业态、产线  
2. `seedMerchantPresetsFromEnterprise()` — 从**企业级已发布预设**复制（仅尚无商家快照的组合）  
3. `applyPlatformPresetContext()` — 写入 session，侧栏开始按预设过滤  
4. 跳转首个允许路径  

侧栏展示的是：商家 store 中对应 combo 的 `selection`（源头 = 企业预设 = 蓝图同步 + M 平台勾选）。

### 6.4 日常运行侧栏过滤链（三视角共用）

```
NAV_MODULES
  → filterVisibleNavModules()           // RBAC + 视角（集团/品牌/门店）
  → filterNavModulesByPlatformPreset()  // 读商家 runtime selection（引导上下文并集）
  → renderSidebar()
```

平台预设**只控制可见性**，不改路由定义；视角层决定「门店列表」等模块是否出现。

## 七、四端对比总表

| 维度 | M 平台 | 商家·集团视角 | 商家·品牌视角 | 商家·门店版 |
|------|--------|---------------|---------------|-------------|
| **菜单路由/蓝图** | ✅ 配置、发布 | ❌ 无入口 | ❌ | ❌ |
| **平台预设配置页** | ✅ 企业级 | ✅ 商家级（可覆盖） | ✅ 同左 | ✅ 同左 |
| **四列树来源** | 已同步则蓝图树，否则系统树 | 已同步则蓝图树，否则系统树 | 同左 | 同左 |
| **selection 默认来源** | 蓝图同步 + 手工配置 | 企业预设（引导/同步） | 同左 | 同左 |
| **是否直接驱侧栏** | ❌ | ✅（经商家 store + context） | ✅ | ✅ |
| **视角特有过滤** | — | 集团门店列表等 | 品牌门店列表等 | 单店 scope |

## 八、单一事实来源（SSOT）

| 数据 | SSOT | 说明 |
|------|------|------|
| 导航结构（L1～L4 节点集合与层级） | M 平台已发布导航蓝图 | system 或 custom 由 `navigationSource` 决定 |
| 企业默认展示策略 | M 平台企业级预设 | 业态×产线维度的 selection |
| 租户生效展示策略 | 商家级预设 | 默认等于企业，允许局部覆盖 |
| 当前会话生效组合 | 商家引导上下文 | 多业态×多产线并集 |

### 8.1 与三视角的设计原则

- **预设配置**：视角无关，配置一次，三视角共享 selection  
- **侧栏展示**：视角相关，同一 selection 下由 RBAC + 数据视角决定「哪些 L1 能渲染」  
- **不应**为集团/品牌/门店各维护一套独立企业预设（除非未来有明确产品需求）
