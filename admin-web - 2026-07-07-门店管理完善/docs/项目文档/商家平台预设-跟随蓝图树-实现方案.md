## 一、目标

商家后台 **系统设置 → 平台预设 → 配置预设** 四列编辑页，在结构与 M 平台企业预设编辑页一致：

| 商家快照 `blueprintVersion` 有效，且等于当前已发布导航蓝图版本 | **已发布导航蓝图树**（system / custom 由蓝图 `navigationSource` 决定） |

## 二、现状与差距

### 2.1 已具备

- 商家快照类型含 `blueprintVersion` / `treeVersion`（`platform-preset-types.ts`）
- 企业 → 商家同步 / 首次引导会复制 `blueprintVersion`（`platform-preset-enterprise-sync.ts`）
- M 平台企业编辑页：`resolvePlatformPresetTreeOptions("enterprise", snapshot)` + `buildPresetEditorPlatformPresetIndex()`
- 商家编辑页 UI 已调用上述 API，但 `resolvePlatformPresetTreeOptions` 对 `merchant` **硬编码返回 `{}`**

### 2.2 核心缺口

```typescript
// platform-preset-tree.ts（当前）
export function resolvePlatformPresetTreeOptions(scope, snapshot) {
  if (scope !== "enterprise") return {};  // ← 商家被挡在这里
  ...
}
```

### 2.3 连带缺口（若只改 resolve，仍会不一致）

以下函数构建索引时**未传入** `treeOptions`，始终按系统全量树处理 selection：

| 函数 | 文件 | 影响 |
|------|------|------|
| `normalizeSelectionForLine` | `platform-preset-selection-normalize.ts` | 打开/保存编辑页时补全键、裁剪孤儿键 |
| `cascadeEnableSelection` | `platform-preset-store.ts` | 勾选联动子节点范围错误 |
| `countEnabledLevel1` | `platform-preset-store.ts` | L1 计数与矩阵不一致 |
| `ensureAlwaysEnabledPresetModules` 等 | `platform-preset-store-factory.ts` | 默认推荐、发布归一化 |
| `diffPresetSelections` | `platform-preset-changelog-diff.ts` | 变更记录路径标签错误 |

## 三、设计原则

### 3.1 树解析规则（商家 = 企业，同一套条件）

```typescript
function resolvePlatformPresetTreeOptions(
  _scope: "merchant" | "enterprise",
  snapshot?: Pick<PlatformPresetSnapshot, "blueprintVersion">,
): PlatformPresetTreeOptions {
  if (!snapshot?.blueprintVersion || snapshot.blueprintVersion <= 0) return {};
  return {
    useSyncedBlueprint: true,
    syncedBlueprintVersion: snapshot.blueprintVersion,
  };
}
```

- **不再区分** `scope` 是否 enterprise；商家、企业共用条件。
- 蓝图 SSOT：`getPublishedNavBlueprint(DEFAULT_NAV_BLUEPRINT_ID)`（与 M 平台同一蓝图 ID）。
- 版本不一致 → 回退系统树，并在 UI 提示「蓝图已更新，请同步企业默认」。

### 3.2 索引选用规则

| 场景 | 使用 API |
|------|----------|
| 四列编辑页渲染、列切换、勾选联动 | `buildPresetEditorPlatformPresetIndex(pl, treeOptions)` |
| selection 归一化、级联、发布 diff | `buildPlatformPresetIndex(pl, treeOptions)`（结构同源，无需视角过滤） |
| RBAC 矩阵 | 保持 `buildRbacPlatformPresetIndex`（不变） |

编辑页继续用 `buildPresetEditorPlatformPresetIndex`，以保留 `filterMatrixNavModuleGroups`（避免「门店列表」重复等）。

### 3.3 selection 与树的关系

- **归一化**：对当前索引 `flat` 中每个 key 保证有 selection 条目；索引外 key **保留不删**（避免企业同步后切换蓝图版本丢数据），但编辑页不展示。
- **发布**：仅校验/保存索引内 key 的 enabled 状态；可选在发布时 strip 索引外 key（建议 **Phase 2 不做 strip**，降低风险）。

### 3.4 旧数据兼容

| 商家快照状态 | 编辑页树 | 提示文案 |
|--------------|----------|----------|
| 无 `blueprintVersion` | 系统 registry | 「未绑定导航蓝图，展示系统默认结构」 |
| `blueprintVersion` < 已发布蓝图.version | 系统 registry | 「导航蓝图已更新（快照 vX / 当前 vY），请同步企业默认」 |
| 已对齐 | 蓝图树 | 「导航结构：导航蓝图 vN（系统默认/自定义）」 |

## 六、测试计划

### 6.1 前置数据

1. M 平台：菜单路由配置 → 选 **自定义导航树** → 新增一级 → 发布蓝图 v1

### 6.2 用例

| ID | 步骤 | 期望 |
|----|------|------|
| T1 | 商家编辑页打开已 seed 的 combo | 四列树 = M 平台企业编辑页（同 blueprintVersion） |

- M 平台企业编辑页行为不变

## 七、风险与对策

| 风险 | 对策 |
|------|------|
| 蓝图树节点 key 与 registry 不一致，侧栏不展示自定义 L1 | 编辑页先对齐；侧栏自定义节点渲染单列需求 |
| 商家改过 selection 后企业蓝图升级，结构变化 | 保持 `outdated` + 手动同步；merge 逻辑沿用 `mergeSelectionWithBlueprintTree`（企业侧已有） |
| 归一化用错索引导致静默丢勾选 | Phase 2 必须上线，与 Phase 1 同发或紧接 |
| 缓存 stale | `invalidatePlatformPresetTreeCache()` 在蓝图发布、企业/商家 sync 后已调用；商家 publish 后调 runtime cache invalidate（已有） |
