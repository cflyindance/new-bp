# 导航维度：连锁与单店

> 文档版本：v1.0  
> 适用：`admin-web` 顶栏数据范围 + 侧栏一级导航 + 门店版/连锁版布局  
> 实现：`admin-web/src/auth/session-scope.ts`、`admin-web/src/permissions/nav-access.ts`

---

## 1. 两个独立概念

| 概念 | 含义 | 载体 |
|------|------|------|
| **数据维度（Org Tier + Scope）** | 当前看哪一层组织的数据 | 顶栏 **品牌 · 区域 · 门店**；账号 **组织层级**（`store` / `chain`） |
| **导航布局（Layout Preset）** | 哪些模块常显 / 收进「更多」 | 顶栏 **门店版 / 连锁版**（`sidebar-nav-layout-preset-v1`） |

**实际可见导航** = 账号 RBAC × 组织层级 × 布局预设 × 顶栏 scope。

---

## 2. 顶栏控件分层

### 2.1 连锁维度（数据范围）

| 控件 | 连锁账号 | 单店账号 |
|------|----------|----------|
| 品牌筛选 | ✓ 可选 | 隐藏 |
| 区域筛选 | ✓ 可选 | 隐藏 |
| 门店筛选 | ✓ 可选（含「全部门店」） | **锁定当前门店**（只读展示） |

### 2.2 个人 / 界面层（与组织无关）

| 控件 | 说明 |
|------|------|
| AI 助手 | 应读取当前 scope 上下文 |
| 界面语言 | 个人偏好 |
| 深 / 浅色 | 个人偏好 |
| 门店版 / 连锁版 | 侧栏收纳策略；默认随组织层级，可手动覆盖 |
| 个人中心 | 账号级 |

---

## 3. 侧栏一级模块维度归属

图例：**连** = 连锁主数据 · **店** = 单店经营 · **混** = 随 scope 变化

### 3.1 连锁维度（总部 / 区域为主）

单店组织层级下 **默认不展示**（见 `STORE_TIER_HIDDEN_NAV_MODULE_IDS`）：

| 模块 | 说明 |
|------|------|
| 品牌管理 | 品牌主数据、多品牌策略 |
| 权限管理中心 | RBAC、员工赋权 |
| 素材中心 | 品牌级素材库 |
| 日志管理 | 审计、登录日志 |
| 信贷中心 | 金融产品入口 |

### 3.2 单店维度（店长 / 现场）

单店账号 **始终保留**（RBAC 允许时）：

| 模块 | 说明 |
|------|------|
| 主页 | 今日概览、待办 |
| 前厅 / 后厨 / 外卖 / 预约等位 | 营业现场 |
| 团队管理 | 排班、打卡、小费 |
| 财务中心 | 日结、收银审计 |
| 门店管理 | 本店档案（非多店列表） |
| 硬件 / 打印 | 本店设备与小票（多在「更多」） |

### 3.3 混合维度（随顶栏 scope）

| 模块 | 连锁视角 | 单店视角 |
|------|----------|----------|
| 商品中心 | 品牌商品、菜单下发 | 门店菜单、本店调价 |
| 报表 / 财务 | 多店汇总、区域对比 | 本店日报 |
| 促销 / 会员 / 营销 / 评价 | 总部活动与洞察 | 本店执行与回复 |
| 库存管理 | 多店策略（连锁版主导航） | 本店效期物料 |
| 订单 / 支付 | 集团规则模板 | 本店继承配置 |

## 4. 门店版 / 连锁版布局对照

详见 [`docs/项目文档/侧栏导航布局-门店版与连锁版.md`](./侧栏导航布局-门店版与连锁版.md)。

| 预设 | 主导航约 | 「更多」约 | 默认绑定 |
|------|----------|------------|----------|
| 门店版 | 14 项 | 13 项 | 单店组织层级 |
| 连锁版 | 16 项 | 11 项 | 连锁组织层级 |

连锁版与门店版差异：**权限管理**、**库存管理** 在连锁版为 **主导航**。

## 6. 已落地行为（代码）

| 建议 | 实现 |
|------|------|
| 顶栏 scope 与账号绑定 | `isChainScopeMode()`：连锁账号 **或** 选择 **连锁版** 时展示品牌/区域/门店三级筛选；门店版 + 单店账号锁定当前门店 |
| 侧栏与 RBAC + 组织层级 | `nav-access.ts`：`filterVisibleNavModules()` |
| 布局预设与账号联动 | 登录时 `applyDefaultLayoutPresetForOrgTier()`；手动切换后不再自动覆盖 |
| 页头标明 scope | 主内容区 kicker 追加 `formatScopeFilterLabel()` |
| 主页待办区分维度 | `/dashboard/*` 占位页展示不同待办列表 |
| 无权限路由 | 访问隐藏模块时重定向至 `#/dashboard/overview` |
| 连锁版展示品牌管理 | 选择顶栏 **连锁版** 时，单店账号亦在侧栏主导航展示 **品牌管理** |
| 连锁版 scope 筛选 | 选择 **连锁版** 时，顶栏展示 **品牌 · 区域 · 门店** 下拉（单店账号亦适用） |
