# Emenu 项目初始地图

## 已确认事实

- 仓库根目录是 `D:\MenusifuStore\emenu-new`，也是 Git 根目录。
- 根项目 `package.json` 中项目名为 `emenu`，版本为 `5.11.81`，`private` 为 `true`。
- 项目使用 React 17、Vite 2、React Router 6、Redux Toolkit、Material UI 4、Ant Design 4、i18next、axios、ahooks 等依赖。
- 包管理器声明为 `yarn@3.4.1`，`.yarnrc.yml` 使用 `node-modules` linker，并配置了 npm 镜像和 `@menusifu` 私有源。
- `package.json` 要求 Node.js 版本 `>= 18.18`。
- 构建输出目录由 `vite.config.js` 配置为 `build`。
- `docs/agent-wiki/` 在首次扫描前不存在，本文件是首次创建的 wiki 记录。

## 关键入口

- 应用 HTML 入口：`index.html`。
- React 挂载入口：`src/index.jsx`。
  - 初始化 i18n。
  - 创建 Material UI theme。
  - 使用 Redux `Provider` 注入 `src/store`。
  - 使用 `HashRouter` 承载路由。
  - 使用 `ErrorBoundary`、`AliveScope`、`SnackbarProvider` 和项目内 `AntdConfigProvider` 包裹应用。
  - 给 Android WebView 暴露 `window.androidWebkit.keyboardOpen` 和 `keyboardClose`。
- 应用路由入口：`src/App.jsx`。
  - 懒加载主要页面。
  - 在挂载时初始化语言、系统配置和 CRM/会员相关数据。
  - 非设置页通过 `effects.initConfig` 初始化配置。
  - 设置页通过 `postMessage` 获取 session key 后拉取配置。
- 顶层页面容器：`src/pages/Index.jsx`。
  - 负责 license 选择、client login、公司信息、系统配置、全局上下文、WebSocket 更新、用餐时间/营业时间提醒和全局网络弹窗。

## 路由

`src/App.jsx` 使用 `react-router-dom` 的 `Routes` 和 `Route`，并挂在 `HashRouter` 下：

- `/`：`src/pages/Landing`
- `/setup`：`src/pages/SetupOrder`
- `/order`：`src/pages/Order`
- `/setting`：`src/pages/SystemSetting`
- `/setting/global`：`src/pages/GlobalSetting`
- `/setting/device`：`src/pages/DeviceSetting`
- `/setting/category`：`src/pages/CategorySetting`
- `/setting/menuClassify`：`src/pages/MenuClassify`
- `*`：`src/pages/NotFound`

## 关键目录

- `src/pages/`：页面级入口。
- `src/components/`：通用组件和业务组件。
- `src/services/`：接口封装和订单/菜单/配置/CRM 等业务转换逻辑。
- `src/hooks/`：业务 hooks，包括菜单加载、订单拉取、WebSocket、下单、发送厨房、CRM 等。
- `src/store/`：Redux store 和 slices。
- `src/constants/`：系统配置、订单、localStorage key、WebSocket 等常量。
- `src/utils/`：请求、存储、税费、CRM、菜单过滤、设备信息等工具函数。
- `src/locales/`：多语言资源。
- `src/assets/` 和 `public/assets/`：图片、图标和 PWA 静态资源。
- `src/docs/`：项目内已有说明文档。
- `docs/superpowers/plans/`：已有实施计划文档。
- `scripts/`：Node 测试脚本，当前主要覆盖 CRM integration 相关逻辑。

## 状态和 API 位置

- Redux store：`src/store/index.js`。
  - `systemConfigSlice`
  - `avocadoSlice`
  - `system`
  - `crmProviderSlice`
  - `crmIntegrationValidationSlice`
- 系统配置状态：`src/store/slices/systemConfig.slice.js`。
  - 通过 `getEmenuConfig`、`setEmenuConfig`、`getEmenuProConfig` 读取和保存配置。
  - 维护 `configList`、`tempGlobalConfig`、`deviceBindInfo`、`emenuProConfig`。
- 轻量全局状态：`src/hooks/useGlobalState.js`。
  - 使用 `react-hooks-global-state`。
  - 保存菜单、购物车、订单、会员、CRM、buffet、权限、分类、海报等前端状态。
- 全局上下文：`src/context/GlobalStorageContext.js`。
  - 在 `src/pages/Index.jsx` 中提供 auth、company、system、socket 类型等信息。
- 请求实例：`src/utils/request.js`。
  - 使用 axios 创建 baseURL 为 `/kpos/api` 的实例。
  - 统一处理 Authorization、POS version、`/kpos/webapp` 请求、session key 刷新、POS version 刷新和网络错误提示。
- 主要服务模块：
  - `src/services/system.js`：license、login、权限、消息、公司信息、系统时间等。
  - `src/services/setting.js`：EMENU/EMENUPRO 配置、图片上传、POS 日志。
  - `src/services/menus.js`：菜单获取、菜单转换、营业时间过滤、多语言资源注入。
  - `src/services/orders.js`：订单获取、保存、清台、送厨、打印、订单转换、订单生成、服务费和时间提醒计算。
  - `src/services/crm.js`：CRM 状态、会员、权益、积分和奖励规则。
  - `src/services/crmIntegration*.js`：集成型 CRM 的客户端、SDK、权益校验和订单格式化。
  - `src/services/avocado.js`：Avocado 相关会员、活动和事务接口。
