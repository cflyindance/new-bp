#### Emenu-new 接口 `[修订中]`

- ##### 所有菜单

  获取所有分类和菜品的数据

  参考接口`webapp/menu/menu?product=EMENU`

- ##### 下单

  提交保存订单

  参考接口`webapp/order/saveOrder`

- ##### 已下单

  获取已提交订单

- ##### 首页相关

  首页封面图/视频地址信息

- ##### 发消息

  呼叫服务员

  参考接口`webapp/message/saveMessage`

- ##### 后台管理登录

  服务员等后台人员登录

- ##### 桌子列表

  获取所有桌号以供选择

  参考接口`webapp/emenu/area/listTables`
