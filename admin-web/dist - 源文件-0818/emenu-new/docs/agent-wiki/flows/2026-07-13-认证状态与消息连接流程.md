# 认证状态与消息连接流程

## 认证状态同步

1. `src/utils/storage.js` 的 `setStorageValue` 继续把值序列化后写入 `localStorage`。
2. 当写入键为 `emenu_auth` 时，该函数还会在 `window` 上派发 `emenu_auth_changed` 事件，并把本次写入值放在事件的 `detail` 中。
3. `src/hooks/useWS.js` 挂载时监听 `emenu_auth_changed`；事件包含 `detail` 时，用该值调用 `setAuthInfo`。
4. hook 卸载时移除同一个事件监听器。
5. `useWS` 原有依赖 `authInfo` 的状态推导因此能够接收到通过 `setStorageValue('emenu_auth', value)` 写入的新认证信息。

## SocketCenter 连接引用清理

1. `src/hooks/useSocketCenter.js` 创建 `SocketClient` 后，保留原始 `close` 方法的绑定引用。
2. 包装后的 `close` 会先检查当前客户端是否仍分别保存在 `window.globalWs` 和 `scRef.current` 中。
3. 命中时把对应引用置为 `null`，然后调用原始 `close`。
4. `useSocketCenter` 的连接创建入口以 `scRef.current` 是否存在作为提前返回条件；关闭时清空该引用后，后续调用不再被旧客户端引用拦截。

## 呼叫服务消息来源

- `src/services/system.js` 的 `sendCdsMsg(orderId)` 向 `/cds/message` 发送 `CALL` 动作时，在请求体中固定携带 `requestSource: 'EMENU_CALL_SERVER'`。
