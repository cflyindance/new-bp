变更编号 M-ROLE-HIERARCHY-20261116-01；三份配对文档 V1.19。功能分支 codex/m-role-menu-hierarchy-20261116，main@fef93770 起始；原main预览5348不变，新功能预览5349。提交、合并和推送状态以最终 Git 交付核验为准。

## 根因与边界

根因confirmed：buildMEditorCatalog直接将M_MODULES映射为模块／页面两层，而侧栏renderMNavigation在授权目录之外生成中间分组和复用入口。失败测试确认缺少菜单配置层；实际侧栏菜单叶子与修复配置树逐项对比均为26项。

修复将原展示转换提取到m-platform-navigation.ts供侧栏和编辑器使用；编辑器展示节点映射原权限资源。M_RESOURCES、mResolve、saveMState和存储schema未修改；同一权限的多个导航入口仍共同生效，没有新增独立授权。

Wiki bypass：resolver返回wiki_not_configured，依据当前源码与测试。影响范围见[analysis-scope.json](analysis-scope.json)，计划见[plan.md](plan.md)。
