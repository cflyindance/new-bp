# 平台角色菜单层级修复计划

根因：配置树只读取权限资源目录；实际侧栏在此基础上另生成菜单配置、页面注册中心、角色与权限及两个预设别名，配置树未承接这些展示节点。RED 已确认缺少菜单配置中间层。

1. 从现有侧栏逻辑提取纯展示清单供侧栏与编辑器共用，维持原入口及顺序。
2. 编辑器增加展示节点到已有权限资源键的映射；中间组织目录无独立授权；共用入口显示说明，不迁移授权。
3. 保持 mResolve、M_RESOURCES、saveMState 不变；别名动作仍写原资源键。
4. TDD：先验证缺失层级，再验证完整叶子与侧栏一致、唯一展示键、共享授权、只读与父级限制。
5. E2E required：菜单与页面管理两层、角色与权限第三层、预设别名、搜索、草稿预览、保存差异、侧栏打开返回及商户编辑器回归。
6. 类型检查；Build skipped：未改依赖、构建或动态导入边界，CI build 仅有提交证据、状态unknown，不假设CI兜底。
7. 三份 V1.18 文档核对实现偏差，补当前截图和验证记录。风险：共用授权被误解为独立权限，必须提示；回滚仅还原本次展示适配文件，不动已保存授权。
