指定演示账号允许不含 @；原有 Menusifu 企业邮箱和受维护员工账号校验继续生效，停用账号仍拒绝，错误密码仍拒绝。会话及日志沿用实际提交账号记录，大小写和首尾空格沿用既有归一化流程。

验收：打开、刷新、重新进入登录页均有默认值；不手工输入可点击登录进入系统；错误密码提示并留在登录页；企业邮箱登录不受影响。未改变会话有效期、权限或自动下发规则。
