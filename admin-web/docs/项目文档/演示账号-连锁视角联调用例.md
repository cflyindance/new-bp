## 三、分账号联调步骤

### TC-01 · 多品牌运营（`brand.ops.east@menusifu.cn`）

**场景**：一个账号管理多个品牌，每品牌下有多门店。

1. 登录 → 顶栏版本选 **MVP** → 视角选 **连锁版 · 品牌多门店**。
2. 确认顶栏 **品牌** 为下拉，选项含「张记火锅」「张记串串」，**不含**「杭城小笼」「茶语一家」。
3. 选「张记火锅」→ 门店下拉含「上海陆家嘴店」「广州天河店」。
4. 切换品牌为「张记串串」→ 门店下拉刷新为「成都春熙店」「重庆解放碑店」；区域筛选在 MVP 下隐藏。
5. 进入 **门店管理 → 设置**（或任意 `/…/settings` 配置页）→ 顶栏**无**门店下拉；页内展示「请先选择门店」引导。
6. 在页内选择「上海陆家嘴店」→ 展示配置项 + 顶部「配置门店」选择条，可切换门店。
7. 切换顶栏品牌为「张记串串」→ 门店选择清空，配置页回到「请先选择门店」。

**预期**：切换品牌后 `menusifu:scope-filter-change` 触发，业务页数据范围随 `resolveEffectiveScope()` 更新。

---

### TC-02 · 单品牌锁定（`brand.ops.single@menusifu.cn`）

**场景**：仅授权一个品牌的经理，顶栏品牌不可切换。

1. 登录 → MVP + 品牌多门店视角。
2. 顶栏 **品牌** 为只读标签「张记火锅」，无下拉。
3. 门店下拉仅含上海、广州两店。
4. 尝试在 URL 或控制台改写 `scope-brand` 为 `merchant-zhangji-skewers` → 保存后被 `clampScopeToStoreAccess` 收敛回授权范围。

**预期**：`shouldShowBrandScopeLockedLabel() === true`。

---

### TC-03 · 集团超管 MVP 浏览（`zhangji.admin@menusifu.cn`）

**场景**：MVP 隐藏集团总部入口，超管以品牌多门店视角浏览多品牌。

1. 登录 → 确认版本 **MVP** 下视角菜单**无**「集团总部」「M 平台」。
2. 默认或手动选 **品牌多门店**。
3. 顶栏品牌下拉含张记集团内全部品牌（张记火锅、张记串串、杭城小笼等，以 M 平台同步快照为准）。
4. 切换版本为 **未来版本** → 可出现「集团总部」；选集团总部后顶栏含品牌/区域/门店三级筛选。

**预期**：`ensureMvpGroupHqViewSwitchHidden` 在 MVP 下不会停留在集团总部视角。

---

### TC-04 · 门店版单店（`xiaoming.wang@menusifu.cn`）

**场景**：店长不涉及品牌概念。

1. 登录 → 默认 **门店版**，顶栏仅显示当前门店（上海陆家嘴店）只读。
2. 无品牌/区域筛选。
3. 侧栏无「品牌管理」等连锁专属模块（或收入「更多」）。

**预期**：`isStoreScopeLocked() === true`，`perspective === store`。

---

### TC-05 · 收银员权限裁剪（`cashier.li@menusifu.cn`）

1. 登录门店版 → 确认订单/支付模块可见，敏感设置类入口按 RBAC 隐藏。
2. 顶栏门店锁定为上海陆家嘴店。

**场景**：验证《集团-品牌-门店分级权限方案》§1.1。

2. 该员工登录 → 品牌多门店视角下仅见张记火锅，与集团侧授权一致。

### TC-07 · 团队管理页内门店选择（`brand.ops.east@menusifu.cn`）

**场景**：团队管理各二级入口均需先选门店；角色与员工、员工打卡为页内精简筛选。

1. 登录 → MVP + 品牌多门店，顶栏选「张记火锅」。
2. 进入 **角色与员工**：顶栏无门店下拉；「员工列表」标题下方可见「门店」下拉；未选门店时表格提示先选店；选店后列表按门店过滤。
3. 进入 **员工打卡**：在「打卡管理」「考勤记录」Tab 中，门店下拉位于日期选择左侧；「规则设置」Tab 顶部同样有门店下拉。
4. 进入 **排班**：精简门店下拉位于日期选择器左侧；未选门店时表格提示先选店。
5. 依次进入：**休息与加班**、**设置**。
6. 上述页面：未选门店时显示「请先选择门店」；选店后展示页顶「配置门店」条及业务内容。
7. 在「休息与加班」页切换门店 → 页面随 `menusifu:scope-filter-change` 刷新，数据范围更新。

**覆盖路径**：`/team/roles-employees`、`/team/clock-in`、`/team/shift-scheduling`（页内精简筛选）、`/team/breaks-overtime`、`/team/settings`（见 `team-store-scope.ts`）。

### TC-09 · 财务中心页内门店选择（`brand.ops.east@menusifu.cn`）

**场景**：收银记录与审计在查询区精简选门店（时间选择器左侧）。

## 五、常见问题

| 现象 | 排查 |
|------|------|
| 品牌下拉为空 | 检查 `loadChainBrandOrgForContext()` 是否已同步；localStorage 键 `menusifu:chain-brand-org-sync-v1:group-zhangji-holdings` |
| 切换品牌后门店未刷新 | 确认 `bindHeaderScopeFilters` 中 brand change 调用了 `writeChainDataPerspective` |
| 仍看到茶语一家 | 旧 RBAC 种子未迁移；清除 `localStorage` 中 `menusifu:rbac-*` 相关键后重载 |
| MVP 仍显示集团总部 | 检查 `menusifu:product-version-v1` 是否为 `mvp` |
