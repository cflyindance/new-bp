## 已确认页面结构

实际入口为团队管理 → 薪资管理（`#/team/payroll-report`）→“发薪周期设置”。设置全屏展示，返回保留原筛选；新增/编辑规则在居中弹框中完成，再二次确认。历史位于当前规则摘要下方，门店筛选联动两者。旧的独立 `#/team/payroll-schedule` 原型及旧“待确认交互点”不再作为当前开发依据。

薪资页面默认双周示例；点击“实际数据”恢复真实快照。演示、真实记录和尚未接入的历史模拟汇总不可混用。实际规则只读，正式发布及完整迁移尚未接入；详情、打印和文件生成的设计确认不等于全部生产验收通过。
