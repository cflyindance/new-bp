## 代登录性能修复（IMPERSONATION-PERF-20261021-49）

产品V1.46／研发V1.45／个人V1.45；基线main@f39b220b（含此前已合并未推送成果），功能分支codex/impersonation-performance-20261021，预览5238。本次修复品牌/门店点击代登录后进入后台偏慢；页面布局、按钮、权限、合同和服务状态规则均不变，不新增UI字段。

| 项目 | 说明 |
| --- | --- |
| 已确认根因 | 同一入口/渲染链重复构建只读权限目录和系统菜单结构。CDP CPU profile指向buildCenterCatalog、pagePolicy/registerPageModes、nav-blueprint-current-tree；商户快照读取也是成本项，但最终没有缓存或改变其数据读取逻辑。 |
| 权限目录复用 | 仅品牌运行时复用按UI语言构建的Catalog；品牌权限编辑器默认仍取得独立目录，避免编辑共享缓存。 |
| 菜单键映射复用 | 按Catalog、已发布菜单路由版本、完整raw key集合建立映射缓存；上限128组。菜单键或路由版本变化使用新结果，不缓存最终可见/可编辑结论。 |
| 系统菜单结构 | 只读系统树按语言复用；每次返回structuredClone，路由编辑器等消费者可修改副本，不污染其他页面。自定义发布结构仍由原版本机制处理，不新增菜单或授权。 |
| 实时限制 | 原账号enabled、角色、门店范围、品牌服务状态、brand上限及store菜单每轮仍读取并计算；暂停服务或撤销菜单不会沿用旧授权。 |
| 保持流程 | 原代登录检查、preset同步、品牌/门店上下文锁定、起止审计及退出返回均保留；不跳过同步或放宽权限换速度。 |
| 测量口径 | Windows Edge headless、localhost Vite、每类独立浏览器上下文，同一脚本先验证同步入口再测实际按钮到后台banner及两帧显示。不是生产SLA，实际用户数据/机器时间可能不同。 |
| 品牌结果 | 同机记录点击到显示1262.4ms → 674ms，约减少47%；同步入口76.8ms → 73ms。 |
| 门店结果 | 同机记录点击到显示826.5ms → 372.4ms，约减少55%；同步入口367.4ms → 187.1ms。 |
| 回归预算 | 测试同步入口<300ms、点击到显示<800ms，仅用于本地对比；基线1262.4ms已产生失败证据。不同机器如未满足预算需重新剖析，不把预算视为业务承诺。 |

验证：性能脚本、缓存副本隔离、语言重建、撤销/恢复菜单、服务暂停即时生效、门店锁定/退出/审计、品牌生命周期均通过；系统路由对比214项，缺失/父级/顺序错误均为0；tsc和diff检查通过。未执行嵌入包或生产构建：本次无vendor/emenu和构建边界修改。

### 研发对象、兼容与验收

MerchantStatus保留draft/onboarding/active/suspended/closing/closed以读取旧数据；serviceStatus投影为onboarding/active/suspended/closed，中文待启用/已启用/已暂停/已关闭。新增可选serviceReason:string、firstLoginAt:ISO时间；既有updatedAt、activatedAt、closedAt及suspendedReason沿用。新M平台创建传activateImmediately:false；旧已启用数据和程序化种子不批量改为待启用。账号enabled与品牌status各自存储，不迁移授权或自动新增菜单。

手动操作统一调用transitionBrandService(id, action, reason, expected)，action为activate/suspend/resume/close；服务版本组合品牌/路由/门店配置与品牌访问配置版本，品牌配置版本现包含服务相关品牌数据，但排除firstLoginAt。API状态修改也要求reason及expected并走同一入口，不再任意PATCH枚举。入口要求已登录M平台、当前身份不是商家品牌账号；本地前端校验不冒充生产服务端授权。状态转换与审计在同次配置持久化，失败保留草稿；恢复条件在提交时再次校验，防止过期Admin/菜单配置或合同变化。

配置、账号、门店、菜单及业务数据在暂停/关闭中保留；品牌已关闭后M平台仍可查看既有配置和历史，当前无重新开通业务；本次不调整各配置页原有M平台维护权限。无需门店也可启用，至少一页菜单和有效Admin为必需。旧待引导/draft不再允许商家登录；旧closing不自动到期关闭或获得只读访问。旧初始化完成函数只记录已启用品牌的完成进度，不再激活待启用品牌。未来如需关停审批、撤销关闭、POS全终端强制断开或账务结清检查需独立确认，不属于已实现范围。

## 公共规则

品牌菜单是后台功能菜单，不是菜品。品牌上限、门店实际开通、角色功能权限、账号角色生效门店分别维护。普通账号在某店只能使用四层交集；品牌 Admin 品牌视角可管理所有品牌门店和品牌菜单，在门店业务视角不能绕过本店开通。普通账号无门店开通与账号角色管理入口。

M 平台品牌详情整体独立占满窗口，隐藏平台侧栏和通用顶栏；移除顶部 Enterprise 集团信息和切换区；保留品牌上下文、概览/品牌门店/品牌菜单/品牌管理员/变更记录页签及返回品牌列表。各页签切换和刷新保持独立布局，返回列表恢复平台导航。

新增路由不自动授权已有品牌；品牌新增菜单不自动开通给各店；收回品牌菜单同步裁剪各店。查看与搜索不是未保存编辑；真正修改后的关闭需要确认放弃。预览不写入，确认保存重新校验版本与范围；失败保留输入，取消不写入。
