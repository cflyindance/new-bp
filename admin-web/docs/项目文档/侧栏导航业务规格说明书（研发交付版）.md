## 公共菜单交互规则（NAV-20261014-01）

用户确认：导航菜单存在二级菜单时，统一采用排班式覆盖滑层，任意更深父子层级递归复用。

| 元素 | 逻辑说明 |
|---|---|
| 有子菜单的菜单行 | 整行含文字与空白可点击，显示进入箭头；点击进入下一层，不在父项下内嵌展开，不自动切换业务页。 |
| 子导航滑层 | 占用与父层相同区域，顶部和宽度对齐；覆盖父标题、搜索与列表，不在新标题上方保留父标题。商家标识及导航排序沿用原侧栏边界。 |
| 当前层标题 | 使用被点击的菜单名称；每层只展示该菜单当前允许访问的子项。 |
| 返回按钮 | 左上箭头只退一层，首层子导航返回主导航；不回退业务地址，不保存、下发或修改业务数据。 |
| 叶子菜单 | 沿用原目标地址打开页面，保留当前子导航层，当前项高亮；业务页权限和草稿保护沿用原机制。 |
| 深层父项 | 继续按同位置覆盖滑层下钻，不并排展开多层列表；返回逐层恢复。 |
| 可见菜单范围 | 沿用权限、订阅、发布和预设过滤；不新增授权。过滤后无子项不显示空下钻层。 |
| 搜索 | 已有模块搜索仍在父层使用；进入子层清除原搜索，不复制父搜索框、不新增子层搜索能力。 |
| 刷新／切换模块 | 下钻路径仅保存于内存，刷新不恢复；业务页按地址定位。切换模块或关闭滑层清除旧层级。 |

范围：导航菜单父子层级；页面内部页签、业务列表折叠和更多组织分组不属于本规则。无子菜单的链接沿用原打开方式。新菜单必须复用公共逻辑，不新增模块内嵌展开例外。

## 字段、对象关系与异常

| 字段 | 逻辑说明 |
|---|---|
| hubId | 字符串，来自当前模块 data-hub-sheet-root；关联既有已过滤导航树，切换模块不能继承其他模块层级。 |
| levels | 内存数组，默认空；点击父项压入一层，返回弹出一层；刷新初始化，无业务存储写入。 |
| controls | 字符串，来自父项 aria-controls；必须在当前模块渲染结果定位子导航容器。失效时清空层级、恢复模块根菜单。 |
| title | 字符串，来自父项显示名称，沿用原语言配置；用于子层标题，不改变业务地址。 |
| href | 叶子原导航地址，点击由原 hash 导航进入业务页；保留当前层级并重新计算当前项。 |
| aria-current | 地址与叶子匹配时为 page，沿用原高亮判定；只进入父项不自动改业务页。 |

公共层在原滑层容器替换父层全部内容，顶部使用同一 h-14 标题栏。父层标题不保留在键盘可访问树。当前显示层解除旧内嵌折叠遗留的 tabindex=-1；深层隐藏列表仍不可见。父项点击拦截专用折叠事件，避免一次点击执行两套交互。数据来源仍是最新过滤后的导航 DOM，重新挂载从当前配置重新解析，不使用旧未授权菜单快照。没有容器或权限过滤移除容器时清空下钻状态并恢复模块根菜单。无金额／精度／计算规则新增。

## 验收与验证

| 前置／操作 | 预期 |
|---|---|
| 团队管理 → 员工打卡 → 考勤记录 | 员工打卡标题覆盖团队管理；records 页面打开，子导航保持。 |
| 团队管理 → 角色与员工 | 仅显示员工管理、岗位管理，不在团队管理下内嵌展开。 |
| 团队管理 → 排班 | 排班表、班次、规则设置同位置显示。 |
| 商品中心 → 商品管理 → 配方管理 | 两次下钻覆盖前层；标题为配方管理，返回恢复商品管理。 |
| 会员中心 → 卡券管理 → 返回 | 卡券子菜单显示，返回恢复会员菜单。 |
| 当前子层 → 刷新 | 内存层级清空，业务页地址保留。 |
| 配置过滤移除当前容器 → 重新挂载 | 恢复根菜单，不展示旧子项。 |

真实浏览器验证了团队、商品两层和会员子层；团队子层顶部与父层同为 95.25px（本次视口），可见子层链接没有 tabindex=-1。类型检查通过。其他模块复用同一公共处理，未逐页重验全部业务。旧侧栏布局数量和全量业务字段迁移不属于本次确认。
