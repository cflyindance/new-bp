## 范围与决策

分类管理指面向食客展示的菜单入口分类，与商品主数据中的菜品分类不同。采用“分类与菜单／分类设置”两项公共子导航；沿用 NAV-20261014-01 的覆盖滑层、权限、订阅、预设、发布和草稿保护。

单个分类维护名称、图片、展示渠道、供应时段、可下单菜单与仅可查看菜单。分类模式的适用终端留在本模块设置页。营业时段规则继续在“营业与运营 → 营业时段”维护，本模块只引用已有规则。

本次不新增批量操作、不改变商品主数据、跨产线分别累计口径、终端授权和下发流程，不把“仅可查看”解释成售罄或禁售。

## 路由、对象与数据

| 字段／对象 | 类型与规则 |
|---|---|
| 分类 ID | string；沿用既有 cls ID；新增生成唯一标识，编辑保留 ID，删除依 ID 操作。 |
| name | string；必填，输入最大 50 字符，保存 trim；无新重名规则。 |
| imageDataUrl | 可选 string；来源公共图片选择器，空值显示缺省图片；本次不新增图片服务。 |
| scheduleIds | string[]；引用营业时段 ID；新增优先 All Day、否则首项、源为空为空数组；读取时过滤无效引用并沿用历史默认回退。 |
| displayChannels | BrandMenuLineId[]；kiosk / emenu / pos / sdi；默认四项，显式空数组保留为空。 |
| menuByCategory | Record<分类 ID, CategoryMenuConfig>；删除分类同时删除对应映射。 |
| displayName | string；沿用原字段，基本资料保存时同步当前名称。 |
| orderableStructureByLine | 各产线 string[] 选择结构；默认四产线空集合；来源原公共菜单选择器。 |
| viewOnlyMode | dish / category；原默认 category；决定摘要计数来源和仅查看面板。 |
| viewOnlyCategoryIds | string[]；排除本分类及不存在 ID；删除被引用分类时从其他分类引用数组中移除。 |
| viewOnlyStructureByLine | 各产线 string[]；默认空；按菜模式读取计数，模式切换不主动丢弃既有结构。 |
| 模式适用终端 | emenu / sdi 多选；原字段 602-menu-classification-mode-lines，沿用默认与存储编码。 |
| 分类列表字段 | foh-classification-categories，沿用现有兼容数据源。 |
| 完整状态字段 | foh-classification-settings:v1，含 categories、menuByCategory、hoursNote；hoursNote 既有空值保留。 |

- 列表地址 `/operations/queue-call/classification-settings/categories`；设置 `/settings`。旧根地址及原 category / menu / hours 入口继续重定向列表。
- 两个新子节点归属原 queue-call:qc-classification-settings 分支，不新增独立业务授权规则。
- 保存桶由 resolvePageSaveKey 归一为 `/operations/queue-call/classification-settings`。菜单、基本资料和全局设置沿用同一个桶。
- 基本资料保存使用 `{...prevMenu, displayName: name}`；不能从已移除的菜单选择器读取空值覆盖菜单。
- 菜单宽抽屉同时渲染两套面板，切换仅修改可见状态；保存依次采集 orderable / viewOnly 后写入完整状态，取消不调用写入函数。
- 名称搜索和渠道筛选只改变行 hidden 状态；显示数为同时匹配两条件的分类行数，刷新后保留过滤控件并重新计算。
- 可下单数量以内置树展开计数加上不在内置树中的已配置主机菜品叶子数；同一产线的重复叶子去重，同菜跨产线分别累计。仅查看按分类为有效引用数组长度，按菜使用同一计数。整数，无金额、比例或精度运算。
- 写入、保存失败、异常和下发状态继承公共草稿与下发机制；本次不新建网络接口，不改变既有底层存储异常处理。菜单和图片数据源异常仍使用公共选择器提示。

## 操作前后条件与测试算例

| 场景 | 输入／前置 | 预期 |
|---|---|---|
| 空名称 | 名称仅空格 | 显示必填提示、聚焦输入，分类与菜单均不写入，抽屉保持。 |
| 编辑保留菜单 | A 已引用 B，修改 A 名称 | A 的引用仍为 B；可下单和仅查看菜品结构不变。 |
| 菜单切换 | 仅查看选择 B → 可下单 → 仅查看 | B 仍选中；保存同时采集两面板；取消恢复此前页面草稿。 |
| 分类计数 | 有效引用 B / C | 摘要“按分类 · 2 个分类 · 配置”；不得标为 2 道菜。 |
| 零配置 | 当前模式对应集合为空 | 显示未配置与去配置入口，不隐藏操作。 |
| 组合筛选 | 名称包含午餐、渠道 emenu | 仅显示同时满足两条件行；清空名称不清空渠道。 |
| 删除引用 | A 仅查看引用 B，删除 B | 移除 B、B 菜单映射和 A 对 B 引用；A 的其他数据与商品源不变。 |
| 删除取消 | 已打开 B 删除确认 | 不写入草稿、不删除列表行。 |
| 子页面切换 | 列表产生草稿 → 设置 → 列表 | 使用同一桶读取；不要求中途下发。 |
| 放弃草稿 | 原值无引用，草稿新增 B 引用 | 确认放弃后引用恢复空，持久数据未提前写入。 |

- CLASSIFICATION-Q03：菜单模式适用终端目前仅 eMenu／SDI；单分类展示渠道为 Kiosk／eMenu／POS／SDI。不得由此推断四种终端消费行为一致。
