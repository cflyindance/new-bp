# TipOut · 不打卡 + 按工时分配 · 明细工时录入设计方案

> **模块**：TipOut → 小费分配明细 → 员工行字段  
> **版本**：v1.0  
> **日期**：2026-07-24  
> **状态**：已落地  
> **方案**：方案 1 · 仅明细页 UI 联动  
> **主要落点**：`dist/TipOut/detail.html`

---

## 一、背景与目标

### 1.1 场景

小费池规则中，当同时满足：

- **员工打卡方式** = `不打卡`（`clockin: noclock`）
- **小费分配方式** = `按工作时长占比分配`（`distribution: hours`）

因无打卡数据，无法自动得到工时。需在**小费分配明细**中由用户手工录入每位员工的工时，再据此计算分配比例与金额。

### 1.2 目标

1. 在明细表【员工分配比例】左侧新增可编辑【工时】列  
2. 改工时自动重算同角色员工分配比例，金额跟比例走  
3. 比例仍可手改；再改工时时**始终覆盖**手改比例  

### 1.3 非目标

- 不改 `rule-add` 规则配置字段 / 数据模型  
- 不从打卡、排班自动带出工时  
- 不抽离到 `tipAllocation.js` 计算引擎  
- 不做工时与原始打卡双向同步  
- 本期不改「计提小费占比分配」订单小费卡片表结构（仅动 legacy 小费池汇总明细卡）

---

## 二、触发与展示

| 条件 | 【工时】列 |
|------|-----------|
| `clockin === 'noclock'` 且 `distribution === 'hours'` | **显示** |
| 其它组合 | **不显示**，行为与现网一致 |

**列顺序**：`分配员工` → **`工时`** → `员工分配比例` → `员工分配金额` → `操作`

---

## 三、交互与公式

### 3.1 字段

| 字段 | 可编辑 | 单位 / 约束 |
|------|--------|-------------|
| 工时 | 是 | 小时，小数（如 `7.5`），`≥ 0` |
| 员工分配比例 | 是 | 百分比，与现网一致 |
| 员工分配金额 | 否 | 由比例推算 |

### 3.2 公式（同角色 / 同一员工表内）

**改工时触发：**

```text
比例ᵢ = 工时ᵢ / Σ工时 × 100%
（Σ工时 = 0 时，各行比例 = 0）
```

**金额始终（与现网一致）：**

```text
金额ᵢ = 角色分配金额 × 比例ᵢ / Σ比例
```

### 3.3 交互矩阵

| 操作 | 工时 | 比例 | 金额 |
|------|------|------|------|
| 修改工时 | 写入 | **按工时重算（覆盖手改）** | 跟新比例重算 |
| 修改比例 | 不变 | 手改写入 | 跟新比例重算 |
| 改角色比例 / 池金额 | 不变 | 不变 | 按现有比例重算 |

### 3.4 示例

角色分配金额 `$100`，Alice 工时 `6`、Bob 工时 `10`：

| 员工 | 工时 | 比例 | 金额 |
|------|------|------|------|
| Alice | 6 | 37.5% | $37.50 |
| Bob | 10 | 62.5% | $62.50 |

---

## 四、边界

| 情况 | 处理 |
|------|------|
| 工时空 / 非法 | 按 `0` |
| 同角色 Σ工时 = 0 | 比例全 0，金额全 `$0.00` |
| 首次渲染 | 工时默认 `0`（或空），**不**自动按工时重算比例；沿用现网种子比例，仅用户改工时 / 删行后才按工时重算 |
| 新增行 | 工时默认 `0`；之后改工时按合计重算全员比例 |
| 删除行 | 若处于工时模式，按剩余行工时重算比例与金额 |
| 非触发条件 | 不渲染工时列，不改现有逻辑 |

## 五、实现要点

落点：`dist/TipOut/detail.html`

1. `buildLegacyDetailCardHtml`（及新增行逻辑）：按 `rule.clockin` / `rule.distribution` 条件渲染 `<th>工时</th>` 与可编辑输入框（建议 `class="detail-emp-hours-input"`，单位旁可标 `h`）  
2. 新增 `onEmpHoursChange(tableId)`：读同表各行工时 → 写回比例 → 调用现有金额重算  
3. 修正 `recalcDetailLegacyCard`：勿用笼统 `td.input-cell input` 把工时误当比例；改为按 `detail-emp-pct-input` / `detail-emp-hours-input`（或等价选择器）区分  
4. `addDetailRow` / `removeDetailRow`：在工时模式下同步列结构；删行后若处于工时模式可按工时重算比例  

可选（非必须）：规则详情页提示「不打卡且按工时分配时，请在明细录入工时」。
