# 限购数量步骤 · 场景条交互设计方案

> 状态：已确认  
> 日期：2026-07-23  
> 范围：`admin-web/dist/Configuration center/order-limit.html` 新建/编辑规则向导 · 第 3 步「限购数量」  
> 选定方案：**B · 场景条 + 产线 Tab**

## 1. 背景与目标

当前限购数量步骤采用「子向导」：先设置人数/轮次维度，再通过三个下拉切换「人数 × 轮次 × 产线」填写数量。差异配置是常态时，切换成本高、上下文易丢失。

**目标**

- 按「场景」填数：先锁定人数（× 轮次），再填商品
- 产线与人数/轮次同等重要，可快速切换
- 一眼看到各场景完成度，并支持复制到其他场景
- 去掉限购数量内部的子步骤向导

**非目标**

- 不改规则数据模型语义（仍为：选品共享；数量按人数区间 × 轮次 × 商品键）
- 不改向导总步骤顺序（规则类型 → 详细配置 → 限购数量 → 时间 → 会员 → 确认）
- 不做商品维度矩阵大表（非本次偏好）

## 2. 用户偏好（调研结论）

| 问题 | 结论 |
|------|------|
| 配置形态 | 按人数/轮次差异配置是常态 |
| 填数思路 | 以场景为主（先锁人数+轮次，再填商品） |
| 产线 | 与人数/轮次同等重要，经常切换 |

## 3. 信息架构（单页）

限购数量步骤一页完成，结构自上而下：

1. **配置场景**：场景胶囊列表 +「编辑人数 / 轮次」
2. **产线 Tab** + 当前上下文提示条
3. **批量栏** + 商品数量列表
4. **附加限制**（非多轮时，与现逻辑一致）

### 3.1 场景胶囊

- **多轮**：每个胶囊 = `人数区间 × 轮次`，文案如 `1-3人 · 第一轮`
- **非多轮**：每个胶囊 = 人数区间，文案如 `1-3人`
- 点击切换当前场景（更新 `activePersonRange` / `activeRound`）
- 完成度状态（● / ◐ / ○，见第 5 节）直接显示在胶囊上
- 场景过多时横向换行即可；首版不做折叠，「显示全部」列为可选增强

### 3.2 产线 Tab

- 仅展示有选品的产线（Kiosk / eMenu / SDI）
- Tab 徽标数量 = 该产线已选商品/分类项数（与现下拉一致，不是「已填 >0 的个数」）
- 切换更新 `activeQtyLine`
- 与场景正交：换产线不改场景，换场景不改产线（若当前产线在新上下文无选品，回退到首个有选品产线）

### 3.3 当前上下文

固定提示：`正在编辑：{人数} · {轮次?} · {产线}`，避免填错场景。

## 4. 维度编辑

点击「编辑人数 / 轮次」打开面板（页内展开或轻量弹层均可，优先页内展开以免双层弹窗）：

- **人数区间**：现有增删改校验（不可重叠；`99` 表示及以上）
- **轮次**：仅 `multiRound` 显示；增删轮次；删除时同步裁剪各区间的 `roundQuantities`
- **完成**：校验通过后把草稿写回 draft，关闭面板并重建场景胶囊；若当前场景被删，回退到第一个场景
- **取消 / 关闭**：丢弃面板草稿，不改 draft；编辑过程使用面板内本地草稿，点「完成」才提交，避免误删维度

## 5. 完成度

针对每个场景（人数 × 轮次）：

| 状态 | 条件 |
|------|------|
| ● 已配置 | 该场景下，**每一个**有选品的产线，都至少有一个商品数量 `> 0` |
| ◐ 部分产线 | 仅部分产线满足上述条件 |
| ○ 未配置 | 所有相关产线数量皆为 `0` / 空 |

说明：与向导「下一步」校验解耦——下一步仍只需「全规则至少一处 `> 0`」；完成度仅作进度提示。

> 注：若实现时发现「每个产线都要 >0」过严，可降级为「任一产线有 >0 即为已配置，部分=有产线未看过」。默认按上表实现。

## 6. 填写与批量

- 列表仅展示当前产线商品/分类（与现一致）
- 勾选 + 批量数量 +「应用到所选」
- `0` 表示该场景下不可点（与现语义一致）

## 7. 复制到其他场景

入口：批量栏旁「复制到其他场景…」

- 列出其他场景（排除当前）
- 勾选目标；默认勾选「仅复制当前产线」
- 取消该勾选则复制该场景下全部产线的数量映射
- 确认文案：**复制并覆盖**（目标已有值直接覆盖）
- 复制内容：对应 `quantitySettings`（及多轮时当前/全部 `roundQuantities` 条目）

## 8. 校验与边界

| 时机 | 规则 |
|------|------|
| 编辑维度完成 | 人数区间合法；多轮至少 1 个轮次 |
| 向导离开第 3 步 | 名称/选品已在第 2 步校验；本步：`validateDraftStep3`（至少一处数量 > 0） |
| 无选品 | 提示回第 2 步选商品（正常流不应出现） |
| 单人数 + 非多轮 | 仅 1 个场景胶囊，仍显示场景区以保持心智一致 |

## 9. 数据与实现约束

- **保持**现有 draft 结构：`personRanges[].quantitySettings` / `personRanges[].roundQuantities[].quantitySettings`
- **移除**限购数量内部 `qtyConfigStep` 子向导 UI 与相关「下一步：填写数量 / 返回设置维度」
- 场景列表为派生视图：`personRanges × rounds`（非多轮则仅 personRanges）
- 事件：场景点击、产线 Tab、编辑面板、复制弹层；写入仍走 `setQtyValue` / `getQtyMap`

## 10. 交互对比（相对现状）

| 现状 | 方案 B |
|------|--------|
| 子向导两步 | 单页 |
| 三个下拉切换上下文 | 场景胶囊 + 产线 Tab |
| 无进度 | 场景完成度 |
| 无跨场景复用 | 复制到其他场景 |

## 11. 验收要点

1. 进入限购数量步骤即可直接看到场景胶囊与商品列表，无需点「下一步：填写数量」
2. 切换场景 / 产线后，数量输入绑定正确组合
3. 编辑人数/轮次后场景列表与数据一致；删除维度不残留无效数量
4. 完成度随填写变化正确刷新
5. 复制到其他场景可覆盖目标；「仅当前产线」开关生效
6. 附加限制仍在本步底部（非多轮）
7. 回归：保存规则、编辑回显、模拟器按人数命中区间
