## 实现范围

共用本地日志键，两类入口按模块隔离；操作记录列表支持查询、重置、分页和详情；菜单、项目、页面提供对象记录链接。日志写入失败保留会话记录、显示警告，不回滚已成功业务。注册中心写入阶段为本地保存，不声称发布。

菜单结构操作按同步批次合并；普通编辑以保存或发布提交为记录边界。菜单导入原入口缺少处理，已补齐 JSON 校验、覆盖确认和兼容节点保护；导入只改编辑配置，未自动发布。导出记录浏览器导出触发，不证明用户已将文件写入磁盘。
