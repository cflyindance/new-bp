## 导航规格

员工打卡改为可展开父菜单，下设打卡管理、考勤记录、规则设置，沿用角色与员工折叠模式。父菜单整行点击仅展开/收起，不改变当前页面；子菜单整行点击进入对应页面并高亮。移除页面顶部三个 Tab，标题显示当前页面名。规则设置保留保存并下发栏，其他两页不显示。各页筛选在页面会话内分别保留，不新增跨页同步和刷新持久化。切换页面关闭原页临时弹框；既有未保存配置离开保护继续适用。

旧 `/team/clock-in` 地址进入打卡管理，历史排班考勤记录入口进入考勤记录；子页支持直接访问、刷新恢复页面类型与浏览器前进后退。考勤字段、补卡、计算、权限和配置保存规则沿用现有定义，不由本次导航调整重新决策。

| 字段 | 逻辑说明 |
| --- | --- |
| team-clock | 父菜单；展开状态沿用现有侧栏组机制；不写考勤数据。 |
| team-clock-live | 打卡管理；/team/clock-in/live；状态 live。 |
| team-clock-records | 考勤记录；/team/clock-in/records；状态 records；保留云报表说明弹框。 |
| team-clock-rules | 规则设置；/team/clock-in/rules；状态 rules；继续使用 /team/clock-in 配置保存域。 |
| 页面类型 | 由 hash 路径末段推导；records、rules 各自对应，其余默认 live。 |
| 子项选中 | 当前子链接 aria-current=page；父菜单无页面选中态。 |
| 临时弹框 | 类型切换清空补卡、历史、休息弹框；不写业务数据。 |

## 验证与范围限制

TypeScript 检查通过；本地浏览器三项切换、子项高亮、规则页刷新恢复、Tab 移除及保存栏差异通过。未保存配置离开确认分支未在本次浏览器验证中覆盖。正常算例：点击 records，地址和高亮进入 records，无保存栏；边界算例：刷新 rules，仍在 rules 且保存栏存在；兼容算例：旧父路径进入 live。完整考勤历史字段、算法及真实后端不属于本次规格覆盖，不声称已补齐。

主分支集成校验：保留员工打卡既有入口权限键及 live/records/rules 视图权限键，二级导航不重置已有授权；权限目录仍由专用打卡注册器生成。TypeScript 检查通过；权限回归脚本被既有 /team/roles-employees 操作权限对应菜单缺失阻断，已在未修改的 origin/main 基线上复现，不报告权限回归通过。
