## 默认落地策略

![登录品牌首页](./images/demo-brand-default-20261023/brand-home.png)

图：65131已完成引导的隔离演示配置，非真实账号操作记录。

| 字段／过程 | 定义 |
|---|---|
| 适用账号 | getAuthenticatedEmail经trim／toLowerCase后等于DEMO_LOGIN_ACCOUNT，且非isViewSwitchRestricted代登录上下文。其他账号原逻辑不变。 |
| applyDefaultDemoBrandView | 仅演示展示策略：将应用壳改merchant，复用switchToBrandView完成chain布局、brand视角及合法品牌范围初始化。不修改currentMAccount、账号、角色、授权或业务记录。 |
| 登录成功 | 原syncSessionForAuthenticatedUser后，对适用演示账号先replaceHashPath('/home')，再初始化品牌视角，避免scope-change同步重绘仍在/login时重复初始化。非演示账号继续原M／引导／主页分支。 |
| 已认证访问/login | 同样先离开/login再应用品牌初始化，重绘进入原商家引导／首页处理。 |
| 根地址首次打开 | hash仅为空、#、#/、#/home、#/home/时适用；在初始mount前执行一次。已保存M／其他演示壳不作为此次根地址默认；页内手动切换不再次被此初始化覆盖。 |
| 明确路由 | 非上述根地址不强制品牌，不重写M／业务深链，原路由鉴权继续。 |
| 未认证／首次引导 | 不自动登录；不修改引导完成标志。需引导时品牌初始化后仍按原引导流程，不保证首次使用直接出现/home。 |
| 持久化 | 沿用演示视角既有sessionStorage视角／应用壳和localStorage布局设置，不新增账号或会话权限字段，不删除其他业务存储。 |
| 顺序与错误 | 仅在适用账号调用；原视角受限时不切换。沿用原初始化及数据读取错误处理，不把初始化成功当成权限授权。 |

![重新开根地址回品牌](./images/demo-brand-default-20261023/reopen-root.png)

验证：策略测试覆盖默认演示／真实账号／代登录；浏览器覆盖登录品牌、显式M、M后重开根及业务hash保留。类型及隔离Vite生产bundle构建通过；未构建或修改eMenu源码。真实账号完整登录、引导全流程及CI部署未重新验收。

| 字段或过程 | 定义 |
|---|---|
| DEMO_LOGIN_ACCOUNT | 固定字符串 demo.menusifu.cn，作为账号输入框 value。 |
| DEMO_LOGIN_PASSWORD | 沿用固定演示密码 Menusifu666，作为 password 输入框 value，掩码展示。 |
| 账号校验 | trim 后为空则失败；忽略大小写等于指定演示账号，或通过既有企业邮箱校验，才继续密码校验。不得放开任意非邮箱账号。 |
| 密码校验 | 受维护账号沿用启用状态及其密码验证；其他受支持账号必须匹配现有演示密码。密码不 trim。 |
| 提交成功 | 沿用sessionStorage会话与实际账号登录日志。默认演示使用上节品牌落地；其他账号进入既有M／引导／主页分支。 |
| 提交失败 | 展示校验错误，焦点移到密码框，不写入认证会话，不跳转。 |
| 页面重建 | 重新产生默认 value；不把用户编辑过的密码另行写入存储。 |

测试算例：指定账号+默认密码成功；指定账号+错误密码失败；demo@menusifu.cn+默认密码成功；任意非邮箱账户失败；空账户失败；清空密码失败。首次显示时不产生自动登录，点击按钮才提交。
