| 字段名称 | 所属类别 / 模块 | 定义 / 计算公式 |
| :--- | :--- | :--- |
| **总销售额** | 销售总额 | 以发票价格计算的销售总额，不减扣折扣、折价、退货、回扣或进行其他调整（因POS加收设定各家不同，此处也不含加收的额度）。 |
| **免税销售额** | 税前营业额构成 | 在经营中部分符合资格的商品可能拥有免税的优惠，此销售额含在销售总额中，但在计算税务时不会被含入。 |
| **订单加收**（整单加收） | 税后营业额构成 | 所有整单加收的总额。由于商家对于加收用途及设定不尽相同（可能用于小费、调味加价等），此处加收总额**不会**放进销售总额中，若有税务计算需另外依用途加上。 |
| **菜单加收**（单品加收） | 税后营业额构成 | 所有单品加收的总额。由于商家对于加收用途及设定不尽相同（可能用于小费、调味加价等），此处加收总额**不会**放进销售总额中，若有税务计算需另外依用途加上。 |
| **小费** | 其他应收款项 | 包括系统中有记录的现金、信用卡及其他小费，已扣除信用卡手续费。 |
| **预支付卡存款金额**（预付卡押金） | 独立款项 | 所有预付卡押金的总和（如礼品卡、会员卡等），这个数额**不会**被计算在销售之中，应独立处理。 |
| **预支付卡存款折扣**（预付卡充值享折扣） | 独立款项 | 购买礼品卡时可享受的优惠折扣。 |
| **应收金额** | **最终应付款项合计** | 周期内商家实际应收取的全部款项总额。<br>**公式** = `税后营业额 + 加收（订单加收+菜单加收） + 小费 + 实际预支付卡存款金额` |
| **订单数量** | 统计口径 | 统计周期内的总订单数。**注意**：购买预付卡（礼品卡）不计入总点单数。 |
