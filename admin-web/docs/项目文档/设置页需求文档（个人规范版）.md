## 设置页 / 未保存离开确认

待补页面图片：真实编辑未保存的确认弹框；本次未宣称截图覆盖完整。

用途：保护当前保存范围内真实编辑且尚未保存的数据。仅查看页面后离开不弹出。

| 字段或操作 | 逻辑说明 |
|---|---|
| 触发条件 | 存在净业务差异且切换到其他保存范围。初始化、补默认值、同步兼容迁移不算编辑；恢复原值后不提示。 |
| 标题 | 离开未保存页面。 |
| 提示正文 | 当前页有未保存的设置，离开将丢失修改。确定离开吗？ |
| 取消 | 留在原页，保留未保存编辑。 |
| 确认离开 | 放弃原页草稿，进入请求的目标页面。 |
| 重新渲染 | 保留已有草稿及净变更，不将草稿写为已保存值。 |

本次仅修复公共同步初始化误报；独立页面异步脏状态探针仍需对应验证。
