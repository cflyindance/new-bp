# 限购数量 · 场景条交互 · 实现计划

> **依据**：`docs/项目文档/限购数量-场景条交互设计方案.md`  
> **日期**：2026-07-23  
> **主文件**：`dist/Configuration center/order-limit.html`

## 任务拆分

### 1. 清理子向导

- 删除 `qtyConfigStep`（`createEmptyDraft` / `ruleToDraft` / `wizardNext` 进入第 3 步时的赋值）
- 删除 `renderQtySubStepsHtml`、`renderQtyDimensionStepHtml`、`renderQtyContextBarHtml`（三下拉）
- 删除 `data-qty-config-next` / `data-qty-config-prev` / `data-qty-ctx-*` 事件
- 清理仅服务子向导的 CSS（`.qty-sub-steps` 等；可保留可复用的 `.qty-step-actions` 若编辑面板仍用）

### 2. 场景派生与完成度

新增工具函数（均基于现有 `personRanges` / `rounds`，不改存储模型）：

| 函数 | 职责 |
|------|------|
| `listQtyScenes(draft)` | 派生场景列表：`{ personIndex, roundIndex\|null, label }` |
| `getSceneQtyMap(draft, scene)` | 临时切 active 后取 map，或直接读对应 `quantitySettings` |
| `sceneHasQtyOnLine(draft, scene, lineId, method)` | 该场景×产线是否存在 `>0` |
| `getSceneCompletion(draft, scene, lineOpts, method)` | 返回 `done` / `partial` / `empty` |
| `resolveSceneSelection(draft)` | 保证 `activePersonRange` / `activeRound` 落在合法场景 |

完成度规则按设计 §5（全产线有 >0 → done；部分 → partial；全无 → empty）。

### 3. 单页 UI 重建 `renderQtySectionHtml`

自上而下渲染：

1. **场景区**：胶囊（label + 完成度）+「编辑人数 / 轮次」按钮；`data-qty-scene` 绑定 `personIndex` + `roundIndex`
2. **产线 Tab**：复用/恢复 `qty-line-tabs`（徽标 = 该产线已选项数）
3. **上下文条**：`正在编辑：…`
4. **批量栏**：全选 / 清空 / 批量数量 / 应用到所选 +「复制到其他场景…」
5. **商品列表**：现有 `qty-row2` 逻辑，仍用 `getQtyMap` / `setQtyValue`

`renderStepQuantity` 不变：外包「限购数量」区块 + 非多轮「附加限制」。

### 4. 维度编辑面板（本地草稿）

- draft 增加临时态：`dimEditorOpen`、`dimEditorDraft`（深拷贝 `personRanges` + `rounds`）
- 打开：拷贝当前维度进 `dimEditorDraft`，展开页内面板（优先 `#wQtySection` 内折叠块，避免双层弹窗）
- 面板内增删改只改 `dimEditorDraft`；「完成」跑 `validatePersonRanges` + 多轮至少 1 轮 → 写回 draft → `ensurePersonRangesShape` → `resolveSceneSelection` → 关闭
- 「取消」：关面板，丢弃 `dimEditorDraft`
- 删除轮次时在草稿上裁剪 `roundQuantities`（与现 `round-del` 一致）

### 5. 复制到其他场景

- 轻量弹层/页内面板：`copySceneOpen`、目标场景多选、`copyCurrentLineOnly`（默认 true）
- 确认「复制并覆盖」：
  - 仅当前产线：按当前产线可见 `qtyKey` 从源场景 map 拷到目标场景对应 map
  - 全部产线：对该场景下所有有选品产线的 key 做同样覆盖
- 多轮：写入目标 `personRanges[i].roundQuantities[j].quantitySettings`；非多轮写 `quantitySettings`
- 完成后 Toast + 刷新完成度

### 6. 事件接线

| 选择器 / 动作 | 行为 |
|---------------|------|
| `[data-qty-scene]` | 设 activePerson/Round，清 selectedQtyKeys，`refreshStructureQtyUi` |
| `[data-qty-line]` | 设 activeQtyLine（已有则可复用） |
| `[data-dim-edit-open]` / 完成 / 取消 | 打开/提交/关闭维度面板 |
| 维度面板内 min/max、加减区间/轮次 | 只改 `dimEditorDraft` 并重绘面板区 |
| `[data-qty-copy-open]` / 确认 / 取消 | 复制面板 |
| 原批量 / `data-qty-key` | 保持；写入后刷新场景完成度（可整段 `refreshStructureQtyUi`） |

移除对已删子向导控件的监听。

### 7. 样式

- 新增：`.qty-scene-bar`、`.qty-scene-chip`、`.qty-scene-chip.active`、完成度色点、`.qty-context-hint`、维度/复制面板容器
- 产线 Tab 样式若已删则恢复与现网一致的 pill Tab
- 不引入新依赖

### 8. 冒烟验收（对照设计 §11）

1. 进第 3 步即见场景胶囊 + 列表，无「下一步：填写数量」
2. 切场景 / 产线后数量绑定正确
3. 编辑维度完成/取消行为正确；删维度无脏数据
4. 完成度随填写变化
5. 复制覆盖 +「仅当前产线」开关
6. 附加限制仍在底部（非多轮）
7. 保存 / 编辑回显 / 模拟器按人数命中

## 建议实施顺序

`1 清理` → `2 工具函数` → `3 主 UI` → `6 基础事件（场景+产线）` → `4 维度面板` → `5 复制` → `7 样式打磨` → `8 验收`

## 完成定义

- 限购数量步骤为单页「场景条 + 产线 Tab」，数据模型与校验语义不变
- 维度编辑带本地草稿；支持跨场景复制覆盖
- 设计文档 §11 七条验收通过
