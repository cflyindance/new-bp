版本：V1.1；日期：2026-11-03；共同变更编号：STANDALONE-BACK-20261103-01。
共同业务基线：全项目原生独立页面公共页头；起始 main@c3dee8cb。
配套：[产品权威 V1.1](独立页面头部布局产品权威需求文档.md) · [研发交付 V1.1](独立页面头部布局业务规格说明书（研发交付版）.md) · [个人规范 V1.1](独立页面头部布局需求文档（个人规范版）.md)。
状态：本地原型；不改变各业务原有权限、保存、发布和草稿规则。

## 渲染契约

实现入口：`src/ui/standalone-page-header.ts`；样式由 `src/styles/app.css` 引入。纯模板函数不读取存储、不自动搜索页面、不搬动 DOM，也不触发业务事件。

| 参数/节点 | 类型与约束 |
| --- | --- |
| titleHtml | string，必填；可信模板，动态对象名称必须由调用模块转义；采用原对象字段，不保存新数据 |
| backHtml | string，可选；明确传入单个原按钮/链接；统一图标内容与样式，保留原标签、href、data-*、类型及可访问语义；独立子页提供主返回 |
| actionsHtml | string，可选；空值不生成操作组；保留原条件、禁用状态、事件标识和顺序 |
| subtitleHtml | string，可选；原副标题/状态；空值不生成副标题区 |
| level | 1 或 2，可选，默认1；与页面原有标题层级相符 |
| className | string，可选；内部固定样式类，不接收外部任意文本 |
| DOM顺序 | 返回、标题/副标题、操作；视觉位置与键盘顺序一致 |
| data-standalone-page-header | 共享页头定位标识，不作为权限字段 |

## 返回图标渲染

明确的返回槽只接收单一a或button时替换内部展示为装饰SVG；原标签和属性保持，业务类保留并增加standalone-back-control。SVG为20×20，路径M19 12H5m7-7-7 7 7 7，stroke-width=1.8，aria-hidden=true、focusable=false。缺少非空aria-label时以原返回文本补充，无文本回退“返回”；aria-labelledby仍保留，title不作为唯一命名。异常/多控件槽原样输出，不扫描页面DOM。

按钮48×48px、圆角12px，无可见边框/阴影，背景rgba(0,0,0,.04)，图标rgba(0,0,0,.45)；悬停背景rgba(0,0,0,.08)。焦点可见轮廓，原disabled保持；暗色采用浅色半透明背景/图标。标题首行与操作区最小高度48px，对齐箭头中心，窄屏仍按公共规则换行。

## 提交与状态

员工工作台使用两个稳定动作槽，按配置模式/当前维度切换，生效权限两槽隐藏；M保存绑定工作台原保存处理，商户保存通过actionsHost与原内容根共用同一个处理函数，直接绑定且不代理点击；原确认及独立保存边界保持。

硬件各表单使用唯一 `standalone-<原表单标识>` id，页头 `type=submit` 按钮通过 `form` 属性关联；提交仍走原 form 的 submit 处理，保留 novalidate 及原业务校验。取消/返回保留原标识与草稿保护。不得把按钮移动至无法收到原委托事件的根节点外。权限编辑保存和预览仍由原根节点处理，底部仅保留原状态提示。向导最终提交仍由原提交标识处理，步骤上一页/下一页不迁移。

无新增存储字段、金额、单位、公式、数据范围或状态枚举；授权计算、并发、持久化失败和业务回退由各业务规则负责。展示调整不写入业务数据；已有未保存状态、确认成功/失败/取消后果均保持原规则。

| 算例/边界 | 预期 |
| --- | --- |
| 未修改权限 | 页头保存按原条件禁用；返回可用 |
| 编辑/效果预览切换 | 右侧操作切换模式，左侧主返回不重复 |
| 表单外保存 | button.form 指向当前原表单，原 submit 处理被调用 |
| 必填错误 | 仍由原校验提示，不写入无效记录 |
| 草稿返回后取消离开 | 留在当前页，保留草稿 |
| 未获操作权限 | 同一业务按钮继续禁用/隐藏，不新增权限 |
| 对象不存在 | 展示错误信息，主返回仍位于标题左侧 |
| 窄屏长标题 | 标题可换行，操作组右对齐、不覆盖返回 |
