# 支付中心 · 设置「双重定价」只读拆分

> **版本**：v1.0 · 2026-07-14  
> **状态**：已确认，实施中  
> **关联**：卡交易与附加费用语义重设计（原 454∪543 三选一）本方案在其之上修订

## 1. 决策摘要

| 项 | 结论 |
|----|------|
| 分组 | 仍在「卡支付规则与合规」`card-fees` 内，拆成**独立配置行** |
| 启用权 | **上游决定**；设置页不可打开/关闭双重定价 |
| 百分比 | 仅展示上游同步值，**不可编辑** |
| 与 454 策略行 | 双重定价生效时，**隐藏**「卡加价策略」行 |

## 2. Catalog

| seq | 标题 | 行为 |
|-----|------|------|
| **454** | 双重定价 | 只读百分比；未开通显示 `/` |
| **543** | 卡加价策略 | 仅「不加价 / 整单加收」+ 可编辑比例；DP 生效时不渲染该行 |

## 3. 数据

- 双重定价费率：`dual-pricing-upstream` Snapshot（demo 种子；后续接 SFDC→任务→配置）。
- 卡加价策略：继续用 `454-card-pricing-strategy` JSON，**mode 仅 `none` \| `surcharge`**。
- 遗留 `mode: dual-pricing` 或旧 `454-dual-pricing-percent`：若 Snapshot 无开通，映射为 `none`，不在设置页保留可编辑 dual。

## 4. UI 文案要点

- 双重定价行：说明费率来自上游同步；卡付价 = 现金价 × (1 + 比例)。
- 未开通：`/` + 「由上游系统同步至商家后台后展示」。
- 卡加价策略：去掉「双重定价」单选项。

## 5. 验收

1. `card-fees` 可见「双重定价」独立行，百分比不可改。
2. 种子开通门店：只见双重定价行，不见「卡加价策略」。
3. 未开通门店：两行都在；双重定价为 `/`；策略仅不加价/整单加收。

## 6. 上游同步演示（设置页按钮）

| 按钮 | 场景 | 费率展示 | 543 行 |
|------|------|----------|--------|
| 模拟：上游未配置 | 上游无 Dual Pricing | `/` | 显示 |
| 模拟：同步失败 | 上游已有费率，落库失败 | `/` + 失败说明 | 显示 |
| 模拟：同步成功并下发 | 落库成功 | 百分比只读 | 隐藏 |

同步成功后系统自动创建配置域 `payment.card-pricing` 的下发批次，可在「下发记录」查看；行内展示最近 `batchId` 链接。
