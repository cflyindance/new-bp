# 配置变更预览 · 层级对比可读化 · 实现计划

> **依据**：`docs/项目文档/配置变更预览-层级对比可读化设计方案.md`  
> **日期**：2026-07-22

## 任务拆分

1. **类型扩展** — `deployment-types.ts` 增加 `ChangeDetailRow`、`groupPath`、`details`
2. **可读化核心** — `deployment-change-buffer.ts`：禁止 JSON 直出；通用对象/数组拆字段；摘要拼接；`details` 按 key 判等与合并
3. **写入侧** — `module-settings-deployment-change.ts`：专用格式器产出 `details`；解析 `groupPath`
4. **预览渲染** — `deployment-change-preview.ts`：导航分组 + 卡片 + 逐行对比；旧数据回退
5. **消费者对齐** — `page-save-confirm-dialog.ts` / `deployment-ui.ts` 复用同一预览
6. **冒烟验收** — 对照设计文档 §八 验收点自检

## 完成定义

- 确认变更与变更记录同构展示层级 + 逐行对比
- 界面无默认 JSON 原代码
- 旧历史记录可回退、缓冲合并不误丢变更
