## 导航对象与状态

| 字段 | 逻辑说明 |
|---|---|
| 父菜单 | `team-shifts`，路径 `/team/shift-scheduling`；沿用父项身份，点击展开／收起，无业务写入。 |
| 排班表 | `team-shifts-schedule`，路径 `/team/shift-scheduling/schedule`，映射 `schedule` 面板；根地址默认重定向至此。 |
| 班次 | `team-shifts-types`，路径 `/team/shift-scheduling/shifts`，映射 `shifts` 面板。 |
| 规则设置 | `team-shifts-rules`，路径 `/team/shift-scheduling/rules`，映射 `rules` 面板。 |
| 当前面板 | 字符串枚举 `schedule / shifts / rules`，从 hash 路径读取；刷新依据地址，不依赖临时页签记忆。 |
| 保存键 | 三个地址均归一为 `/team/shift-scheduling`，沿用草稿、下发与变更记录。菜单切换不写业务数据。 |
| 临时状态 | 子页面变化时关闭班次编辑、删除确认及员工筛选浮层，清空浮层搜索词；未提交弹框不产生业务写入。 |

权限和模块归属继承原排班入口，本次不新增权限决策。计算、精度、接口字段和后端错误处理不受本次导航调整影响。

## 验收与验证

1. 旧根地址自动到排班表，展示员工日期表。
2. 点击班次显示班次列表；刷新 `/shifts` 保留列表。
3. 点击规则设置显示打卡依赖排班开关；刷新 `/rules` 保留规则面板。
4. 点击排班表返回日期表，左侧仅对应项选中；顶部旧 `data-shift-tab` 数量为 0。
5. 父项收起／展开只改变菜单可见性，子项整行可点击。

已执行 `npx.cmd tsc --noEmit` 和真实浏览器前三项、第四项页面切换验证。历史完整班次计算、所有弹框字段和保存异常未在此次重新验收，仍以产品原有有效章节为基线。
