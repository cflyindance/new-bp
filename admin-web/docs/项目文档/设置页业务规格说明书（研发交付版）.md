# 设置页业务规格说明书（研发交付版）

版本 v1.0 · SAVE-20261016-01 · 2026-10-16 · 基线 main@04f22aa5。
产品权威：[批量保存设计方案](./设置页-按页面批量保存与下发设计方案.md) v1.3；[个人规范](./设置页需求文档（个人规范版）.md) v1.0。
本次范围仅为既定未保存保护的初始化误报修复，其他保存和下发规则沿用产品权威。

| 对象或字段 | 定义与处理 |
|---|---|
| 初始化作用域 | 每次同步 mount 进入，结束或异常时释放；支持嵌套，不依赖历史访问次数。异步回调不自动处于该作用域。 |
| 初始化字段写入 | 无已有草稿时允许持久化默认值或兼容迁移；已有草稿时不得覆盖草稿或将其持久化。 |
| 页面变更记录 | 初始化作用域内忽略新增记录，保留此前的用户变更。实际事件编辑沿用字段差异合并。 |
| 未持久化的单选/复选默认值 | 以渲染时读取的默认值作为首次编辑比较基线，不能以用户刚选择的新值充当旧值；首次修改同样进入离开保护。 |
| 未保存判断 | 通用页使用净变更记录；具有业务脏状态探针的独立页面沿用该探针，不能用本修复宣称已覆盖其异步业务路径。 |
| 恢复原值 | 同一字段合并后 before=after 时移除记录；所有差异移除后不拦截。 |

验收：首次查看/三次重复查看无变更；编辑后离开提示；编辑后重渲染仍提示且草稿未落盘；恢复原值不提示；渲染异常后真实编辑仍产生变更。取消离开不丢草稿，确认离开执行原有放弃流程。
未闭合：各独立业务探针、异步迁移尚不能视为全量覆盖。
