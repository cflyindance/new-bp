## 一、背景与范围

### 1.1 背景

订单中心滑层将新增 **订单列表** 业务页。美国餐馆场景下，列表需同时支撑：

- 日常查单（单号、状态、桌号/取餐号、服务员）
- 金额核对（小计、税、服务费、应收）
- 小费与实收核对（信用卡小费、现金小费、实收总额）
- 责任追溯（开单服务员、结账员）
- 连锁多店视角（门店列）

### 1.2 本期范围（A）

| 包含 | 不包含 |
|------|--------|
| 列表表头字段全集 | 滑层导航挂载与路由落地 |
| 中英列名 | 筛选、排序、分页交互 |
| 金额口径与计算公式 | 订单详情抽屉/页 |
| 默认显示 / 可选列划分 | 退款流水、支付拆分明细页 |
| 建议列序 | 列表汇总 KPI、导出模板 |

### 1.3 设计原则

| 原则 | 说明 |
|------|------|
| 小费与服务费分列 | Card Tip / Cash Tip 与 Service Charge（含 auto-gratuity 类强制加收）语义分离 |
| 应收不含小费 | Total Due 不含任何小费；小费只进入实收 |
| 责任人分列 | 开单服务员（Server）与结账员（Closer）分列，不合并 |
| 时间分列 | 开单时间与结账时间分列；未结账时结账时间为空 |
| 默认克制 | 第一屏默认列覆盖查单+金额+小费核心；其余进列设置 |

## 二、方案选择

曾评估三种表头组织方式：

| 方案 | 做法 | 结论 |
|------|------|------|
| 1 全量平铺固定列 | 全部字段默认全显 | 列过多，扫读成本高 |
| **2 核心默认 + 可配置扩展** | 默认露出高频列，其余可选 | **采用** |
| 3 语义分组表头 | 身份/金额/小费等分组展示 | 与现有表格组件契合度低，本期收益有限 |

**采用方案 2**：字段全集一次定稿；用「默认显示 / 可选」控制密度。

## 三、金额口径（锁定）

金额列之间的关系如下（单位：本单币种，通常为 USD）：

```text
菜品小计 (Subtotal)
  − 折扣金额 (Discount)
  + 税 (Tax)
  + 加收服务费 (Service Charge)
────────────────────────
应收总额 (Total Due)          ← 不含任何小费

应收总额
  + 信用卡小费 (Card Tip)
  + 现金小费 (Cash Tip)
────────────────────────
实收总额 (Total Collected)
```

### 3.1 字段定义

| 中文 | 英文 | 口径 |
|------|------|------|
| 菜品小计 | Subtotal | 菜品原价合计（含加料/改码加价），**未扣折扣**，未含税、服务费、小费 |
| 折扣金额 | Discount | 本单折扣合计，列表以**正数**展示减免额（`$0.00` 表示无折扣） |
| 税 | Tax | 本单 Sales Tax 等税额合计（含税项汇总；多税率时列表只显示合计） |
| 加收服务费 | Service Charge | 强制加收 / 自动服务费（含大桌 auto-gratuity 等**加收项**）；**不计入**信用卡小费或现金小费列 |
| 应收总额 | Total Due | `小计 − 折扣 + 税 + 加收服务费`；**不含**信用卡小费、现金小费 |
| 信用卡小费 | Card Tip | 通过卡支付会话收取的小费；无则为 `$0.00` |
| 现金小费 | Cash Tip | 现金小费（含补录）；无则为 `$0.00` |
| 实收总额 | Total Collected | 已结账：`应收总额 + 信用卡小费 + 现金小费`；未结账见 §3.2（固定 `$0.00`） |

### 3.2 边界说明

| 场景 | 处理 |
|------|------|
| 未结账 / 未收款 | **应收总额**按当前账单用 §3 公式计算；**实收总额固定 `$0.00`**（尚未收款）；小费列通常为 `$0.00`。§3 的 `实收 = 应收 + 小费` **仅对已结账/已收款订单生效** |
| 已结账 | 严格按 §3：`Total Collected = Total Due + Card Tip + Cash Tip`，并与支付落账字段一致 |
| 部分退款 | 列表金额展示**退款后的当前有效金额**（历史原额放详情，本期不展开） |
| 拆分支付 | 「支付方式」可选列做汇总文案（如 `Card + Cash`）；各通道拆分金额不进本期表头 |
| Service Charge vs Tip | 凡配置为加收/强制服务费的进 **加收服务费**；客人自愿小费进 **Card Tip / Cash Tip** |
| 折扣为 0 | 折扣列显示 `$0.00`，不隐藏列（可选列关闭时除外） |

## 四、表头字段全集

### 4.1 字段表

| 建议列序 | 中文 | 英文 | 字段 key（建议） | 默认显示 | 说明 |
|---------|------|------|------------------|----------|------|
| 1 | 订单号 | Order # | `orderNumber` | ✓ | 业务单号（对客/对账主键展示） |
| 2 | 订单状态 | Status | `status` | ✓ | 如：开单中 / 已结账 / 已退款等（枚举以产品字典为准） |
| 3 | 订单类型 | Order Type | `orderType` | ✓ | 堂食 / 外卖 / 自取等 |
| 4 | 桌号/取餐号 | Table / Pickup # | `tableOrPickupNo` | ✓ | 堂食为桌号；外卖/自取为取餐号；无则空 |
| 5 | 菜品小计 | Subtotal | `subtotal` | ✓ | 见 §3 |
| 6 | 应收总额 | Total Due | `totalDue` | ✓ | 见 §3 |
| 7 | 实收总额 | Total Collected | `totalCollected` | ✓ | 见 §3 |
| 8 | 信用卡小费 | Card Tip | `cardTip` | ✓ | 见 §3 |
| 9 | 现金小费 | Cash Tip | `cashTip` | ✓ | 见 §3 |
| 10 | 加收服务费 | Service Charge | `serviceCharge` | ✓ | 见 §3 |
| 11 | 税 | Tax | `tax` | ✓ | 见 §3 |
| 12 | 开单服务员 | Server | `serverName` | ✓ | Check owner / 开单服务员 |
| 13 | 开单时间 | Opened At | `openedAt` | ✓ | 订单创建时间 |
| 14 | 结账员 | Closer | `closerName` | 可选 | 完成结账的收银员；未结账为空 |
| 15 | 结账时间 | Closed At | `closedAt` | 可选 | 结账/关单时间；未结账为空 |
| 16 | 支付方式 | Payment | `paymentMethodSummary` | 可选 | 多支付时汇总展示 |
| 17 | 折扣金额 | Discount | `discount` | 可选 | 见 §3 |
| 18 | 人数 | Guests | `guestCount` | 可选 | 就餐人数 |
| 19 | 门店 | Store | `storeName` | 可选 | 连锁/多店视角；单店视角可默认隐藏 |

### 4.2 默认列 vs 可选列

**默认显示（13 列）**  
订单号、订单状态、订单类型、桌号/取餐号、菜品小计、应收总额、实收总额、信用卡小费、现金小费、加收服务费、税、开单服务员、开单时间。

**可选（6 列）**  
结账员、结账时间、支付方式、折扣金额、人数、门店。

列设置能力（勾选显隐、记忆用户偏好）属列表交互，**不在本期字段文档实现范围**，但字段方案预留「默认/可选」标记，供后续实现直接消费。

**首期列表页（尚无列设置时）**：只渲染 §4.2 **默认 13 列**；可选 6 列不展示。待列设置落地后再按用户勾选扩展。

### 4.3 展示约定（列表层）

| 类型 | 约定 |
|------|------|
| 金额 | 货币格式，保留 2 位小数；空/无记为 `$0.00`（非空字符串） |
| 时间 | 门店本地时区；格式建议 `MM/DD/YYYY HH:mm`（美式），以产品 i18n 为准 |
| 人员 | 展示员工显示名；已离职可保留历史名并加标记（实现期定） |
| 状态 / 类型 | 中英文随界面语言切换 |
| 门店 | 仅集团/品牌/多店视角有意义；纯单店账号可默认不勾选 |

## 五、与周边模块边界

| 模块 | 边界 |
|------|------|
| 订单中心 · 设置 | 管规则与策略（加收预设、折扣原因等），**不替代**本列表字段定义 |
| 前厅 · POS 找单 | POS 端找单列表可复用本口径，但列密度/默认集可按收银动线另定 |
| 支付中心 | 管支付通道、小费策略、税率配置；本列表只**展示落账结果** |
| 团队 · 小费管理 | 管小费分配规则与明细；本列表只展示单笔 Card/Cash Tip 原值 |
| 报表中心 | 聚合统计以报表字段为准；本列表为订单级明细视图 |

## 六、验收标准（本期文档）

1. 字段全集与 §4.1 共 19 列一致（默认 13 + 可选 6）。  
2. 金额公式：`Total Due` 不含小费；已结账时 `Total Collected = Total Due + Card Tip + Cash Tip`；未结账时实收固定 `$0.00`（§3.2）。  
3. Service Charge 与 Tip 分列，不混列。  
4. Server / Closer、Opened At / Closed At 均为分列。  
5. 每个字段有中英名、建议 key、默认/可选标记与列序。  
6. 首期无列设置时仅展示默认 13 列。
