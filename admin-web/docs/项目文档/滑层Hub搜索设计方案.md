# 滑层 Hub 搜索设计方案

> **模块**：前厅管理中心（`queue-call`）滑层 · 可复用至其他 `subNavPlacement: "sheet"` 管理中心  
> **版本**：v1.2  
> **日期**：2026-07-24  
> **状态**：已确认（搜索已复用至全部 sheet 滑层）  
> **主要落点**：`src/config/hub-sheet-search.ts`（新建）、`src/main.ts` → `renderNavModuleSecondarySheet`、主内容区搜索结果态

---

## 一、背景与目标

### 1.1 现状

点击「前厅管理中心」等一级入口后，二级功能在**侧栏滑层**内展示（`renderNavModuleSecondarySheet`）。设置项分散在多分组、多 seq，用户只能靠记忆点选导航，难以用关键词定位「功能入口」或具体「设置项 / 说明」。

### 1.2 目标

1. 在滑层标题下方提供搜索框  
2. 搜索范围覆盖本 Hub 内：**导航项 + 设置项 + 说明文案（sceneDesc 等）**  
3. 有关键词时：**左栏过滤导航**，**右栏主区展示结果明细**  
4. 点击结果：**跳转 + 展开设置分组 + 滚动定位**  
5. 首版仅启用前厅；索引与壳按**可复用**设计  

### 1.3 非目标

- 跨 Hub / 全站命令面板  
- 后端全文检索、拼音、编辑距离模糊、同义词库  
- 搜索历史 / 推荐  
- 首版键盘完整操作（↑↓ / Enter 可列为后续）  
- 修改 `ModuleSettingCatalogItem` 数据结构

## 二、方案定稿

**方案 1 · Hub 作用域索引 + 滑层搜索条**

| 对比项 | 方案 1（定稿） | 方案 2 仅过滤导航 | 方案 3 全局命令面板 |
|--------|----------------|-------------------|---------------------|
| 入口 | 滑层标题下搜索框 | 同左 | Ctrl/⌘K |
| 右侧 | 主区结果明细 | 无明细 | 浮层 |
| 范围 | 当前 Hub | 仅导航 | 全站 |
| 结论 | **采用** | 不满足深度搜索 | 超出滑层诉求 |

**布局定稿（布局 C）**：左过滤导航 + 右主区明细结果。

## 三、架构

```
┌─ SheetHubSearchShell（滑层壳）
│   · 标题下搜索框
│   · 有关键词 → 左栏过滤导航
│   · 清空 → 恢复完整导航
├─ HubSearchIndex（按 hub 构建）
│   · nav / setting /（可选）feature
└─ HubSearchResultsPane（主内容区）
    · 仅「搜索态」替换主区
    · 点击 → 跳转 + 展开 + 定位后退出搜索态
```

### 3.1 状态机

| 状态 | 左栏 | 右栏 |
|------|------|------|
| 空闲（无关键词） | 完整二级导航 | 正常业务页 |
| 搜索中 | 仅保留有命中的导航祖先/入口 | 结果明细列表 |
| 已选结果 | 清空关键词，恢复完整导航 | 落地目标页并定位 |
| 搜索态点左栏导航 | 清空关键词，恢复完整导航 | 打开该导航对应业务页（与点结果一致：离开搜索态） |

关闭滑层或切走 Hub → 清空关键词与搜索态。

### 3.2 启用范围

- 所有 `subNavPlacement: "sheet"` 的管理中心（通用壳 `renderNavModuleSecondarySheet`）
- 专用滑层壳：`marketing` / `promotions` / `members` / `gift-cards` / `reports-finance` / `print-templates` / `reservations` / `product-center-main` / `inventory-ordering` / `finance-center`

见 `isHubSheetSearchEnabled` / `DEDICATED_HUB_SHEET_SEARCH_IDS`。

```ts
// 通用：subNavPlacement === "sheet" → 启用
// 专用：DEDICATED_HUB_SHEET_SEARCH_IDS 白名单
```

## 四、交互设计

### 4.1 搜索框

- 位置：滑层标题栏（返回 + Hub 标题）**下方**  
- 占位符：`搜索功能与设置…`  
- 输入防抖约 **200ms**；清除按钮 / Esc 清空  
- 打开滑层时**不自动聚焦**  

### 4.2 搜索态

| 区域 | 行为 |
|------|------|
| 左栏 | 只保留「自身或子孙有命中」的导航项；设置命中时保留「设置」及关联入口 |
| 右栏 | 主内容区切换为结果列表（覆盖原业务页，非新窗口） |
| 结果行 | 标题（可含 seq）· 类型标签 · 路径面包屑 · 说明摘要（高亮命中词） |

**分组顺序**：功能入口 → 设置项 → 说明匹配（同组内按相关度，同分按标题）。

> **「说明匹配」不是独立索引 kind**：仍为 `nav` / `setting` 条目；当最高分命中字段为 `sceneDesc` / `moduleName` 时，展示归入「说明匹配」；命中 `title` / 导航名 / `seq` 等则归「设置项」或「功能入口」。title 与 sceneDesc 同时命中时按最高分字段分组（title 权重大于 sceneDesc，故归设置项/功能入口）。

### 4.3 点击结果

1. 写入目标 hash（设置项复用 `getModuleSettingsItemHref`）  
2. 设置项：打开对应分组 / 侧栏选中  
3. 滚动并短暂高亮目标控件（如 `data-seq`）  
4. **清空搜索关键词**，恢复正常导航与落地页  

### 4.3.1 搜索态点击左栏导航

与点击结果一致：**跳转该入口并清空搜索态**（右栏切回对应业务页，左栏恢复完整导航）。左栏不作为「仅过滤、不跳转」的纯筛选器。

### 4.4 空态与边界

| 情况 | 表现 |
|------|------|
| 无命中 | 右栏：「未找到与『关键词』相关的功能或设置」；左栏：「无匹配导航」+ 可一点清除 |
| 中文 | ≥1 个非空白字符即搜索 |
| 英文 / 数字 | ≥2 字符才触发查询（更短视为未进入搜索态） |
| 关闭滑层 | 清空关键词 |

## 五、索引与匹配

### 5.1 条目类型

| kind | 来源（前厅） | 可搜字段 | 跳转 |
|------|--------------|----------|------|
| `nav` | `NAV_MODULES` → `queue-call.children` | title / titleEn / path | 对应 path |
| `setting` | `MODULE_SETTINGS_BY_PATH["/operations/queue-call/settings"].items` | title、groupTitle、moduleName、feature、sceneDesc、seq、id | `getModuleSettingsItemHref` |
| `feature`（可选） | 功能页短描述 | 标题 + 描述 | 功能页 path |

首版：**nav + setting 必做**；无独立 feature 文案时用导航 title 即可。

### 5.2 作用域与可见性

- 绑定 `hubId` + `settingsPath`；只搜当前滑层 Hub  
- 平台预设 / 权限不可见的 L2 与设置项不进结果  

### 5.3 匹配规则

1. trim，大小写不敏感，包含匹配  
2. 权重（高→低）：title / 导航名 → seq 精确 → groupTitle / feature → sceneDesc / moduleName  
3. 多字段命中合并为一条，取最高分；摘要优先命中字段并高亮  
4. 左栏：setting 命中 → 保留祖先导航（如「设置」）  

### 5.4 模块 API（建议）

- `buildHubSearchIndex(hubId): HubSearchIndex`  
- `queryHubSearchIndex(index, q): HubSearchHit[]`  
- 与 AI 助手可共享 catalog 读取，**UI 状态独立**

## 六、实现约束

1. **新建**纯函数模块（如 `hub-sheet-search.ts`），便于单测  
2. 搜索 UI 挂在 `renderNavModuleSecondarySheet`；用 `hubSheetSearchEnabledIds` 控制启用  
3. 右栏结果与主区路由渲染协调（搜索态优先于业务页）  
4. 不改 catalog 生成物；只读现有数据  
5. i18n：占位符、空态、类型标签走 `t` / `pick`  
6. 无障碍：搜索区域 `role="search"`  

---

## 七、验收要点

1. 打开前厅滑层 → 标题下可见搜索框  
2. 搜设置标题（如「搜索菜单」）→ 右栏有结果，左栏保留设置相关入口  
3. 搜 sceneDesc 片段 →「说明匹配」，点击可跳转、展开分组并定位  
4. 搜导航名（如「品类管理」）→ 可进功能入口  
5. 无命中有空态；清空后恢复正常业务页  
6. 搜索态点击左栏某导航 → 打开对应页并清空搜索（与点结果一致）  
7. 其他滑层首版无搜索（开关关闭）  
8. 预设隐藏项不出现在结果中
