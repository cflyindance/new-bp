| 字段／操作 | 逻辑说明 |
|---|---|
| 登录按钮成功结果 | 默认演示账号进入品牌多门店视角，不自动选择M平台。仍须实际点击登录；账号密码校验、失败留页及日志不变。 |
| 项目根地址 | 已认证默认演示账号新打开空hash／#／#/／#/home／#/home/时回品牌；未认证显示登录。只在本次文档首次打开初始化，不在每次页面重绘重置视角。 |
| 首次引导 | 未完成配置时仍先显示原引导，不绕过、不自动保存；登录品牌默认不是跳过引导承诺。 |
| 手动M切换及明确M链接 | 保留原M权限校验和访问能力，本次不移除M、不扩权；显式M路径不强制改为品牌。 |
| 明确业务链接 | 不重写页面路径，不清空业务草稿。真实账号及代登录继续各自原落地和权限。 |

## 登录页 / 默认凭据状态

![登录页默认演示凭据](./images/demo-login-defaults-20261019.png)

图：功能分支 codex/demo-login-defaults-20261019，基于 main@0d922a6a，默认填充状态。
入口：未登录时访问商家后台，或退出后进入登录页。

| 字段或操作 | 逻辑说明 |
|---|---|
| 登录账号 | 默认 demo.menusifu.cn，可修改；清空后点击登录提示必填。还支持既有企业邮箱。 |
| 账号说明 | 说明当前为演示账号，并列明支持的企业邮箱格式。 |
| 密码 | 默认现有演示密码，掩码显示，可修改；错误或空密码均不能登录。 |
| 登录 | 用户点击才提交并执行原校验；默认演示按上节进入品牌视角及必要引导，其他账号沿用原落地；失败留在当前页面展示原因。 |
| 刷新或重新进入 | 恢复默认演示账号和密码，无需再次手工输入；不保存其他手工输入密码。 |
