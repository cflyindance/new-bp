## 下单规则 → 下单设置（VIEWONLY-DISH-FLOW-20261117-17）

入口：前厅管理中心 → 下单规则 → 下单设置。左侧固定展示“下单时间间隔、命中后授权、积分菜限制”分类导航；右侧各分类按 POS、PayPad、POS GO、eMenu、SDI 顺序展示浅灰产线容器与白色规则卡片。下单时间间隔分类内提供“订单间隔／商品间隔”场景页签；商品间隔页签先展示商品间隔规则列表，再展示各产线的间隔内加购设置。点击分类或 Enter 激活更新 /interval、/auth、/points 地址，右侧只显示选中分类；其他分类保留表单但隐藏，不参与阅读、焦点遍历或滚动。当前分类高亮，不随滚动跨入其他分类。切换时记住每个分类的滚动位置、已展开产线、订单／商品场景页签与输入值，不提交、不丢弃草稿。首次打开分类从顶部展示，根路径默认下单时间间隔；分类直达地址展示对应分类。权限配置中的三分类及九个资源保持，业务页卡片保留逐项资源标识。

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 产线名称 | 深灰胶囊展示产线；标题整行是展开按钮，右侧箭头表示展开／收起，不使用开关。首次每分类及订单／商品场景只展开POS，其余收起；支持多条同时展开。按门店、分类和场景记忆本次页面会话内的展开状态；刷新后重新默认。点击、Enter或空格仅改变展示，不修改启用值、不产生待保存变更。 |
| 产线摘要 | 标题行展示当前分类及场景的实际配置；收起时仍可见。订单间隔开启时显示分秒时长与加购策略，关闭时只显示订单间隔未启用；商品显示加购策略，命中后授权显示授权范围、有效范围及可看不可点菜行为，积分菜显示兑换授权和纯积分订单状态。修改后读取当前草稿即时更新，摘要继承对应规则展示权限。 |
| 订单下单时间间隔 | 每产线独立开关；关闭收起从属字段，保留数值。 |

### 多规则授权配置

![允许授权放行开启状态](assets/order-settings-20261117/viewonly-authorize.png)

图注：按产线设置授权范围和有效范围，开关关闭时保留配置但不展示从属字段。

| 组合 | 本次同时命中A、B | 本单后续命中A、B、C |
| --- | --- | --- |
| 逐条规则授权＋仅本次操作 | A、B分别授权 | A、B、C分别重新授权 |
| 合并授权＋仅本次操作 | 一次授权A、B | 再次合并授权A、B、C |
| 逐条规则授权＋本单内有效 | A、B分别授权 | A、B放行，仅C需授权 |
| 合并授权＋本单内有效 | 一次授权A、B | A、B放行，仅C需授权 |

“本次操作”指一次下单或加购触发的完整规则评估；合并只覆盖这次实际命中的待授权规则，不能提前授权未来规则。“本单内有效”按订单标识、产线、具体规则标识及规则版本匹配；订单结束、切换订单／产线、规则配置变化后，不复用不匹配的授权。

授权弹框的已确认口径：列出待授权规则及命中原因；合并按钮“授权并放行本次操作”，本单有效时提示已授权规则本单内免重复授权。合并授权人须拥有全部待授权规则的权限；不满足、密码错误、失败或取消时不整体放行，不新增成功授权记录。后续操作仅对未覆盖的规则请求授权。

配置映射：每产线 `authorizationScope` 为 `per-rule`／`combined`，`validity` 为 `operation`／`order`；均必填，缺省严格组合；`enabled`表示是否允许通过授权放行，新配置默认false，已有配置保留原值。旧 `auth-every` 迁移为逐条＋仅本次，旧 `auth-once` 迁移为逐条＋本单内已授权规则有效，不扩为未来规则。有效新字段优先；非法范围回到逐条，显式非法有效范围回到仅本次。旧mode仅保留时效兼容镜像，不能作为终端放行依据。

交付缺口：当前仓库实现配置页、本地草稿、保存与兼容读取；未发现实际点餐端多规则授权执行链。上表运行规则、规则版本授权记录、实际授权弹框、父开关关闭时拒绝授权且继续执行限制、不可授权规则校验、权限验证及失败处理均为已确认待接入／待验收，不能以后台选择保存成功声明终端已生效。消费方不支持两维策略时，不得用旧mode猜测放行范围。

| 返回按钮 | 左上箭头只退一层，首层子导航返回主导航；不回退业务地址，不保存、下发或修改业务数据。 |

| 深层父项 | 继续按同位置覆盖滑层下钻，不并排展开多层列表；返回逐层恢复。 |
| 可见菜单范围 | 沿用权限、订阅、发布和预设过滤；不新增授权。过滤后无子项不显示空下钻层。 |

| 刷新／切换模块 | 下钻路径仅保存于内存，刷新不恢复；业务页按地址定位。切换模块或关闭滑层清除旧层级。 |
