用途／入口：营销中心 → 营销广告 → 屏保 → 新建或编辑 → 选择门店 → 选择渠道。渠道范围卡片下方为独立展示位置卡片。

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 展示位置 | 必填多选组，固定提供屏保、首页两个选项；新建时均不勾选。与终端渠道分别选择，所选位置应用于本次所选渠道。 |
| 屏保 | 稳定值 screensaver；勾选加入本次展示位置，取消移除。 |
| 首页 | 稳定值 home；可独立选择或与屏保同时选择。 |
| 全选展示位置 | 仅作用于两个位置，不改变渠道选择。未全选时点击勾选全部；已全选时点击清空。只选一项时显示半选状态。 |
| 下一步 | 渠道至少一项且展示位置至少一项才可用；任一组清空后禁用。启用后进入原展示生效时间页，保留原 embedded 与 from 上下文。 |
| 返回／刷新回显 | 同一主题本次选择保留，显式清空也保留；切换主题不会读取另一主题的未保存位置。重新投放回显该主题已保存的位置。 |
| 历史记录 | 没有展示位置字段的记录回显为空，重新保存投放前须明确选择至少一个位置；不自动将历史记录批量改为首页或屏保。 |
| 保存 | 时间页在原时间与重叠校验外再次校验位置非空，空选提示“请返回选择渠道页，至少选择一个展示位置。”并保留当前页面和数据。成功随原主题草稿保存位置，清理本次位置临时选择；取消原重叠确认不写入位置。 |
| 存储失败 | 位置选择写入失败时显示“展示位置保存失败，请检查浏览器存储后重试。”；以最后成功保存的选择回显，不伪装成功。 |

## 二、平台侧：展示区域列表

![区域列表](assets/region-create-success.png)

图：M 平台实际区域列表，包含已创建的新区域。

入口：M 平台 → 展示区域管理。作用对象：平台共享区域目录；商家侧无此入口。

### 筛选区

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 区域名称／编码搜索 | 默认空；不区分大小写的包含匹配，和状态筛选取交集；输入后即时刷新并回第一页。 |
| 状态筛选 | 单选全部／启用／停用，默认全部；影响区域列表和条数。 |
| 重置 | 清空当前页面搜索与状态，回第一页，不改变区域配置。 |
| 新增区域 | 仅有平台预设发布权限可用；打开新增抽屉，创建后默认没有终端接入。 |

### 列表区

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 区域名称 | 商家可见名称；内置区域有内置标签，名称与编码分别展示。 |
| 区域编码 | 稳定消费标识，小写编码，使用等宽样式，不以名称修改编码。 |
| 所属场景 | 用于分组理解，显示保存的场景文字。 |
| 素材规范 | 分别展示类型、数量上限和建议比例；不从示例图片推断规范。 |
| 已接入终端 | 展示当前登记支持的终端；为空显示待终端接入。 |
| 状态 | 启用／停用，不代表终端正在展示。 |
| 编辑 | 打开该区域的编辑抽屉；编码不可修改；已接入协议限制见下一页。 |
| 终端接入 | 打开区域自己的支持矩阵；只读用户可查看，管理按钮及输入按权限禁用。 |
| 停用／启用 | 停用先确认；停用使历史发布失效但不删除内容；启用不恢复旧发布。 |
| 共 N 条 | 当前筛选结果条数；空筛选不误显示系统错误为零条。 |
| 上一页／下一页 | 10 条一页，首尾禁用；切换保留本页筛选。 |

## 三、平台侧：新增／编辑区域抽屉

![区域表单](assets/region-create.png)

图：区域新增抽屉，字段与按钮位于自身画面。

用途：创建可配置的展示单元，或修改其可兼容元数据。

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 区域名称 | 必填，去首尾空格后 1～30 字；默认空；显示给商家。 |
| 区域编码 | 新建必填，唯一且最多 64 字；小写字母开头，字母数字与 `. _ -` 分隔，例如 `home.banner`；编辑禁用。 |
| 所属场景 | 必填 1～20 字，默认空；可以输入新场景，候选仅提供输入建议。 |
| 区域说明 | 选填，默认空，最多 200 字；说明位置与用途。 |
| 支持素材类型／图片 | 默认选中，选中后可为区域配置图片内容。 |
| 支持素材类型／视频 | 默认不选中；至少图片或视频有一项。 |
| 建议比例 | 默认 16:9；每边 1～4 位正整数；多比例使用 `/`，保存去重。 |
| 素材数量上限 | 默认 5，必填整数 1～20。 |
| 轮播间隔参数 | 默认开放；决定商家编辑中是否显示该参数。 |
| 无操作进入参数 | 默认不开放；需要空闲触发时由管理员选择；不会强加给首页等区域。 |
| 保存区域 | 重新校验平台管理权限、唯一编码、字段与目录版本；全部通过后保存并返回列表。失败不写入，表单保留。 |
| 已接入协议保护 | 有终端登记时，比例、数量、类型、参数不直接变更；名称、场景、说明可编辑。需兼容性变化时协调终端或使用新区域。 |
| 取消／关闭 | 未修改直接返回；有修改先询问放弃，取消确认保留输入，确认放弃不写入。 |

## 六、内容编辑

![六、内容编辑](assets/v11-content-create.png)

图：六、内容编辑；功能分支 V1.1，隔离演示会话。

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 内容方案名称 | 必填1—50字，去首尾空格；列表搜索按名称匹配。 |
| 展示区域 | 单选启用区域，决定比例、类型、总量及参数。切换区域时不删除素材，不再匹配的比例转入通用分组，保存时重检。停用区域不可保存新内容。 |
| 无操作进入屏保时间 | 区域开放idle时显示；默认60秒，1—3600整数，终端执行进入退出。 |
| 图片轮播时间间隔 | 区域开放interval时显示；默认5秒，1—300整数。 |
| 切换效果 | 内置屏保或区域开放transition时显示；默认slide，可选slide/fade/zoom/rotate/bounce/flip，发布冻结参数，由支持的产线执行。 |
| 比例分区 | 按区域比例分别编辑；9:16显示竖版，16:9显示横版，其他显示比例名。已有default素材另显示通用分组。 |
| 图片／视频 | 每个比例只能一种类型；最多5张图片或1个视频，同时受区域总数上限约束。切换类型且存在其他类型素材时确认，确认只移除当前草稿该比例素材；取消保留。 |
| 素材删除 | 移除当前草稿引用，不删除素材库、媒体原件或历史快照；无素材不能保存。 |
| 前移／后移 | 仅调整同一比例的素材相对顺序，首尾越界无变化，保存后进入下一内容版本。 |
| 保存草稿 | 重检内容、品牌、权限和revision；成功version+1，不修改已上架快照，失败保留编辑内容。 |
| 选择门店 | 先保存当前内容；成功进入门店步骤并带入此方案，失败停留编辑页。 |
| 返回 | 有修改先确认放弃；取消留在原表单，确认关闭不保存。 |
