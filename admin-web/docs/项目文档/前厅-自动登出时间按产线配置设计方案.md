# 前厅 · 自动登出时间按产线配置设计方案

> **模块**：前厅管理中心 → 设置 → 账户安全与授权 → 自动登出时间(分钟)（seq 75）  
> **版本**：v1.0  
> **日期**：2026-07-20  
> **状态**：已落地（方案 1：pos-session-security-ui 内改造）  
> **对标实现**：门店信息 · 营业时间即将结束提示（seq 582，`module-settings-store-closing-alert-ui.ts`）

---

## 一、背景与目标

### 现状

seq 75 当前为：

- **一个全局分钟数**（`75-auto-logout-minutes`，0 = 不自动登出，1–999）
- **适用产线多选**（`75-auto-logout-minutes-lines`：POS / POS GO / PayPad）

各产线共用同一超时，无法按产品差异化（例如 POS 15 分钟、PayPad 5 分钟）。

### 目标

- 各产线可独立设置「是否启用自动登出」与「无操作超时分钟」
- UI / 存储模式对齐 seq 582（产线 | 启用 | 分钟）
- **不加总开关**（面板始终可见）
- 兼容旧数据与 FOH 按产线视图、下发预览、AI 数值编辑

### 非目标

- 不改 seq 166 / 175
- 不抽公共「按产线分钟表」组件
- 不扩展产线集合（仍为 POS / POS GO / PayPad）
- 本期不做 AI 按产线分别配置

---

## 二、交互与语义

### 界面

- 位置不变：前厅设置中 seq 75 展开面板（无总开关，常显）
- 表格列：**产线 | 启用 | 无操作超时**
- 行：POS、POS GO、PayPad
- 未勾选「启用」时，该行分钟输入框 **disabled**（同 582）
- 说明文案：为各产线分别设置无操作自动登出时间；取消勾选表示该产线不自动登出

### 语义

| 状态 | 行为 |
|------|------|
| `enabled = false` | 该产线不自动登出 |
| `enabled = true` | 无操作满 `minutes` 分钟后自动登出 |
| `minutes` 范围 | **1–999**（启用后不允许 0；0 仅作为历史迁移输入） |

默认：各产线 `enabled = true`，`minutes = 15`（与现网默认一致）。

## 三、数据模型

### 主存储

- fieldId：`75-auto-logout-by-line`
- 类型：JSON

```ts
type AutoLogoutLineConfig = {
  enabled: boolean;
  minutes: number; // 1–999
};

// Record<"pos" | "pos-go" | "paypad", AutoLogoutLineConfig>
```

示例：

```json
{
  "pos": { "enabled": true, "minutes": 15 },
  "pos-go": { "enabled": true, "minutes": 30 },
  "paypad": { "enabled": false, "minutes": 15 }
}
```

### Legacy 同步（写入主存储时同步）

| 字段 | 用途 |
|------|------|
| `75-auto-logout-minutes-lines` | 已启用产线 id 数组；FOH `FOH_LINE_STORAGE_BY_SEQ[75]` 依赖 |
| `75-auto-logout-minutes` | 第一个已启用产线的分钟数；AI / 旧读路径依赖。**若无已启用产线，不改写该字段**（对齐 582 `syncLegacyFields`） |

读路径以 `75-auto-logout-by-line` 为准；若仅有 legacy，走一次性迁移后再写回主存储。

### 旧数据迁移（一次性）

「有效对象」定义：JSON 解析后为 object，且 `Object.keys(raw).length > 0`（空 `{}` **不算**已迁移，与 582 一致）。

1. 若 `75-auto-logout-by-line` 已有有效对象 → 规范化后写回，结束  
2. 否则读取：
   - `minutesLegacy = 75-auto-logout-minutes`，缺省读法与现网 `readAutoLogoutMinutes()` 一致（缺省 **15**，非法值回退 15）
   - `linesRaw = 75-auto-logout-minutes-lines`
   - **`linesLegacy` 解析规则（与现网 `readPosSessionSecurityLines(75)` 一致）**：
     - 若 `linesRaw` 为非空合法产线 id 数组 → 使用该数组
     - 若为 `null` / 缺失 / 空数组 `[]` → **视为全选** `[pos, pos-go, paypad]`（避免未改过产线的门店迁移后全部关掉自动登出）
3. 对每个产线：
   - 在 `linesLegacy` 中且 `minutesLegacy > 0` → `{ enabled: true, minutes: clamp(minutesLegacy, 1, 999) }`
   - 在 `linesLegacy` 中但 `minutesLegacy === 0` → `{ enabled: false, minutes: 15 }`
   - 不在 `linesLegacy` 中 → `{ enabled: false, minutes: 15 }`
4. 写出 `75-auto-logout-by-line`，并执行 legacy 同步

## 四、实现要点（方案 1）

在现有 `module-settings-pos-session-security-ui.ts` 内改造 seq 75；166/175 仍用产线多选，逻辑不变。

### 核心 API（示意）

- `readAutoLogoutByLine()` / `writeAutoLogoutByLine(config)`
- `renderAutoLogoutMinutesPanelHtml()` → 渲染 by-line 表（含 `data-foh-line-config-row`）
- `bindPosSessionSecurityUi` → 绑定启用勾选与分钟 change/input
- 保留 `readAutoLogoutMinutes()` / `writeAutoLogoutMinutes()` 作为 legacy 读写：写时落到所有已启用产线的 `minutes`

### FOH 按产线视图

- 表格行：`data-foh-line-config-row="{lineId}"`，按产线视图只显示当前产线
- `75-auto-logout-minutes-lines` 与 by-line 的 `enabled` **双向同步**：
  - 写 by-line → 同步更新 lines 数组（及 legacy 分钟）
  - `foh-settings-by-line-toggle`（或等价路径）写 lines 时 → **回写**对应产线的 `enabled`，避免 FOH 开关与表格「启用」漂移
- 按产线视图修改启用/分钟 → 写 by-line 并 sync legacy

### 下发预览

对齐 582，在 `module-settings-deployment-change.ts`（及必要时 `deployment-change-preview.ts`）：

- 识别 `75-auto-logout-by-line`
- 文案例：`POS：启用，无操作 15 分钟` / `POS GO：未启用`
- 操作推断：按行对比（同 582 `inferClosingAlertByLineOperation` 模式）

### AI 可编辑

- 保留 `KNOWN_NUMBER_FIELDS` 中 `75-auto-logout-minutes`
- AI 写入该数值时：先 `clamp` 到 **1–999**（`0` 或非法值按最小值 1 处理，与「启用后不允许 0」一致），再更新所有**当前已启用**产线的 `minutes`；未启用产线不动
- 本期不新增按产线 AI mutation

### Catalog（可选）

- `sceneDesc` 调整为：为各产线分别设置无操作自动登出时间；取消勾选表示该产线不自动登出。

## 六、验收标准

1. 场景视图：三行可分别设置启用与分钟（1–999）  
2. 取消启用 → 分钟输入禁用；该产线视为不自动登出  
3. 旧数据迁移：原分钟 + 勾选产线正确迁入；原分钟为 0 → 对应行未启用；原 lines 为空/缺失 → 按全选迁移  
4. 按产线视图：仅当前产线一行；启用与分钟可改且持久化  
5. FOH lines ↔ by-line `enabled` 双向同步不漂移  
6. 下发预览可读出「产线：启用/未启用 + 分钟」  
7. AI 写入 `0` 后，已启用产线分钟为 `1`（非 0）  
8. seq 166 / 175 无回归
