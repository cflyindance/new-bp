## 采集口径

菜单配置记录新增、复制子树、移动、排序、删除、导入、导出、保存草稿和发布。普通名称、用途、权限及关联页面修改在成功提交编辑或保存时形成记录，不逐字记录输入和失焦。一个提交批次仅生成一条主记录，详情列出涉及对象及变化，避免结构动作与字段变化重复记账。菜单操作对编辑中配置的成功改变标为“编辑配置”，不得标为发布成功；仅 repository.publish 返回成功后记录“发布成功”。

注册中心记录项目新增、编辑、启停、删除，以及目录和页面新增、编辑、复制、移动、排序、删除。以成功写入最新本地工作区快照为成功判定。按钮虽然为“保存并发布”，但其实际仅写浏览器存储，记录阶段固定“本地保存”，不伪造发布版本。

自动读取、恢复草稿、默认测试数据初始化、搜索、展开、收起、选择、日志查看均不记操作。确认弹框取消、放弃尚未提交表单不记失败。用户明确提交后发生校验、权限或存储失败，记录一次失败尝试，保留业务输入且不记成功。无法确定操作身份时显示“未知本地账号”，不冒用管理员。

## 字段与详情

每条记录有稳定记录 ID、批次 ID、模块、操作类型、对象稳定 ID、操作时名称、操作前后层级路径、时间（UTC ISO 保存、界面本地时间到秒）、登录身份快照、阶段、成功或失败、失败原因、字段差异及必要对象快照。操作人从现有认证账号获取，标记为本地身份信息，不能作为服务端认证证据。

对象重命名和删除后仍展示历史名称、路径和差异。复制整树记录复制数量和来源／新对象标识；移动和排序展示原父级、目标父级及位置。菜单更换页面展示关联参数差异；同一字段的前后值完全相同时不记字段变更，无任何变化不生成编辑记录。导出只记录主动成功导出的行为，不记录查看日志为导出；导入记录最终提交的数据差异，解析失败记失败，不改原配置。

不保存口令、令牌、文件原文或 URL 内的凭据及查询参数；路由、字段快照经过递归脱敏后再存储。详情以字段／修改前／修改后三列展示，复杂对象按可展开 JSON 展示，所有动态内容转义，禁止将日志当作可执行 HTML。

## 列表

标题下统一标注：仅当前浏览器及本站点的本地记录，可被清除或篡改，不是正式审计；不跨设备／浏览器／端口同步，无历史数据补录。

列表列：操作时间、操作人、操作对象及路径、操作类型、阶段、结果、查看详情。默认时间倒序，每页 20 条，分页只作用于筛选结果。筛选为起止日期（含当天，以当前浏览器时区解释）、操作人、操作类型、结果和对象关键字；日志模块由入口固定，注册中心另支持项目／页面／目录对象类型筛选。查询执行交集筛选并回第一页；重置恢复全部时间／类型／结果、空关键字及第一页。开始时间晚于结束时间禁止查询并提示。

详情弹框展示本条记录快照，不从当前对象反查替代历史事实；返回／关闭不改变筛选、分页或滚动。菜单、项目及页面详情增加“查看记录”只读入口，携带对象稳定 ID 打开所属记录页；无记录展示明确空态，不显示演示日志。

## 存储及失败策略

共用版本化独立 localStorage 日志键，保留完整记录、不自动截断或清理。未知版本、损坏数据禁止覆写；显示存储异常，不伪装为空列表。

当前业务包含服务端／本地仓库及浏览器工作区两种边界，日志与业务不具备跨键原子性。采取不回滚既有成功业务的策略：业务成功后尝试日志写入；失败则清晰提示“业务已成功，操作记录保存失败”，保留本次记录在当前会话供查看并标为“未持久化”，刷新会丢失；不显示完整审计成功，也不自动重复执行业务。业务失败时日志写入失败同样提示，但不掩盖原失败原因。日志不可用不扩大业务权限。

不自动修改全局存储配置。多标签同时写日志采用写入前重新读取并按记录 ID 合并去重，但 localStorage 不提供可靠事务，本版本不承诺跨标签无丢失；界面边界说明列明该限制。记录规模导致空间不足时遵循上述失败提示，不自动删除旧日志。

## 实施与验收

1. 统一日志领域和存储：差异、脱敏、失败分支、损坏／未知版本保护、无变化去重、会话未持久化记录。
2. 菜单 store 与导入导出入口接入采集；注册中心公共写入口接入对象差异；成功、失败、取消边界明确，避免重复监听或重复日志。
3. 导航三级滑层、两个列表、详情及对象查看记录入口，权限和草稿保护沿用现有公共实现。
4. 单元验证对象变更与身份快照、删除历史可读、失败不记成功、发布阶段区分、递归脱敏；浏览器验证真实新增／编辑／移动／删除／启停／保存发布及双模块隔离、筛选分页、详情关闭上下文。
5. 日志写入配额异常、业务成功日志失败、损坏数据和只读角色进行隔离测试。不使用真实账号敏感信息，不把控制台注入演示日志当作采集验收。

业务范围以本规格为准；不包含服务端审计、跨设备日志、版本恢复和历史操作追溯补录。实现后交付分支预览、真实截图和明确未验证边界。
