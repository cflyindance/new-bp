# 商家订阅“更多”操作浮层交互设计

## 背景与目标

商家订阅列表当前使用行内展开结构承载“更多”操作，展开后会改变表格行高，与服务包管理中的悬浮操作菜单不一致。用户已选择方案 1：完整复用服务包管理“更多”的交互样式与键盘行为，使订阅明细中的低频操作以不占据表格布局的浮层展示。

## 范围

- 仅调整商家订阅列表“更多”按钮及其操作菜单的展示、定位、关闭和键盘交互。
- 主操作按钮、各状态操作矩阵、操作顺序、权限判断、禁用原因、确认弹框、抽屉、存储写入和审计逻辑保持不变。
- 服务包管理现有行为作为验收基准，本次不改变其业务操作或生命周期规则。

## 页面结构

- “更多”使用按钮触发器，具备 `aria-haspopup="menu"`、`aria-controls` 和随开关状态同步的 `aria-expanded`。
- 操作容器使用原生 Popover，声明 `popover="auto"` 与 `role="menu"`，脱离表格普通文档流，不改变订阅行高。
- 触发器和菜单容器直接复用服务包的 `package-more`、`package-menu` 样式契约；普通、危险、禁用和 `focus-visible` 状态沿用同一间距、宽度、圆角、阴影、颜色和焦点轮廓，不制作近似副本。
- 操作项使用 `role="menuitem"`。可执行项沿用原操作事件；禁用项使用 `aria-disabled="true"` 而非原生 `disabled`，保持可聚焦但不可执行。禁用原因使用菜单内可见辅助文本，并通过 `aria-describedby` 与该操作关联；`Enter`、`Space` 点击禁用项均不触发业务处理。
- 同一时刻只展开一个操作菜单。

## 定位与关闭行为

- 默认在触发按钮右侧对齐并向下展开；下方空间不足时改为向上展开。
- 水平方向限制在视口内；内容过多时限制最大高度并允许菜单内部滚动。
- 再次点击同一“更多”、点击浮层外、窗口缩放、路由变化或外层滚动时关闭。
- 菜单自身滚动保持打开；表格横向滚动、列表／页面纵向滚动及其他外层滚动关闭。
- 点击可执行操作后先关闭浮层，再进入既有确认弹框、抽屉或业务处理流程。
- 表格横向滚动、页面纵向滚动及视口底部行均不得造成菜单被裁切、残留或错误覆盖。

## 键盘与焦点

- 触发器按 `Enter` 或 `Space` 沿用按钮默认点击语义打开／关闭；按 `ArrowDown` 打开并聚焦首项，按 `ArrowUp` 打开并聚焦末项。
- 打开后焦点进入第一个菜单项；禁用项同样可被方向键访问，以便读取禁用原因。`ArrowDown`、`ArrowUp` 在全部操作项间循环；`Home`、`End` 分别定位首项和末项。全部操作均禁用时仍聚焦首项，允许读取原因，但所有激活动作均不执行。
- 可执行菜单项按 `Enter` 或 `Space` 触发既有操作；禁用项不触发。
- `Escape` 关闭并将焦点还给触发按钮；`Tab` 或 `Shift+Tab` 关闭浮层，并按浏览器正常正向／反向顺序移至菜单之外的下一／上一可聚焦控件，不回跳触发器、不形成焦点陷阱。
- 触发按钮与菜单因页面刷新而移除时，焦点恢复逻辑安全退出，不抛出异常。

## 异常与兼容

- 找不到目标菜单时不执行打开动作，不影响列表其他行。
- 无权限的操作继续按既有规则隐藏；因状态、服务包或数据缺失暂不可执行的操作继续显示禁用原因。
- 原生 Popover 不可用时不新增第二套业务流程；实现侧通过现有目标浏览器能力与自动化契约校验保障。

## 验收

1. 点击任意订阅行“更多”，菜单悬浮展示且该行高度不变，视觉与服务包管理一致。
2. 首行、中间行、视口底部行和横向滚动状态下均正确定位；下方不足时向上展开。
3. 外部点击、重复点击、外层滚动、缩放、路由切换、`Escape`、`Tab`／`Shift+Tab` 均按定义关闭；菜单内部滚动保持打开。
4. 触发器 `Enter`／`Space`／方向键、菜单项方向键、`Home`、`End`、`Enter`／`Space` 和焦点恢复符合定义。
5. 禁用项可聚焦、可读到原因但不可执行；全部项目禁用时也不丢失原因说明。
6. 触发器展开态、菜单容器、普通／危险／禁用项及 `focus-visible` 与服务包管理使用同一样式类和状态表现。
7. 各订阅状态的主操作、更多操作、禁用原因及后续确认流程与变更前一致。
8. 功能完成后实采订阅明细“更多”展开态及底部向上展开态截图；实现前文档明确标记待补，不使用示意图冒充实采图。
