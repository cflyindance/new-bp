# 自助餐规则列表筛选与表头设计

## 1. 目标

自助餐规则列表参照“菜单下单限制”的筛选、字段设置和表格交互方式，建立适合自助餐规则业务维度的列表能力。页面继续保留“整单限制”“每轮常用组合模板”“每轮原子规则”三个分组，不改变规则编辑、保存、校验、启禁用和发布逻辑。

## 2. 页面结构

### 2.1 顶部操作

- 页面标题：自助餐规则。
- 右侧主操作：新增规则。
- 结果数量：`筛选 X / 共 Y 条`。

### 2.2 筛选区

第一行展示常用筛选：

1. 规则搜索。
2. 门店。
3. 状态。
4. 限购主体。
5. 额度周期。
6. 限购对象。
7. 重置。

第二行展示：

- 高级筛选入口，展开“人数区间”和“生效时间”。
- 结果数量。
- 字段设置。

### 2.3 规则分组

保留以下顺序：

1. 整单限制。
2. 每轮常用组合模板。
3. 每轮原子规则。
4. 其他规则，仅存在自定义或无法归入前三组的规则时展示。

筛选只过滤分组中的规则，不改变规则原始排序。筛选后没有记录的分组自动隐藏；所有分组都为空时展示“暂无匹配规则”。

## 3. 筛选条件定义

### 3.1 规则搜索

- 搜索范围：规则名称、旧 KPOS 能力编号、旧 KPOS 能力名称。
- 使用包含匹配。
- 忽略输入首尾空格和英文大小写。
- 空输入不参与筛选。

### 3.2 门店

- 业务字段：生效门店，不使用参与门店。
- 默认值：全部门店。
- 选项来源：全部规则实际引用的生效门店，按门店目录顺序展示。
- 规则包含所选门店 ID 时命中。

### 3.3 状态

- 选项：全部状态、已启用、已禁用、草稿。
- `active` 映射为已启用。
- `disabled` 和历史值 `inactive` 统一映射为已禁用。
- `draft` 映射为草稿。

### 3.4 限购主体

- 选项：全部主体、按桌/订单、按人数。
- 分别匹配 `order`、`party_size`。

### 3.5 额度周期

- 选项：全部周期、整个订单、每轮、多轮。
- 分别匹配 `order_lifetime`、`per_round`、`multi_round`。
- 兼容 `enabledPeriods` 多值结构：只要规则包含所选周期即命中。

### 3.6 限购对象

- 选项：全部对象、菜品、分类、菜品集。
- 分别匹配 `dish`、`category`、`dish_set`。

### 3.7 高级筛选：人数区间

- 输入实际就餐人数，限定为大于等于 1 的整数。
- 规则任一有效人数区间包含输入值时命中。例如输入 `3`，可同时命中 `1–3人` 和 `3–5人`。
- “所有人数”规则命中任意合法人数。
- 非法值不执行筛选，并在输入框附近提示“请输入大于等于 1 的整数”。

### 3.8 高级筛选：生效时间

- 默认值：全部时间。
- 选项包含全天生效及全部规则中实际使用的时间设置摘要。
- 使用归一化后的生效时间摘要精确匹配。

### 3.9 组合规则

- 所有非空条件之间使用“且”关系。
- 任一筛选条件变化后立即更新列表、分组显隐和结果数量。
- 筛选条件只影响当前展示，不修改规则数据。
- 筛选状态本期不持久化，重新进入页面恢复默认。
- 门店、时间等动态选项始终从全部规则生成，不随当前筛选结果收缩。
- 重置清空全部条件、收起高级筛选并恢复完整列表。

## 4. 默认表头

默认展示以下七列：

| 字段 | 展示定义 |
|---|---|
| 规则名称 | 名称和“系统默认”标识；点击名称进入查看 |
| 规则策略 | `限购主体 · 额度周期 · 限购对象 · 计量方式`；组合模板需体现“每轮总量＋对象限额” |
| 人数场景 | 所有人数或人数区间摘要，如 `1–3人、4人及以上` |
| 商品范围 | 如 `指定菜品 12 个`、`菜品集 8 个成员`、`分类 3 个`；无范围显示 `—` |
| 生效门店 | 一家显示门店名；多家显示“首家门店等 N 家”；无门店显示 `0 家` |
| 状态 | 已启用、已禁用、草稿 |
| 操作 | 编辑、复制、启用/禁用、删除；草稿按现有生命周期展示可用操作 |

规则名称固定在左侧；状态和操作固定在右侧。表格超出容器时在表格区域横向滚动。

## 5. 字段设置

### 5.1 固定字段

- 规则名称。
- 状态。
- 操作。

固定字段始终勾选且不可关闭。

### 5.2 默认字段

- 规则策略。
- 人数场景。
- 商品范围。
- 生效门店。

### 5.3 可选字段分组

**旧规则核对**

- 旧 KPOS 调研能力。
- 覆盖结果。

**规则类型**

- 限购主体。
- 额度周期。
- 限购对象。
- 计量方式。

**场景与数量**

- 人数区间。
- 轮次区间。
- 每轮总量。
- 对象限额。
- 相同菜品限额。

**商品配置**

- 参与门店。
- 适用产线。
- 目标商品数。
- 数量完成度。

**超限授权**

- 授权范围。
- 默认授权范围。
- 所需权限。
- 授权原因。

**生效范围**

- 有效日期。
- 活动周期。
- 营业时段。
- 会员范围。

**补充字段**

- 规则描述。

### 5.4 字段设置交互

- 点击“字段设置”打开浮层，按上述业务组展示复选框。
- 切换字段立即更新表头和表格，不刷新页面、不改变筛选条件。
- “恢复默认”恢复固定字段和默认字段。
- 字段偏好使用自助餐规则模块独立、带版本号的本地存储键，不与菜单下单限制共用。
- 加载偏好时剔除无效或已删除字段，并自动补回固定字段。
- 系统默认规则、普通规则和草稿共用同一套字段设置。

## 6. 数据归一化

- 规则数据按 `authoringConfig`、`authoringDraft`、`editorDraft` 的优先顺序读取可用配置，并形成只读列表视图。
- 筛选和表格展示不得回写配置对象。
- 字段为空时统一展示 `—`；选择具体筛选条件时，缺失对应字段的规则不命中。
- KPOS 能力从默认场景的 `legacyCapabilityIds` 映射到能力目录，供搜索和可选列使用。
- 分组继续复用默认场景模板的 `group` 定义；自定义规则使用归一化后的主体、周期和对象推导，无法推导时进入“其他规则”。

## 7. 状态与异常

- 无规则：展示“暂无自助餐规则”和新增入口。
- 有规则但无筛选结果：展示“暂无匹配规则”和重置筛选入口。
- 人数输入非法：保留当前完整列表，不应用非法条件并展示输入提示。
- 本地字段偏好损坏：忽略损坏值并恢复默认字段。
- 未识别状态或枚举：显示 `—`，并可通过“全部”条件查看。

## 8. 验收标准

1. 六个常用筛选、高级筛选、组合筛选和重置均正确工作。
2. 人数值能命中所有包含该人数的区间规则。
3. 结果数量、分组显隐和无结果状态正确。
4. 默认七列表头及内容符合定义。
5. 字段设置支持显示、隐藏、恢复默认和刷新后恢复偏好。
6. 固定字段不能隐藏，横向滚动时固定列仍可查看和操作。
7. 系统默认规则、普通规则和草稿均可正确归一化、筛选和展示。
8. `disabled`、`inactive` 等历史状态兼容正确。
9. 筛选和字段设置不修改规则配置，不影响编辑、复制、启禁用、删除和发布。
10. 自助餐规则字段偏好与菜单下单限制互不影响。

## 9. 可视化确认

已通过可视化伴侣确认以下布局：常用筛选单行展示，高级筛选与结果数量/字段设置位于第二行；默认表头使用七列精简方案；规则分组继续保留。
