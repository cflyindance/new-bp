# 限购数量人数×轮次组合平铺展示设计

## 背景

「数量与频次限制 > 限购数量」在规则周期为多轮（`period === "multi_round"`）时，通过两排 Tab 分别选择人数场景与轮次场景，一次只编辑一个组合下的数量矩阵。人数与轮次都有多个区间时（例如 1人 / 2人及以上 × 1轮 / 2轮），运营需要反复切换才能看清各组数量，二次核对与对照填写成本高。

## 目标

- 多轮规则默认按「人数 × 轮次」笛卡尔组合**平铺**编辑，一眼看到全部组合。
- 仍保留现有「分开选择」交互（两排 Tab，一次编一组），供习惯或组合特别多时使用。
- 不改变 `limits` 键结构与门店 / 产线数据模型。

## 已确认方案

| 决策 | 结论 |
|---|---|
| 平铺形态 | 每个组合一块独立矩阵，纵向分段排列 |
| 出现条件 | 仅多轮规则显示模式切换 |
| 默认模式 | 组合平铺 |
| 模式入口 | 配置门店下方、场景区顶部的分段控件 |
| 批量 | 每块自带批量条与勾选，只作用于该组合 |
| 勾选集合 | 每块独立，互不影响 |
| 模式持久化 | 仅编辑器临时 UI 状态，不入库 |

## 模式切换

多轮规则在「配置门店」下方展示「场景展示」分段控件：

- **组合平铺**（默认）
- **分开选择**

非多轮规则不渲染该控件，人数场景 Tab 行为与现网一致。

### 临时状态

在 `editorState` 增加例如：

- `sceneDisplayMode: "tile" | "split"`（默认 `"tile"`）
- 平铺下各块批量勾选：`batchSelectedByScene` 或等价结构，键为 `partyIndex|roundIndex`

不写入 `editorDraft`，不参与草稿持久化与发布快照。

### 切换行为

1. 切换模式时清空全部批量勾选。
2. 不修改任何 `limits` 单元格。
3. 切到「分开选择」时，用当前 `activePartyIndex` / `activeRoundIndex` 恢复两排 Tab（若索引越界则归一化到 0）。
4. 离开步骤 4：重置为 `"tile"`，清空勾选。
5. 切换门店 / 产线：保留展示模式，清空勾选。

## 组合平铺

### 块生成

对 `draft.partyRanges` × `draft.roundRanges` 生成有序列表：

1. 外层：`partyIndex` 升序  
2. 内层：`roundIndex` 升序  

块标题：`formatRange(partyRange, "人") + " · " + formatRange(roundRange, "轮")`。  
块旁可显示当前门店、当前产线下该组合的完成度 `已配置/总数`。

即使只有 1×1 个组合，多轮规则仍走平铺布局（仅一块），以保持模式一致。

### 页面结构（平铺）

1. 配置门店  
2. 场景展示分段控件  
3. 产线配置标题（含「查看已配置规则」）+ 产线 Tab  
4. 纵向排列的组合块；每块含：标题与完成度、批量工具条、数量表（勾选列 + 菜单 + 上限）

平铺模式下**不渲染**人数 Tab、轮次 Tab。

### 读写

- 单元格键保持：`partyIndex|roundIndex|lineId|targetId`（落在当前门店 `storeConfigs[storeId].limits`）。
- 块内单格输入与批量应用显式带上该块的 `partyIndex` / `roundIndex`，不依赖 `activePartyIndex` / `activeRoundIndex`。
- 产线 Tab、门店下拉仍决定「当前门店 / 当前产线」；所有块共用这两个维度。

### 批量（每块）

对齐现有批量能力，但作用域收窄到本块：

- 已选计数、全选当前产线（本块行）、清空选择、数量输入、应用数量  
- 成功后仅清空**本块**勾选，不退出平铺模式  
- 不提供跨块一次改多组合

## 分开选择

与现网一致：

1. 人数场景 Tab  
2. 轮次场景 Tab  
3. 产线配置 + 单套批量条 + 单套矩阵  

矩阵与批量读写 `activePartyIndex` / `activeRoundIndex`。

## 完成度

- 产线 Tab 完成度：继续按当前门店 × 该产线，跨全部人数×轮次汇总（现有 `completionFor` 口径）。
- 块级完成度：仅统计该 `partyIndex|roundIndex|activeLineId` 下目标单元格。

## 与全量预览的关系

「查看已配置规则」弹层不受展示模式影响，仍按门店 × 人数 × 轮次 × 产线全量只读展开。

## 非目标

- 宽表多列（一行菜单、多组合列）平铺  
- 跨组合块的统一批量  
- 展示模式写入草稿、按门店或按规则记忆  
- 改变 `limits` 键、发布裁剪或场景区间配置步骤  

## 验证

新增专项脚本，至少断言：

1. 多轮规则渲染场景展示控件；非多轮不渲染  
2. 默认 `sceneDisplayMode === "tile"`（或等价初始化）  
3. 平铺按 party×round 顺序生成块标记 / 标题  
4. 块内批量 / 输入带明确 party/round，不误用另一组合  
5. 模式切换清空勾选且不改 `limits`  
6. 离开步骤 4 重置为平铺  

浏览器验收：

- 2 人数 × 2 轮次默认 4 块，各组数量独立  
- 分开选择 ↔ 组合平铺往返数据不丢  
- 块内批量只影响该块  
- 非多轮无模式控件  
- 产线完成度与块完成度正确
