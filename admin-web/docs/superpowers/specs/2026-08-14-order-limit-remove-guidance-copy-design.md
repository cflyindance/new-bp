# 数量与频次规则说明文案精简设计

## 目标

从“新增数量与频次规则”流程中删除用户指定的七条辅助说明，减少重复信息和页面视觉噪声，同时保持现有规则配置能力、校验逻辑、按钮和步骤结构不变。

## 变更范围

生产代码仅修改 `dist/Configuration center/assets/order-limit-flow.js` 中对应步骤的渲染模板，并新增一份静态验证脚本。需要删除的准确原文和节点如下：

| 步骤 | 删除的准确原文 | 节点处理 |
| --- | --- | --- |
| 商品配置 | `通过门店下拉切换并配置各门店商品，实际生效门店将在“生效范围”中选择。` | 删除包含该文案的整个标题说明 `<p>` |
| 商品配置 | `切换门店会自动保存上一家门店的商品配置。` | 删除包含该文案的整个 `.olf-hint` `<span>` |
| 设置限购数量 | `先选择门店，再按该门店实际包含的产线配置数量；空输入表示未配置，0 表示禁止。` | 删除包含该文案的整个标题说明 `<p>` |
| 设置生效范围 | `选择本次实际生效门店，并配置时间、会员和有效人数口径。` | 删除包含该文案的整个标题说明 `<p>` |
| 设置生效范围 | `已配置商品的门店可以生效；取消勾选不会删除该门店商品和数量配置。` | 删除包含该文案的整个 `.olf-help` `<div>` |
| 设置超限授权 | `授权只绕过当前规则的数量限制，不绕过售罄、停售、年龄或支付限制。` | 删除包含该文案的整个标题说明 `<p>` |
| 确认规则并发布 | `保存草稿不会影响门店；保存并下发后才生成正式版本。` | 删除包含该文案的整个标题说明 `<p>` |

预计修改文件：

- `dist/Configuration center/assets/order-limit-flow.js`：删除七个文案节点。
- `scripts/verify-order-limit-guidance-copy-removal.mjs`：验证目标文案消失且关键结构保留。

## 保留内容

- 各步骤标题与焦点定位属性。
- 门店下拉、商品选择、数量矩阵、生效门店、授权和发布相关控件。
- 所有业务状态、保存行为、校验规则和事件处理。
- 其他未被指定删除的字段提示、状态说明和操作反馈。

## 页面结构处理

页面标题区域继续保留 `.olf-content-head` 与 `h2`，包含目标文案的 `<p>` 节点整体删除。商品配置中的自动保存提示删除整个 `.olf-hint` 节点。生效门店区块继续保留 `.olf-section-head`、标题和表格；原帮助文案删除整个 `.olf-help` 节点。所有因本次删除失去内容的节点均不保留为空元素。

本次不通过 CSS 隐藏文案，也不新增替代文案，确保这些内容不会残留在 DOM 或辅助技术的可访问文本中。

## 验证

- 添加静态验证脚本，断言七条目标文案不再出现在流程源码中。
- 断言“商品配置”“设置限购数量”“设置生效范围”“设置超限授权”“确认规则并发布”“生效门店”等关键标题仍存在。
- 执行 JavaScript 语法检查与现有数量与频次规则验证脚本，确认无功能回归。
- 在本地预览中逐步检查相关页面，确认删除后没有空白帮助区域或布局异常。

## 非目标

- 不调整其余提示文案。
- 不改变页面视觉规范、间距系统或组件样式。
- 不修改规则数据模型、持久化结构和发布流程。
