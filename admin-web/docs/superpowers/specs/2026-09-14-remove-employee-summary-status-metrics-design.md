# 删除员工分配汇总状态统计设计

## 目标

从“员工分配汇总”页面删除第二行状态统计卡片，降低重复信息和页面纵向占用。

## 删除范围

完整删除以下四项组成的统计区块：

- 当前筛选员工数
- 已确认最终获得合计
- 已完成人数
- 待确认人数

同时删除“待确认人数”下关联的异常人数辅助文案。

## 保留范围

- 门店、日期、角色、员工等现有筛选条件保持不变。
- 上方小费金额汇总保持不变。
- 员工列表、员工状态、金额字段与进入员工详情的交互保持不变。
- 列表筛选、排序、导出及员工详情不受影响。

## 实现规则

- 从模板中删除整个统计区块，不使用 CSS 隐藏。
- 删除渲染函数中仅用于更新这些 DOM 节点的代码，避免空节点访问错误。
- 保留员工列表及其他功能仍使用的汇总/状态计算，不做无关重构。
- 更新静态验证：要求旧 ID 和四项旧文案均不存在，同时继续验证员工列表主体存在。

## 验收标准

1. 进入员工分配汇总后，不再显示第二行四项统计卡片。
2. 上方金额汇总与下方员工列表直接衔接，布局无空白占位。
3. 筛选、员工列表状态、金额和进入详情均正常。
4. 页面运行时没有因旧统计 DOM 缺失产生错误。
5. 原生视图验证脚本与项目构建通过。
