# 自助餐配置额度双额度列设计

## 1. 背景与问题

按人数计算的自助餐规则同时支持两类商品额度：

- `targetLimits`：按人数计算的对象主额度；
- `tableTargetCaps`：不乘人数的整桌固定封顶。

当前单门店商品表底层已经分别渲染两个单元格，但跨门店场景表把两个输入框合并进同一个“限购数量”单元格，导致组合模板中出现上下排列、没有语义标签的两个输入框。用户无法判断哪个值按人数计算、哪个值是整桌固定值，批量设置也必须与表格保持同一认知。

## 2. 目标

1. 所有配置额度入口用明确列名区分对象主额度和整桌固定额度。
2. 组合模板、普通按人数规则、单门店与跨门店场景使用一致的列结构与文案。
3. 批量设置字段与表格列一一对应。
4. 保持既有数据字段、计算逻辑、保存格式和 `0` 表示禁止的语义不变。
5. 在当前配置额度弹窗宽度下不出现横向滚动条。

## 3. 展示规则

### 3.1 动态额度列

商品或分类表按当前周期和计算主体生成额度列：

| 计算主体 | 周期 | 主额度列 | 整桌额度列 |
| --- | --- | --- | --- |
| 按人数 | 每轮或分轮次 | 每人每轮最多 | 整桌每轮最多 |
| 按人数 | 整个订单 | 每人每单最多 | 整桌整单最多 |
| 按桌 | 每轮或分轮次 | 每轮最多 | 不展示 |
| 按桌 | 整个订单 | 每单最多 | 不展示 |

组合模板按其真实额度口径展示。固定整桌组合不得因为场景使用人数区间而错误展示为“每人每轮最多”；字段落在 `tableTargetCaps` 时显示“整桌每轮最多”，字段落在 `targetLimits` 且组合使用人数乘数时显示“每人每轮最多”。若同一场景确实同时允许两种额度，则显示两列。

菜品集成员保护继续使用其专属列名，例如“每轮每种最多份数”，不套用上述双列。

### 3.2 表格结构

商品表保持以下顺序：

`复选框｜商品｜产线｜分类｜门店｜主额度（如适用）｜整桌额度（如适用）｜状态（如现有场景需要）｜操作`

分类表保持相同原则，但不重复展示分类字段。单门店和跨门店表均不得把两个额度输入框合并到一个单元格；每个额度列每行最多出现一个输入框，输入框右侧保留单位“份”。商品名称、产线、分类和门店继续独立展示。

### 3.3 批量设置

批量设置区由与当前表格额度列相同的列定义生成：

- 展示“每人每轮最多”时，生成对应主额度输入；
- 展示“整桌每轮最多”时，生成对应整桌额度输入；
- 整单周期改用“每人每单最多”“整桌整单最多”；
- 按桌规则只展示一个输入；
- 未填写的批量字段不修改原值；至少填写一个字段后才允许应用；
- 输入必须为 `0` 至 `999999` 的整数，`0` 仍表示禁止。

批量写入继续分别更新 `targetLimits` 和 `tableTargetCaps`，不新增数据字段。

## 4. 交互与数据流

1. 打开场景配置额度页时，根据规则主体、周期、目标类型和组合模板额度口径生成统一列定义。
2. 单门店表、跨门店表和批量设置共同消费该列定义，避免文案和字段映射分叉。
3. 用户编辑主额度时只更新 `targetLimits`；编辑整桌额度时只更新 `tableTargetCaps`。
4. 保存、切换场景和重新打开时，两个字段分别回显到对应列。
5. 空值表示未配置；显式 `0` 必须保存并显示为已配置/禁止状态。

## 5. 布局约束

- 表格继续使用固定布局并占满容器宽度，不设置会强制溢出的最小表宽。
- 额度输入允许在列内收缩，字段名允许合理换行，但不得把两个额度重新堆叠到同一列。
- 商品名称列保留优先宽度；复选框与操作列使用固定窄宽；身份字段和额度字段分配剩余空间。
- 配置额度商品列表在常用桌面弹窗宽度下不得出现左右滚动条。

## 6. 兼容性与非目标

- 不改变 `targetLimits`、`tableTargetCaps`、`defaultDishLimits` 或 `exceptionDishLimits` 的结构。
- 不改变运行时额度合并、人数乘数、整桌封顶和冲突校验逻辑。
- 不修改商品选择、商品移除、门店筛选或全场景配置汇总能力。
- 不为移动端重新设计独立表格；窄屏仅要求内容仍可辨认且不产生页面级横向滚动。

## 7. 验收标准

1. 按人数每轮规则中，同一商品的两个值分别位于“每人每轮最多”和“整桌每轮最多”列。
2. 按人数整单规则使用“每人每单最多”和“整桌整单最多”。
3. 按桌规则仅显示对应周期的一列额度，不出现空的整桌列。
4. 组合模板按真实字段口径显示列名，不再出现单个“限购数量”列中上下两个无标签输入框。
5. 单门店、跨门店和多场景配置入口的字段顺序、文案和保存回显一致。
6. 批量设置展示与表格相同的字段；只填写其中一个时，另一个既有值保持不变。
7. 输入 `0`、正整数、空值的状态与保存回显正确；非法值被拦截。
8. 商品表在当前本地预览弹窗宽度下无横向滚动条。
9. 菜品集成员保护仍只显示其专属额度列，不受双额度列调整影响。
