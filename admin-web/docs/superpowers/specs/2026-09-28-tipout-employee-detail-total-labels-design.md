# 员工每日小费详情汇总与逐日文案统一

日期：2026-09-28  
状态：已确认

## 目标与范围

小费管理的员工每日小费详情页，上方六个指标展示所选日期区间的汇总，下方表格逐行展示单日数据。文案应明确区分“区间总值”与“单日值”，并与员工分配汇总视图的金额术语一致。仅修改该页面的静态展示文字，不改任何金额、工时、筛选、排序或导出数据。

## 文案映射

| 位置 | 原文案 | 新文案 |
| --- | --- | --- |
| 上方指标 | 打卡工时 | 打卡总工时 |
| 上方指标 | 分配工时 | 分配工时 |
| 上方指标 | 分配前 | 分配前总小费 |
| 上方指标 | 贡献入池 | 贡献入池总额 |
| 上方指标 | 从池分得 | 从池分得总额 |
| 上方指标 | 实际获得 | 分配后总小费 |
| 逐日表格 | 打卡工时、分配工时 | 保持原名 |
| 逐日表格 | 分配前 | 分配前小费 |
| 逐日表格 | 贡献入池、从池分得 | 保持原名 |
| 逐日表格 | 实际获得 | 分配后小费 |

“分配工时”存在多个规则口径，区间指标也不标“总”。逐日列不标“总”，避免把单日值误读为时间段累计值。

## 验收与边界

1. 上方六个指标及下方逐日表头显示映射后的文案，列顺序、数值和状态不变。
2. 修改日期范围及考勤、分配状态筛选后，汇总值仍使用现有计算结果，文案保持稳定。
3. 点击分配工时弹框、日期排序、导出等既有交互不变。
4. 不改员工分配汇总、日期分配汇总、规则页等其他页面。
