# 已选商品筛选顺序调整设计

## 目标

在“查看已选商品”弹窗中，将筛选控件调整为“门店 → 产线 → 菜单搜索”，使菜单搜索位于产线右侧。

## 页面结构

- 桌面端按“门店、产线、菜单搜索”从左到右排列。
- 门店和产线保持固定筛选宽度。
- 菜单搜索占据右侧剩余宽度，继续显示“搜索商品/分类名称”占位文案。
- 移动端按同一语义顺序纵向排列：门店、产线、菜单搜索。
- DOM 顺序与视觉顺序一致，保证键盘焦点顺序正确。

## 交互与数据

- 不改变门店与产线的级联关系。
- 不改变菜单搜索范围，仍只匹配商品名称或分类名称。
- 不改变搜索输入法处理、分页复位和勾选清空逻辑。
- 不改变底部批量删除、全部删除、分页和单条删除交互。

## 验证

- 自动化验证筛选控件在渲染结构中的顺序为门店、产线、菜单搜索。
- 验证桌面端网格宽度为两个固定筛选列加一个弹性搜索列。
- 运行 JavaScript 语法检查及全部菜单限购回归脚本。
- 浏览器检查桌面端与移动端排列、搜索输入和筛选联动。

## 不在范围内

- 不调整弹窗其他区域的视觉样式。
- 不修改搜索、筛选或删除业务规则。
