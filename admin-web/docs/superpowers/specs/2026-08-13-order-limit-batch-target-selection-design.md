# 菜单下单限制批量勾选目标设计

## 背景

「新增/编辑数量与频次规则 > 限购数量 > 产线配置」当前提供“批量设置”，但应用数量、禁止下单或不限制时会直接覆盖当前人数场景、轮次场景和产线下的全部菜品或分类。门店经常只需要批量调整其中几个目标，现有行为容易造成无关配置被覆盖。

## 目标

- 点击“批量设置”后，可在当前数量表格中勾选多个目标。
- 按菜品规则勾选菜品；按分类规则勾选分类，交互保持一致。
- 批量数量、禁止下单和不限制仅作用于已勾选目标。
- 未勾选目标的既有配置保持不变。
- 批量模式默认不选任何目标，避免误操作。
- 批量成功、取消或切换配置上下文时自动退出并清空选择。

## 已确认方案

采用“表格行内多选”方案。批量选择复用现有数量表格，不新增弹窗或多选下拉框，使名称、当前上限、状态和实际限额始终处于同一行。

## 页面结构

### 进入批量模式

- 点击「产线配置」右侧“批量设置”进入批量模式。
- 批量模式下按钮文案改为“取消批量设置”，再次点击等同取消。
- 现有数量表格新增最左侧选择列。
- 每个当前产线的菜品或分类行显示复选框。
- 表头提供“全选当前产线”复选框；部分选中时显示 indeterminate 状态。

### 批量操作条

批量模式下在产线 Tab 与数量表格之间显示操作条：

- 显示“已选 N 项”。
- 提供“全选当前产线”和“清空选择”文本操作。
- 保留数量输入框。
- 提供“应用数量”“设为禁止”“设为不限制”三个动作。
- 未选择目标时，三个应用动作禁用。
- “应用数量”还要求输入大于或等于 0 的整数。

原“全部禁止”“全部不限制”文案改为“设为禁止”“设为不限制”，避免让用户误以为仍作用于当前产线全部目标。

## 状态与作用域

批量选择是编辑器界面的临时状态，不写入 `editorDraft`，也不参与草稿持久化。编辑器状态新增：

- `batchMode`：是否处于批量模式。
- `batchSelectedTargetIds`：当前已选目标 ID 集合。

选择仅作用于当前：

- 人数场景；
- 轮次场景（多轮规则）；
- 产线；
- 当前规则目标类型（菜品或分类）。

以下操作自动退出批量模式并清空选择：

- 任一批量动作成功；
- 点击“取消批量设置”；
- 切换人数场景；
- 切换轮次场景；
- 切换产线；
- 离开“限购数量”步骤。

重新进入批量模式时始终默认不选。

## 数据更新

执行批量动作时：

1. 获取当前人数、轮次和产线上可见的全部目标。
2. 过滤出 `batchSelectedTargetIds` 中仍属于当前上下文的目标。
3. 未选到有效目标时不更新数据，并提示“请至少选择一个菜品/分类”。
4. 对有效目标生成现有 `limitKey`，写入 `{ configured: true, value }`：
   - 应用数量：`value` 为输入整数；
   - 设为禁止：`value` 为 `0`；
   - 设为不限制：`value` 为 `null`。
5. 未选目标不写入、不清空、不改变完成状态。
6. 保存草稿并重新渲染；退出批量模式并清空选择。

## 交互细节

- 行复选框的可点击标签包含目标名称，便于键盘和触控操作。
- 全选只选择当前产线当前表格中的目标，不跨产线。
- 清空选择不退出批量模式。
- 选择或清空本身不标记业务草稿为已修改；只有批量动作实际写入上限后才标记草稿变更。
- 单行数量输入和“设为不限制”操作保持原有行为。
- 没有可选目标时，批量模式仍可取消，但所有应用动作保持禁用。

## 响应式与视觉

- 复选框列使用紧凑固定宽度，不压缩名称与数量列。
- 批量操作条允许换行，小屏上数量输入和按钮自然换行。
- 复用现有按钮、输入框、表格和焦点样式，不引入新的视觉体系。
- 表头全选、行复选框和操作按钮均保留清晰的键盘焦点反馈。

## 影响范围

预计修改：

- `dist/Configuration center/assets/order-limit-flow.js`：批量临时状态、表格选择列、全选/清空、上下文清理和仅更新已选目标。
- `dist/Configuration center/assets/order-limit-flow.css`：选择列与批量操作条的局部布局。
- 新增专项验证脚本，覆盖渲染结构、状态边界和数据更新范围。

不修改规则数据结构、草稿兼容格式、商品选择器、门店下发、授权逻辑或其他步骤。

## 验证方案

### 自动验证

- 批量模式默认关闭且选择集合为空。
- 表格仅在批量模式显示选择列。
- 全选/清空仅处理当前产线目标。
- 未选择时不允许执行批量动作。
- 批量动作只遍历有效的已选目标，不再遍历当前产线全部目标。
- 应用数量、禁止和不限制分别写入正确值。
- 应用成功和上下文切换后退出并清空。
- 既有单行数量编辑与不限制操作代码仍存在。

### 浏览器验证

- 进入步骤 4 后，点击“批量设置”默认无勾选。
- 可勾选多个菜品，应用数量后仅这些菜品变化。
- 可在分类规则中勾选多个分类并批量配置。
- 表头全选、部分选中状态和清空选择正确。
- 无选择时按钮禁用；无效数量有明确提示。
- 应用成功后自动退出并清空。
- 切换人数、轮次或产线后自动退出并清空。
- 单行编辑、新增规则保存和返回列表无回归。
- 控制台无错误。

## 非目标

- 不跨人数场景、轮次场景或产线批量配置。
- 不记忆上一次批量勾选结果。
- 不新增搜索、筛选、分页、反选或跨页选择。
- 不改变当前规则允许选择的菜品/分类范围。
