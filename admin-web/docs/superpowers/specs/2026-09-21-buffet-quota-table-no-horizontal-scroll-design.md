# 自助餐配置额度商品表格无横向滚动设计

## 1. 目标

“配置额度”弹窗中的商品列表在常规桌面弹窗宽度和较窄窗口下均适配可用宽度，不出现左右滚动条。保留现有商品、产线、分类、门店、限购数量、状态、操作字段，以及选择、批量设置、添加和删除交互。

本调整只影响单场景配置额度商品表格，不改变“全部场景商品配置”汇总弹窗的宽表展示规则。

## 2. 布局规则

1. `.olf-scene-workbench .olf-v4-product-table` 使用 `width: 100%` 和 `table-layout: fixed`，覆盖通用表格的固定最小宽度。
2. `.olf-scene-workbench .olf-v4-product-table-wrap` 禁止横向溢出；表格不能依赖左右滚动查看字段。
3. 勾选列与操作列使用紧凑固定宽度；商品列和限购数量列获得主要空间；产线、分类、门店和状态按剩余空间分配。
4. 商品名称、产线、分类和门店允许自然换行，并通过 `overflow-wrap: anywhere` 处理长文本；不得以增加表格最小宽度解决长文本。
5. 限购数量单元格内的一个或多个输入组允许换行；输入框使用 `min-width: 0` 和弹性宽度，不得撑破单元格。
6. 跨门店样式 `.olf-cross-store-table` 在配置额度弹窗内取消 `1040px` 最小宽度；门店列与额度列同样遵循弹性布局。
7. 表格纵向滚动、分页、表头、全选、行选择和批量设置行为保持不变。

## 3. 响应式策略

- 支持的最小桌面视口为 `1024 × 768`；配置额度弹窗按现有 `94vw` 宽度渲染时，商品表格及页面均不得产生横向溢出。
- 大于最小支持宽度的桌面弹窗下优先单行展示短内容。
- 空间不足时，文本和多个额度输入在各自单元格内换行，不隐藏任何字段。
- 不将状态合并到其他列，不把表格改为卡片，也不引入横向滚动。
- 操作按钮保持完整可点击，不因文字换行覆盖相邻单元格。

## 4. 验收标准

1. 普通菜品按份规则中，商品列表容器的 `scrollWidth` 不大于 `clientWidth`。
2. 菜品集按种或存在多个额度输入时，输入组在限购数量列内换行，页面无左右滚动条。
3. 跨门店商品同时展示时，门店字段保留且商品表格无左右滚动条。
4. 长商品名、分类名和门店名不会撑宽表格，文本可换行且其他列仍可操作。
5. 商品名称、产线、分类、门店、限购数量、状态、操作字段均保留。
6. 全选、单选、批量设置、添加商品、每行移除、分页及纵向滚动行为不受影响。
7. “全部场景商品配置”汇总弹窗仍可按既有宽表规则横向滚动，不受本调整影响。
8. 在 `1024 × 768` 视口中，商品表格容器与页面的 `scrollWidth` 均不大于各自 `clientWidth`，全部字段、添加商品按钮及每行操作按钮保持可见且可点击。
9. 普通、菜品集多输入、跨门店和长文本四种数据场景中，分别验证添加商品及每行操作可见、可点击，且没有横向滚动。
