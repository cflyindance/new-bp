# 链接目标菜单树形选择设计

## 目标

强化“选择链接目标菜单”弹窗的一至三级层级关系，并移除菜单 Key 的可视展示，使非研发用户能够仅凭菜单名称和树形结构准确选择目标页面。

本设计采用已确认的视觉方案 A“树形引导线”。

## 展示结构

- 弹窗按菜单文档原有顺序展示完整的一至三级菜单树。
- 子级相对父级增加缩进，并使用竖向连接线表达父子关系。
- 有子菜单的节点在名称前展示三角展开图标；展开与收起状态使用方向变化区分。
- 菜单名称使用加粗文本，右侧展示“1 级 / 2 级 / 3 级”。
- 弹窗中不展示菜单 Key，包括名称下方、名称旁边、提示文字和可见标题属性。

## 交互规则

- 弹窗打开时所有包含可用后代的目录默认展开。
- 有子菜单的目录节点点击后只展开或收起，不执行目标选择。
- 可访问页面节点点击后沿用现有逻辑，将该节点 Key 写入 `targetKey` 并关闭弹窗。
- 不可作为链接目标的节点仍不可选择，包括当前正在编辑的节点、链接类型节点、禁用节点，以及仅作为目录的节点。
- 鼠标悬停页面节点时使用浅灰背景；当前 `targetKey` 对应节点使用主题色边框和浅绿色背景。
- 展开状态属于弹窗临时界面状态，不写入菜单数据或导出 JSON；重新打开弹窗时恢复默认全部展开。
- 展开按钮和可选择页面均使用按钮语义，支持键盘聚焦与回车/空格操作，并提供可见焦点样式；展开按钮暴露 `aria-expanded`。

## 数据边界

- Key 仅从界面隐藏，仍作为页面节点选择后的内部值写入 `targetKey`。
- 不修改菜单 JSON 字段、序列化、链接目标校验及保存发布逻辑。
- 不改变菜单节点的原始顺序和父子关系。

## 验收标准

- 弹窗清楚展示一至三级的缩进、连接线和层级文案。
- 弹窗可见内容和标题属性中均不出现菜单 Key。
- 目录节点可展开、收起但不可被写入 `targetKey`。
- 页面节点点击后写入正确 Key 并关闭弹窗。
- 当前目标节点具有明确选中态，其他节点悬停态清晰。
- 重新打开弹窗时所有包含可用后代的目录默认展开。
- 键盘可操作展开按钮和页面选择按钮，展开状态具有正确 `aria-expanded`。
- 相同选择操作产生的 `targetKey`、校验、保存、发布及导出结果与改造前一致。
- 相关菜单配置回归测试和 TypeScript 静态检查通过。
