# 小费分配视图文案统一设计

## 目标

统一原生小费管理中两个视图的用户可见名称，使“按日期”和“按员工”的汇总对象更明确。此次只修改展示文案，不改变页面路由、状态键、DOM 标识、函数名、数据结构或任何业务计算逻辑。

## 文案映射

- `分配汇总` 改为 `日期分配汇总`。
- `员工对账` 改为 `员工分配汇总`。
- 由上述名称组成的用户可见复合文案同步替换，例如：
  - `返回员工对账` 改为 `返回员工分配汇总`。
  - `员工对账明细` 改为 `员工分配汇总明细`。
  - `员工小费对账汇总` 改为 `员工小费分配汇总`。
  - `当前筛选范围暂无员工对账数据` 改为 `当前筛选范围暂无员工分配汇总数据`。

### 员工明细页短文案

- `对账日期范围` 改为 `分配汇总日期范围`。
- `员工对账金额概览` 改为 `员工分配汇总金额概览`。
- `员工逐日对账明细` 改为 `员工逐日分配明细`。
- `当前筛选条件下暂无对账明细` 改为 `当前筛选条件下暂无分配明细`。
- `无法展示对账明细` 改为 `无法展示分配汇总明细`。
- `对账明细上下文已失效，请返回员工对账列表重新进入。` 改为 `分配汇总明细上下文已失效，请返回员工分配汇总列表重新进入。`。
- `无法打开员工对账明细，请重试` 改为 `无法打开员工分配汇总明细，请重试`。
- `查看 {员工} 对账明细` 改为 `查看 {员工} 分配汇总明细`。
- 页面可见主标题继续只展示员工姓名和角色，不重新增加此前已移除的通用“明细”标题。

### 导出文案与文件名

日期汇总导出统一使用：

- 英文报表标题：`Date Tip Allocation Summary`。
- CSV/PDF 文件名前缀：`DateTipAllocationSummary_`。
- 中文通知中的 `分配汇总` 改为 `日期分配汇总`。

员工汇总导出统一使用：

- 英文报表标题：`Employee Tip Allocation Summary`。
- CSV/PDF 文件名前缀：`EmployeeTipAllocationSummary_`。
- 中文通知中的 `员工对账` 改为 `员工分配汇总`。

员工个人明细导出统一使用：

- 打印/PDF 报表标题：`{员工姓名} 员工分配汇总`。
- 仅修改打印页正文中的 `<h1>`；浏览器页面 `<title>` 继续使用现有员工姓名与日期范围，以保持“打印为 PDF”时的默认文件名不变。
- 现有以员工姓名和日期范围组成的个人明细 CSV/PDF 文件名保持不变，因为其中不含旧视图名称。
- 员工个人明细没有独立的 CSV 报表标题，也没有 jsPDF 生成路径，本次不新增这些能力。

当前邮件功能只模拟发送并展示通知，没有独立的邮件主题字段。本次仅把发送通知中的报表名称改为新名称，不新增邮件主题或改变发送流程。

## 修改范围

同步修改以下用户可见位置：

- 小费管理主页的两个视图 Tab。
- 员工分配汇总列表的可访问名称和空状态。
- 员工分配汇总明细页的返回按钮、语义标题及辅助说明中出现的旧名称。
- 导出菜单、导出提示、PDF/打印标题、邮件发送通知、CSV 文件名和其他下载文件名中出现的旧名称。
- ARIA 标签、可访问名称和通知信息中出现的旧名称。
- 原生页面验证脚本中针对用户可见文案的断言与预期值。

## 不修改范围

以下技术契约继续保持现状：

- 路由 `/team/tips/distribution?view=employee` 与 `/team/tips/employee-reconciliation`。
- URL 参数 `view=employee`、`employeeId`、`from` 和 `return`。
- `employeeReconciliation*`、`dateTask*` 等函数名、变量名和模块导出名。
- `employeeReconciliationList`、`employeeReconciliationPanel`、`dateTaskTab`、`summaryViewSwitch` 等 DOM ID。
- 本地存储、会话存储 Key 及其数据格式。
- 导出数据字段名、金额与工时计算口径、筛选条件和权限校验。

## 兼容与回归边界

- 历史收藏链接和明细返回链接必须继续有效。
- 切换视图、前进后退、刷新和明细返回行为不变。
- 导出 PDF、邮件和 CSV 的内容及数据范围不变，只调整标题或文件名中的用户可见视图名称。
- 文案替换不得使用无边界的全仓库批量替换；只修改原生小费模块内确认属于用户界面的字符串。
- 设计文档、历史变更记录以及描述技术标识的注释不要求追溯改名。

## 验收标准

1. 小费管理主页显示 `日期分配汇总` 和 `员工分配汇总` 两个 Tab。
2. 员工汇总列表、明细页、返回按钮、空状态和辅助技术名称不再使用 `员工对账`。
3. 日期汇总 CSV/PDF 使用 `Date Tip Allocation Summary` 和 `DateTipAllocationSummary_`；员工汇总 CSV/PDF 使用 `Employee Tip Allocation Summary` 和 `EmployeeTipAllocationSummary_`；个人明细打印标题使用 `{员工姓名} 员工分配汇总`。导出字段、数值及筛选范围不变。
4. 原生小费模块所有可交互页面中不再出现作为视图名称的 `分配汇总` 或 `员工对账`；`日期分配汇总` 内部包含的连续文字不视为旧文案残留。
5. 路由、DOM ID、函数名、存储 Key 和数据结构保持不变。
6. 现有小费管理专项校验继续通过，并新增新文案存在、旧可见文案不存在以及技术标识未改动的断言。
7. 自动化校验须按三类视图的现有适用路径覆盖：日期汇总与员工汇总覆盖 CSV 标题/文件名、jsPDF 标题/文件名、打印回退标题和邮件发送通知；员工个人明细覆盖 CSV 文件名保持、打印页正文标题更新和浏览器 `<title>` 保持。页面校验覆盖 ARIA 名称、空状态和错误通知；同时断言代表性的金额、工时、员工数量、路由、DOM ID、函数名与存储 Key 保持不变。
