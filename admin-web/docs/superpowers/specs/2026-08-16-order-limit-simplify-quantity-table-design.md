# 限购数量表格简化设计

## 背景

“限购数量 > 产线配置”当前同时展示数量输入、“状态”和“实际限额”。状态与实际限额均可由输入值直接推导，信息重复，增加了表格宽度和阅读负担。

## 目标

- 删除产线配置表格中的“状态”和“实际限额”列。
- 让数量输入框同时承担配置状态和限额表达。
- 保持现有门店、人数、轮次、产线及批量配置的数据隔离和保存逻辑不变。

## 交互与语义

普通模式表格只保留两列：

1. `菜品`或`分类`
2. `订单上限`或`人均上限`

批量模式在最左侧增加勾选列，其余列与普通模式一致。

数量输入语义：

- 空输入：未配置。
- 正整数：该数字即配置上限。
- `0`：配置为禁止下单。

输入框仍使用 `min="0"`，不允许负数。现有批量设置中的“应用数量”和“设为禁止”保持不变。

## 数据处理

不改变现有数量矩阵的数据结构：

- 空输入继续写入 `configured: false`。
- 数字输入继续写入 `configured: true` 和对应的 `value`。
- `value: 0` 继续表示禁止下单。

本次只调整渲染层，不修改草稿、复制、保存、发布和正式快照结构，以兼容现有规则。

## 异常与空态

- 未选择参与门店时，继续使用现有“暂无参与门店”空态。
- 当前产线没有目标商品时，继续使用现有表格空态。
- 非法或负数输入沿用现有输入校验，不增加新的错误提示。

## 验收标准

- 普通模式不再出现“状态”和“实际限额”表头及单元格。
- 批量模式表头与行列数保持一致。
- 输入为空、正整数和 `0` 时，底层配置语义保持不变。
- 门店、人数、轮次和产线切换后，数量矩阵仍独立保存。
- 所有相关静态验证与语法检查通过。
