# 独立页面操作头部规范

用户明确整个项目独立页面。基线最新 main@d0404494，分支 codex/standalone-page-actions-20261103；仅开发，不提交合并推送。

返回、标题、页面级操作在同一头部：返回在标题左；保存、取消、预览、发布、导出等在标题右。副标题/状态在标题下；窄屏操作组换行右对齐；保持逻辑 DOM 焦点顺序。每页只一个主返回，不在底部重复页面操作。

覆盖项目原生独立详情/编辑/预览路由：权限（M/商户）与员工工作台、M 品牌/门店详情及创建、服务包详情/创建/品牌权益、硬件9类编辑布局、预设/蓝图编辑、下发详情和原生详情入口。盘点清单逐项标记已调整/已符合/非独立。普通列表不强加返回；弹框/抽屉、行内操作、内容操作、向导上一步/下一步不移到页头。iframe宿主遵守，不跨文档搬移子应用 DOM，内嵌业务应用列为边界，不宣称其内部完成。

采用共享纯页头渲染与样式，明确修改模板，不全局扫文本搬DOM、不克隆或代理按钮。保留原 data-*、权限判断/禁用、事件处理、保存/提交校验、草稿离开确认和返回上下文。移出 form 的 submit 使用明确 form=id 关联并核对事件绑定范围。底部可以保留只读状态。向导步骤不作为页面级操作。

AGENTS.md 添加 STANDALONE-HEADER-20261103-01；新增唯一公共布局三份当前态文档，测试盘点和缺口独立记录，不堆历史。TypeScript和相关回归，外部Chrome独立端口实测权限编辑/预览及硬件表单关联、业务代表页面；未访问项不得称全量验收。

员工工作台：M 平台与商户后台仍分别保存；当前角色配置维度的保存显示在页头右侧，生效权限模式不显示保存。品牌创建向导最后一步核对创建位于页头右侧；上一步、下一步仍在步骤区域。
