# 小费分配明细接收方员工权重调整

## 已确认范围

用户确认：在接收方员工明细中新增可编辑「员工权重」列，默认 1，修改后立即重算员工分配比例和金额。调整只影响当天当前规则，不回写规则默认权重；已发放记录保持只读。

## 展示与数据

- 列位于员工信息之后、分配工时或比例之前。
- 读取所属接收方的 employeeWeights[role][employee]，不得跨接收方合并；按员工实际参与角色定位配置。
- 未配置默认 1，明确配置为 0 时保留 0。仅接受有限的非负数，空值、负数和非法值提示错误并禁止确认。
- 列头说明：默认 1，修改后按当前分配方式重新计算；仅影响当天本规则。
- 普通接收方、计提接收方及剩余接收方使用各自配置。
- 切换员工及新增行时同步对应配置，不沿用上一员工的值。
- 新确认结果保存实际使用权重的独立快照字段，重新打开读取快照；已发放记录不读取当前规则。
- 老快照没有字段时显示「—」，表示未记录；不得修改历史快照补值。

## 分配计算

- 平均分配：有效参与员工的计算基数为 1 × 员工权重。
- 工时分配：有效分配工时 × 员工权重；保留现有手动工时优先规则。
- 订单占比分配：归属订单数 × 员工权重。
- 先保留规则已配置的各接收方份额，再在份额内归一化以上基数得到比例；若接收方下还有独立固定角色份额，则先划分角色份额再在角色内归一化。多个角色共享同一份额且未单独配置角色比例时，在该共享份额内统一归一化，不凭空新增角色份额。同一员工跨角色的金额按各角色分别计算再汇总。不改变贡献方金额或小费池金额。
- 权重不绕过参与资格。按小费发生时段在岗参与的规则，应在每个时间片内应用权重，再汇总结果，不能用全天权重重分全天金额。
- 修改权重或工时重算同接收方比例；之后仍可手动修改比例，以最终确认比例计算金额。后续再次修改权重时覆盖该接收方的手动比例，并在列头提示这一行为。
- 全部有效基数为 0 时分配额为 0，对应金额保留未分配，不平均兜底。
- 使用整数分和最大余数法分摊尾差，保证接收方分配额不超过份额。
- 默认值、手动值与快照值优先级：当天手动值 > 已确认快照值 > 规则值 > 1。旧快照显示未记录；用户明确重新计算时才采用规则值或 1。
- 权重调整必须经过现有未保存提示、重新确认及已发放锁定流程。不能仅移除“不支持旧权重”校验，必须让其对应计算路径支持相同权重语义后再调整校验。

## 验证

验证多个角色、多个接收方同一员工、0 权重、未配置默认 1、员工切换及新增行、历史快照缺失配置、规则变更不影响已发放快照。固定角色份额 60/40 时，调整员工权重不得挪用另一角色份额；多个角色共享一份额时应统一归一化，同一员工跨角色结果分别计算后汇总。

100 元在两名有效员工间分配：平均基数且权重 1:2 时为 33.33/66.67；工时 4:8 且权重 2:1 时为 50/50；订单 2:3 且权重 3:1 时为 66.67/33.33。全零权重时全部未分配。另测资格排除、时段内计算、跨日期/规则隔离、保存重开、非法输入、手动比例覆盖、发放后不可改及金额守恒。

## 不在范围内

修改规则默认权重、批量回填旧快照、绕过资金或参与资格校验、自动提交或推送业务代码。
