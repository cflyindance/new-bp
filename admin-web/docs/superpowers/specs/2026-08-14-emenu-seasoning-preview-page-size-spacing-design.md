# eMenu 调味预览每页数量控件间距设计

## 1. 目标

修正批量建立关联“预览确认”页面左下角每页数量控件的拥挤和竖排问题，使“每页 / 数量下拉框 / 个商品”保持清晰、稳定的一行展示。

本次只调整该控件的布局与间距，不改变分页数据、可选数量、页码按钮或其他预览区域。

## 2. 设计

- “每页”、数量下拉框和“个商品”继续作为一个完整控件组。
- 控件组使用不可换行布局，三个元素始终保持单行。
- 元素间距统一扩大为 12px。
- 数量下拉框固定为 80px 宽，避免浏览器根据内容压缩。
- “每页”和“个商品”分别使用独立文本元素，禁止单个汉字折行。
- 预览分页栏空间不足时，允许整个每页数量控件组与右侧页码区域分行，但不得拆开控件组内部内容。
- 继续沿用现有边框、颜色、圆角、字号和 eMenu 本地配置后台视觉风格，不增加新的卡片或背景。

## 3. 响应式与可访问性

- 桌面宽度下，每页数量控件位于左侧，页码位于右侧。
- 窄屏下分页栏可整体换行，每页数量控件保持完整一行。
- 下拉框仍由原有 `label` 包裹，保留可访问名称“每页 个商品”。
- 键盘操作、焦点样式以及 5、10、20、50 四个选项保持不变。

## 4. 验收

- “每页 5 个商品”在截图对应宽度下横向一行显示。
- “每页”和“个商品”不出现逐字竖排。
- 三个元素之间具有明显且一致的 12px 间距。
- 下拉框宽度稳定为 80px。
- 窄屏换行时控件组内部仍不拆分。
- 页码切换、上一页、下一页和每页数量切换功能不回归。
