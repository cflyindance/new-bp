# 自助餐规则列表移除顶部覆盖说明设计

## 目标

移除自助餐规则列表中规则分组标题下方的两类说明区：

- 黄色的 KPOS 完整覆盖/产品重定义说明。
- 蓝色的 KPOS 历史行为待验证说明。

规则列表应直接从分组标题进入规则表格，降低页面噪声。

## 范围

- 修改 `dist/Configuration center/buffet-rule.html`。
- 停止渲染分组说明区。
- 删除仅供说明区使用的 `groupNote` 渲染逻辑和 `.coverage-note` 样式。
- 保留规则表格中的“旧 KPOS 调研能力”和“覆盖结果”列及其数据。
- 不修改默认规则、编辑流程、启禁用、复制、删除或持久化逻辑。

## 验收标准

1. “整单限制”和“每轮原子规则”等分组标题下不再出现黄色或蓝色说明框。
2. 规则表格仍展示“旧 KPOS 调研能力”和“覆盖结果”。
3. 列表中的编辑、复制、启用/禁用和删除操作不受影响。
4. 页面脚本无语法错误，浏览器可正常渲染规则列表。
