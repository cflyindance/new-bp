# 员工分配汇总指标精简设计

## 背景

“员工分配汇总”当前同时展示门店/日期层的小费池指标和员工层的处理指标。两组数据统计对象不同，“已分配”“未分配”等字段又没有明确单位，容易让用户误认为它们是当前员工筛选结果的金额汇总。

## 目标

- 员工分配汇总只展示员工维度的关键指标。
- 明确人数、金额和处理状态的统计口径。
- 指标与当前员工列表使用相同筛选结果。
- 没有已确认结果时提供明确的金额值，不使用含义不明的破折号。

## 非目标

- 不调整日期分配汇总的小费池指标。
- 不改变小费分配、确认分配、取消分配和金额计算逻辑。
- 不新增后端接口或持久化字段。
- 不改变员工列表的列、排序或进入明细逻辑。

## 页面结构

日期分配汇总继续展示现有的“原始小费、入池金额、已分配、未分配、小费池数量”。切换到员工分配汇总时隐藏这组日期/小费池指标，仅展示一组四列员工指标：

1. **当前筛选员工数**：当前员工列表中符合门店、日期、角色、员工和状态筛选的去重员工数量，显示为 `N 人`。
2. **已确认最终获得合计**：当前筛选员工中，已确认且校验通过的最终获得金额之和，显示为货币金额。
3. **已完成人数**：当前筛选员工中状态为已完成的员工数量，显示为 `N 人`。
4. **待确认人数**：当前筛选员工中尚未完成确认的员工数量，显示为 `N 人`。

“已确认最终获得合计”下方保留辅助说明：“仅统计已确认且校验通过的结果”。其余指标不添加解释文案。

## 数据与筛选口径

四项指标从员工列表应用全部有效筛选后的**完整员工结果集**派生，不从未过滤的员工全集单独计算，也不只统计当前分页或当前可视窗口。统计发生在分页、虚拟滚动或其他前端窗口裁剪之前。有效筛选包含：

- 当前门店；
- 当前共享日期范围；
- 角色；
- 员工；
- 员工状态。

筛选发生变化时，先生成员工聚合记录并应用全部有效条件，再用同一结果同时渲染指标和列表。员工数量按稳定员工 ID 去重，不按显示名称去重。

当前员工聚合状态固定映射如下：

- 存在规则引用失效、确认结果校验失败等问题时，原始状态为“异常”；不计入已完成人数或待确认人数。
- 不存在异常，但筛选日期范围内仍有未确认分配日期时，原始状态为“待处理”；计入“待确认人数”。
- 不存在异常，且筛选日期范围内没有未确认分配日期时，原始状态为“已完成”；计入“已完成人数”。

“已完成人数”和“待确认人数”互斥。异常人数沿用现有表现，以“另有异常 N 人”的辅助文案展示在“待确认人数”指标下方，因此始终满足：`当前筛选员工数 = 已完成人数 + 待确认人数 + 异常人数`。员工状态筛选为“异常”时，前两项人数均为 `0 人`，辅助文案展示当前异常人数。

## 空值与边界状态

- 没有符合筛选条件的员工时：员工数、已完成人数、待确认人数均显示 `0 人`，金额按门店币种显示零金额（例如美元门店为 `$0.00`）。
- 有员工但没有已确认结果时：金额按门店币种显示零金额，并继续展示统计说明。
- 部分员工已确认时：金额只汇总已确认且校验通过的员工，不把待确认员工的预估金额计入。
- 金额格式沿用页面现有货币格式化函数和门店币种规则。
- 当前页面从本地同步数据构建员工聚合结果，不存在独立的请求加载、请求失败或无权限状态，本次不新增这些状态。若未来改为异步数据源，加载中应将指标组标记为 `aria-busy="true"` 并以 `—` 占位；请求失败应显示页面级错误提示及重试入口并以 `—` 占位；无权限应显示无权限空状态并隐藏指标组。三种状态均不得用零值冒充有效结果。

## 视觉与响应式

指标保持现有白色圆角卡片和四等分结构，不引入新的颜色或图标。桌面端四列同行；窄屏沿用当前指标条的响应式列数。所有人数值包含“人”单位，金额包含币种符号。

辅助说明的文字颜色必须满足现有设计系统的次级文字对比度，不通过降低透明度弱化到不可读。

## 可访问性

- 指标组保留可识别的分组名称“员工分配结果概览”。
- 指标标签不得只依赖相邻位置解释数值单位。
- 按门店币种格式化的零金额表示真实零值；未来若引入加载中、请求失败和无权限状态，不得复用该值。
- 视图切换后，隐藏的日期指标不应继续进入读屏顺序。

## 验收标准

1. 日期分配汇总仍展示原有五项小费池指标。
2. 员工分配汇总不展示“原始小费、入池金额、已分配、未分配、小费池数量”。
3. 员工分配汇总只展示“当前筛选员工数、已确认最终获得合计、已完成人数、待确认人数”。
4. 四项指标与员工列表使用完全相同的门店、日期、角色、员工和状态筛选结果。
5. 人数均显示“人”单位；零金额按门店币种格式显示（美元门店为 `$0.00`），无确认结果时不显示 `—`。
6. 部分员工已确认时，金额仅包含已确认且校验通过的记录。
7. 视图切换不会改变筛选条件，隐藏指标不会进入读屏顺序。
8. 桌面和窄屏布局均无溢出，辅助说明清晰可读。
9. 四项指标统计完整筛选结果集，不随分页或可视窗口变化；异常员工仅进入异常辅助计数，三类状态人数之和等于当前筛选员工数。
