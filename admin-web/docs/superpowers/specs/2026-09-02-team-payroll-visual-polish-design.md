# Team Payroll 视觉还原与滚动修复设计

## 目标

以用户提供的 Payroll Management 设计稿为唯一视觉基准，修正当前原生 Payroll 页面中的滚动、整体留白、卡片、表格和表单控件样式。保留主项目左侧导航、顶部账号栏、现有字段结构、数据与交互行为。

## 范围

- `/team/payroll-report` 页面内部的 Payroll 视觉样式。
- 主内容区纵向滚动和考勤宽表横向滚动。
- 顶部操作区、筛选器、员工信息卡、考勤汇总卡、周明细表及 Manage Payroll 表单。
- 桌面端主视图，并保证较窄窗口不破版。

不调整业务计算、字段名称、数据来源、保存逻辑、导出逻辑或主项目导航结构。

## 实现方案

在生成的 `payroll-page.css` 之后加载一份人工维护的 `payroll-polish.css`。修正层限定在 Shadow Root 内的 `.team-payroll-page`，以稳定覆盖原 TipOut CSS 中的重复规则，同时避免污染主项目。

滚动采用单一纵向滚动容器：主路由面板保持固定可用高度，`[data-team-payroll-root]` 填满面板，Shadow Root 内页面不以内容高度撑开宿主；由路由面板承担纵向滚动。考勤表仅在内容宽度不足时承担横向滚动，禁止嵌套纵向滚动。

## 视觉规格

- 页面背景为浅灰，内容画布为白色，画布圆角约 16px。
- 页面主留白 20–24px，模块纵向间距约 20px。
- 顶部按钮和筛选胶囊高度约 40–42px，操作按钮圆角约 10–12px。
- 员工 Hero 使用深色横向卡片，圆角约 14px，信息与操作保持单行层级。
- 三张考勤汇总卡使用浅灰背景、弱边界、约 14px 圆角和一致内边距。
- 周摘要条使用浅灰底；明细表为紧凑行高、细分割线和稳定列宽。
- Manage Payroll 分组使用浅灰背景；输入框为白底、1px 灰边、约 12px 圆角和 42px 高度。
- 视觉密度、文字大小和对齐关系以设计稿为准，不引入额外装饰或动效。

## 状态与交互

所有现有弹窗、筛选、编辑、员工切换、保存和导出行为保持不变。聚焦态使用主项目蓝色描边，禁用态和占位符保持清晰可辨。滚轮在 Payroll 内容任意非弹窗区域均可驱动页面纵向滚动。

## 验证

- 静态检查专属修正 CSS 的作用域和关键视觉规则。
- TypeScript 与生产构建通过。
- 浏览器验证无 iframe、主导航与顶部栏存在。
- 验证页面滚轮能从顶部移动到 Manage Payroll 底部。
- 验证考勤表、输入框和三类弹窗仍可交互。
- 在常用桌面视口下与设计稿对照截图检查间距、圆角、边框和密度。
