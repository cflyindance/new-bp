# 菜单结构层级与选中态视觉优化设计

日期：2026-08-15  
状态：用户已确认设计方向 A，待实施

## 1. 背景与目标

菜单路由配置页已经采用“屏保式单画布”结构，但左侧菜单树仍存在以下问题：

- 左侧宽度约 300–330px，名称、Key、层级、类型标签和悬停操作同时出现时拥挤。
- 二级、三级菜单主要依赖缩进表达，父子关系不够直观。
- 当前选中态仅使用浅色背景，与普通悬停状态差异不足。
- 右侧详情只显示当前节点级别和 Key，缺少与左侧树结构对应的完整路径。

本次目标是在不改变菜单字段、JSON 格式、树操作和发布逻辑的前提下，提高菜单层级辨识度、当前选中反馈和左右区域的视觉关联。

## 2. 设计范围

### 2.1 包含

- 左侧菜单树的自适应宽度。
- 一级、二级、三级节点的缩进规则和父子连接轨道。
- 节点行的信息排布、选中态与悬停态。
- 节点操作按钮在选中和悬停状态下的显示规则。
- 右侧详情标题下的完整父级路径。
- 1024px、1280px、1440px 桌面视口下的适配。

### 2.2 不包含

- 不新增、删除或重命名 JSON 字段。
- 不改变菜单树最大三级限制。
- 不改变搜索、拖拽、展开/收起、新增、编辑、复制、删除和问题定位逻辑。
- 不改变兼容只读子树的保护规则。
- 不改变草稿、发布、导出和全屏预览行为。
- 不增加用户拖拽调整栏宽或栏宽持久化功能。

## 3. 布局规则

### 3.1 左右区域比例

左侧菜单树使用自适应宽度：

```css
width: clamp(340px, 34%, 400px);
```

- 最小宽度 340px，保证三级缩进后仍能展示主要名称和类型。
- 常规宽度占主白色画布的 34%。
- 最大宽度 400px，避免菜单树反向挤压右侧详情。
- 右侧详情继续使用剩余空间，并保持独立纵向滚动。
- 页面本身不得因菜单树宽度产生横向滚动。

### 3.2 窄屏适配

- 管理后台最低验收宽度为 1024px。
- 在 1024px 视口中，左侧保持 340px，右侧详情允许文本换行和内容区内部滚动。
- 在 1280px 与 1440px 视口中，左侧按 34% 增长，但不超过 400px。
- 底部固定工具区不得遮挡左侧树或右侧详情。

## 4. 菜单层级轨道

### 4.1 缩进

- 一级菜单：0px 额外缩进。
- 二级菜单：24px 额外缩进。
- 三级菜单：48px 额外缩进。
- 历史第四级兼容节点：72px 额外缩进，并使用虚线末级轨道表达只读兼容层。
- 若历史兼容数据超过四级，缩进上限仍为 72px，通过第二行的实际 `N 级` 和“兼容保留”标签表达真实深度，避免继续压缩内容区。
- 节点展开按钮、名称和类型标签使用稳定列位，展开/收起时不发生横向跳动。

### 4.2 连接线

- 二级、三级节点左侧显示 1px 浅灰色竖向轨道。
- 每个子节点使用短横线与所属竖向轨道连接。
- 三级节点同时保留一级到二级、二级到三级两段父链轨道。
- 第四级及更深兼容节点保留前三段父链，并使用一段虚线末级轨道连接当前节点；虚线表示该层级仅为历史只读兼容展示。
- 轨道颜色使用低对比度中性灰，不使用主色，避免与选中态竞争。
- 搜索过滤时只绘制当前可见结构对应的轨道，不制造不存在的父子关系。

## 5. 节点信息层级

- 节点最小高度约 48px，并使用稳定的两行结构。
- 第一行显示菜单名称、错误/警告状态点和节点操作区；名称为主要信息，使用 13px 中等字重。
- 第二行左侧显示 `Key · N 级`，右侧显示状态标签；Key 使用等宽字体或项目现有代码字体，颜色弱化。
- 页面类型、目录或兼容状态标签固定在第二行右侧，不参与层级缩进。
- `display: false` 继续显示“隐藏”标签；不得因本次视觉重排丢失隐藏状态。
- “兼容保留”替代普通页面类型标签，隐藏状态可与兼容标签同时显示。
- 第二行最多展示两个标签；若后续出现更多状态，保留“兼容保留/页面类型”和“隐藏”的优先级，其余状态折叠到“更多”操作的完整信息中。
- 错误和警告继续使用红色、琥珀色状态点，靠近菜单名称展示。
- 超长名称和 Key 使用单行省略，不允许挤压类型标签和操作按钮。

## 6. 交互状态

### 6.1 默认态

- 白色或透明背景，无可见边框。
- 节点操作按钮隐藏。
- 层级轨道保持可见。

### 6.2 悬停态

- 使用非常浅的中性灰背景。
- 显示当前节点允许的新增、编辑和更多操作。
- 悬停态不得使用与选中态相同的青绿色背景或边框。
- 节点内部任一元素获得键盘焦点时，使用 `focus-within` 显示与悬停态相同的允许操作。

### 6.3 选中态

选中节点同时使用以下反馈，缺一不可：

- 整行浅青绿色背景。
- 1px 青绿色细边框。
- 左侧 4px 深青绿色强调条。
- 菜单名称使用深青绿色和加粗字重。
- 类型标签切换为浅青底、青色边框和深青色文字。
- 节点操作按钮保持可见，无需再次悬停。
- 操作按钮固定在第一行右侧，最多占用约 72px；名称在剩余空间内省略。类型和隐藏标签位于第二行，不与操作按钮竞争同一横向空间。

选中态不使用整行深青绿色反白，避免在长树中产生过强色块并抢夺右侧详情的注意力。

### 6.4 焦点态

- 键盘聚焦节点时显示清晰的焦点环。
- 选中和焦点同时存在时，焦点环应位于选中边框外侧，不能覆盖左侧强调条。
- 使用 Tab 聚焦未选中节点内部时，其允许操作必须可见且可继续通过 Tab 访问。

## 7. 右侧详情关联

- 右侧详情标题继续显示当前节点名称。
- 标题下增加完整路径，例如：`运营中心 / 经营看板`。
- 路径根据当前树结构实时计算，不写入菜单节点，也不进入 JSON 导出。
- 路径使用单行省略，悬停时通过原生 `title` 展示完整内容；路径后继续显示菜单级别和页面类型标签，窄屏时标签不得被路径挤出可视区域。
- 左侧切换节点后，右侧路径与详情内容同步更新。
- 节点重命名或拖拽改变父级后，路径必须随页面重新渲染立即更新。

## 8. 兼容与状态规则

- 兼容只读节点继续显示“兼容保留”标签，并遵循原禁止编辑、复制、移动、删除和添加子节点规则。
- 第四级及更深兼容节点使用 72px 最大缩进、虚线末级轨道和实际 `N 级` 文案，不得被误显示为三级可编辑节点。
- `display: false` 节点继续显示“隐藏”标签。
- 包含错误或警告的选中节点同时保留状态点和选中态；状态点不得被背景色隐藏。
- 拖拽时继续使用现有放置位置提示，轨道只负责表达静态层级，不替代拖拽反馈。
- 搜索结果自动展开命中路径的现有行为保持不变。

## 9. 验收标准

- 左侧菜单树宽度符合 `clamp(340px, 34%, 400px)`。
- 一级、二级、三级节点分别呈现 0、24、48px 的视觉缩进。
- 历史第四级兼容节点呈现 72px 缩进与虚线末级轨道；更深兼容节点保持 72px 最大缩进并显示真实级别。
- 二级和三级节点能通过竖向轨道与短横线识别父子关系。
- 选中节点同时具有浅青底、青色边框、左侧 4px 强调条和加粗深青色名称。
- 选中节点操作按钮常驻；未选中节点在悬停或 `focus-within` 时显示允许操作，并可继续通过 Tab 访问。
- 在 340px 最小宽度和三级 48px 缩进下，名称、操作区、类型/兼容标签及“隐藏”标签无重叠；超长名称和 Key 正确省略。
- 右侧详情显示与左侧选中节点一致的完整路径；长路径正确省略并可通过 `title` 查看全文。
- 节点重命名或拖拽改变父级后，右侧路径立即更新。
- 1024px、1280px、1440px 视口下无页面横向滚动、标签遮挡或底栏覆盖。
- 搜索、展开/收起、拖拽、新增、编辑、复制、删除、校验定位、全屏预览和导出 JSON 行为与修改前一致。
- 参考 JSON 兼容测试和生产构建通过。
