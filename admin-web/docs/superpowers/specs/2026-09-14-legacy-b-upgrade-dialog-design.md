# 老B平台升级提示对话框设计

## 目标

用户每次进入老B平台商户页时，立即看到新版后台升级提示。用户可以切换到品牌版新版后台，或暂时关闭提示并继续浏览老B平台。

## 范围

- 仅修改老B平台全屏静态页及其进入新版后台的交互。
- 不接入接口，不记录关闭状态，不改变商户卡片内容。
- 保留老B平台的悬浮球；隐藏新版后台顶栏、侧栏的现有行为不变。

## 展示规则

- 每次 `mountLegacyBShell()` 创建新的老B页面 DOM 时默认展示对话框；同路由发生应用重挂载也视为再次进入并重新展示。
- 刷新该路由会再次展示。
- 从其他视角离开后再次进入老B平台，会再次展示。
- 「暂不切换」关闭当前 DOM 中的对话框；只要该 DOM 未被重新挂载，本次浏览期间不再自动弹出。
- 不允许点击遮罩或按 Escape 关闭，用户必须选择一个明确操作。

## 视觉与无障碍

- 在老B页面内容上方覆盖半透明深色遮罩，中央显示白色圆角卡片。
- 弹窗层级高于商户页内容、低于悬浮球，保证悬浮球仍可见；弹窗打开期间悬浮球仅展示，不可点击、不可聚焦，也不能用于离开当前页面。
- 标题为「全新后台已上线」。
- 正文为「操作更顺、加载更快、数据更清晰。您当前的旧版入口即将停止维护，建议现在花 1 分钟切换体验。」
- 主按钮为「立即切换到新版」，次按钮为「暂不切换」。
- 使用 `role="dialog"`、`aria-modal="true"` 和可关联的标题、正文标识。
- 打开后将焦点放在主按钮；弹窗展示期间阻止背景内容和悬浮球接收指针操作，并将 Tab/Shift+Tab 焦点循环限制在两个操作按钮内。
- 小屏幕下按钮纵向排列，大屏幕下横向排列。

## 交互与状态流

### 立即切换到新版

1. 退出老B平台 shell 模式。
2. 将新版后台视角设为品牌版，并选择默认锚点品牌（如存在）。
3. 同步品牌版所需的数据范围状态。
4. 跳转到 `#/nav-home` 并重新挂载应用。

该行为复用现有视角切换的品牌版逻辑，避免弹窗单独维护另一套状态切换规则。

### 暂不切换

1. 隐藏或移除当前对话框。
2. 恢复页面内容交互。
3. 焦点移到带 `tabindex="-1"` 的「您的商户」主标题；如果标题节点不存在，则安全跳过聚焦，不影响页面交互。
4. 不写入 localStorage、sessionStorage 或模块级关闭状态。

## 代码边界

- `src/shell/legacy-b-shell.ts`：渲染对话框、绑定关闭和切换按钮。
- `src/shell/view-switch-control.ts`：导出或复用切换到品牌版的单一入口，保证悬浮球和弹窗行为一致。
- `scripts/verify-legacy-b-platform.mjs`：增加静态契约检查，覆盖文案、按钮、对话框语义和品牌版切换入口。

## 异常与降级

- 默认品牌不存在时，仍进入品牌版视角并跳转 `#/nav-home`，由现有范围解析逻辑选择可用范围。
- 若预期按钮节点不存在，绑定逻辑安全返回，不影响老B页面和悬浮球展示。
- 每次重挂载都生成新的页面 DOM 和弹窗；事件只绑定当前 DOM，不保留上一实例的监听或关闭状态。

## 验收标准

1. 每次进入或刷新老B平台时，对话框默认展示。
2. 页面顶栏和侧栏继续隐藏，悬浮球继续展示。
3. 点击「暂不切换」后弹窗关闭，焦点移至「您的商户」主标题，商户页与悬浮球恢复交互。
4. 点击「立即切换到新版」后进入品牌版 `#/nav-home`，老B模式退出。
5. 点击遮罩和按 Escape 均不会关闭弹窗。
6. 弹窗打开期间悬浮球保持可见但不可点击或聚焦，Tab/Shift+Tab 仅在两个按钮之间循环。
7. 同一路由应用重挂载后弹窗重新出现；关闭状态不跨 DOM 实例保存。
8. 桌面和窄屏下弹窗不溢出，按钮文案完整可见。
9. 静态契约脚本验证文案、按钮、dialog 语义和品牌版切换入口；浏览器交互验证默认展示、焦点循环、背景及悬浮球不可操作、关闭后焦点恢复、切换行为和重挂载重现。
10. TypeScript 检查和生产构建通过。
