# 老 B 平台升级弹框交互设计

## 目标

用户从视角切换进入老 B 平台时，明确提示新版后台已上线，并允许用户立即进入当前品牌的新版后台，或暂时停留在老 B 平台。

## 展示规则

- 每次从其他路由进入 `/legacy-b/merchants` 都展示升级弹框。
- 刷新老 B 平台页面后重新展示。
- 点击“暂不切换”不写入本地或会话记忆；下次进入仍展示。
- 点击“暂不切换”后，同一次连续停留中的普通重绘不重新展示。
- 弹框打开时，老 B 页面作为背景保留，但不可操作。

## 页面与操作

弹框标题为“全新后台已上线”，说明新版后台在操作、加载和数据展示上的改善。

- 主操作“立即切换到新版”：退出老 B 独立壳层，切换为连锁布局下的“品牌多门店”数据视角，进入当前品牌的新版后台首页。
- 次操作“暂不切换”：仅关闭当前弹框，继续停留并使用老 B 商户页。
- 点击遮罩不关闭弹框，避免误触。
- `Escape` 等同“暂不切换”。

## 无障碍与焦点

- 弹框使用 `role="dialog"`、`aria-modal="true"`，并关联标题与描述。
- 打开后焦点默认落在“立即切换到新版”。
- `Tab` 与 `Shift+Tab` 的焦点限制在两个操作按钮之间循环。
- “您的商户”标题提供稳定的 `tabindex="-1"` 焦点目标。关闭时先解除页面背景的 `inert`，再将焦点回到该标题。
- 弹框存在期间，页面背景和 Demo 视角切换悬浮球均设为不可交互。

## 状态流

1. 用户选择“老B平台”。
2. 应用进入 `/legacy-b/merchants` 并渲染老 B 商户页。
3. 升级弹框立即显示并取得焦点。
4. 用户选择：
   - 立即切换：进入当前品牌的“连锁布局 · 品牌多门店”新版后台首页。
   - 暂不切换或按 `Escape`：关闭弹框并停留在老 B 商户页。
5. 用户再次进入或刷新老 B 平台时，流程从第 2 步重新开始。

## 错误与边界

- 视角切换受限时，沿用现有权限限制，不允许进入老 B 平台。
- 进入老 B 前的当前品牌 ID 继续保存在现有品牌锚点中。主操作优先读取该锚点；没有已存锚点时，使用当前授权组织上下文的默认品牌。
- 若已存品牌已失权，按当前授权组织上下文重新解析默认品牌。
- 若最终没有任何可用品牌，主操作不可跳转，弹框保持打开并展示“暂无可切换的品牌，请联系管理员”的错误提示；“暂不切换”仍可使用。
- 切换新版复用品牌多门店视角的统一切换函数，避免分别维护 shell、连锁布局、品牌视角、品牌锚点和首页路径。
- 弹框 DOM 缺失时不阻断老 B 页面展示，但绑定函数应安全返回。

## 验收标准

1. 每次进入或刷新老 B 平台均显示弹框。
2. “立即切换到新版”退出 `legacy-b` shell，进入新版后台首页；侧栏布局为 `chain`，数据视角为 `brand`，品牌 ID 与进入老 B 前的有效品牌锚点一致。
3. “暂不切换”和 `Escape` 均关闭弹框并停留在老 B 页面。
4. 点击遮罩不会关闭弹框。
5. 弹框打开时背景及悬浮球不可操作，焦点不会离开弹框。
6. 关闭弹框时先解除背景不可交互状态，随后 `document.activeElement` 为“您的商户”标题。
7. 不持久化关闭状态；关闭后的同次停留重绘不弹出，离开重进或刷新后重新弹出。
8. 没有可用品牌时不跳转，展示错误提示且仍可暂不切换。
