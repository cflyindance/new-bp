# 日期任务未分配金额展示调整

## 目标

在原生“小费管理 > 日期任务”列表中，避免未分配日期展示尚未产生业务含义的分配结果金额。

## 已确认方案

采用方案 A：未分配日期行的“扣除”“分得”“分配后”统一展示 `—`；“分配前”金额和“待分配”状态保持现状。已分配日期行继续显示全部金额。

## 展示规则

- 判断条件沿用现有逐日行的 `allocated` 布尔值。
- `allocated === false` 时：
  - 分配前：显示现有格式化金额；
  - 扣除：显示 `—`；
  - 分得：显示 `—`；
  - 分配后：显示 `—`；
  - 状态：显示“待分配”。
- `allocated === true` 时，六列内容保持当前展示逻辑。

## 数据边界

- 仅在日期任务表格单元格渲染时替换展示文本。
- 不清空、覆盖或重新计算逐日数据中的 `deducted`、`received`、`after` 字段。
- 不修改顶部金额概览、员工对账列表、员工对账明细、导出、分配或取消分配逻辑。
- 日期完成分配后，下一次渲染立即恢复三个字段的格式化金额。

## 验收

- 未分配行的“扣除”“分得”“分配后”均为 `—`，不出现 `$0.00` 或其他金额。
- 未分配行的“分配前”和“待分配”状态保持正常。
- 已分配行继续显示三个字段的真实格式化金额。
- 分配、取消分配后，行展示随 `allocated` 状态同步切换。
- 原生页面契约测试与生产构建通过。
