# TipOut 日期分配汇总顶部指标文案设计

## 背景与目标

日期分配汇总顶部的四个金额指标按所选门店和日期范围汇总。随后用户确认下方每日列表的四个金额列也统一加“总”；列表每行仍表示该日期的总金额，不改变统计口径。

## 已确认方案

日期分配汇总顶部四个指标标签及下方每日列表对应四个金额列统一使用：

| 当前文案 | 新文案 |
| --- | --- |
| 原始小费 | 原始总小费 |
| 入池金额 | 入池总金额 |
| 已分配 | 已分配总额 |
| 未分配 | 未分配总额 |

员工分配汇总、分配明细及其他页面不在本次范围内。

## 实现边界

- 同步更新日期分配汇总模板的初始标签和运行时重新渲染时写入的标签，避免筛选或刷新后恢复旧文案。
- 金额计算、日期范围、筛选、状态、空值表现及布局均不改变。
- 验证初次加载与重新渲染后的四个顶部标签一致，并确认逐日列表四个金额表头使用相同的新文案。
