# TipOut 日期分配汇总顶部指标文案设计

## 背景与目标

日期分配汇总顶部的四个金额指标按所选门店和日期范围汇总，但当前文案与下方逐日列表表头相同，容易误认为单日金额。仅通过文案明确顶部展示的是范围总额。

## 已确认方案

只修改日期分配汇总顶部四个指标标签：

| 当前文案 | 新文案 |
| --- | --- |
| 原始小费 | 原始总小费 |
| 入池金额 | 入池总金额 |
| 已分配 | 已分配总额 |
| 未分配 | 未分配总额 |

下方逐日列表的“原始小费、入池金额、已分配、未分配”表头保持原样。员工分配汇总、分配明细及其他页面不在本次范围内。

## 实现边界

- 同步更新日期分配汇总模板的初始标签和运行时重新渲染时写入的标签，避免筛选或刷新后恢复旧文案。
- 金额计算、日期范围、筛选、状态、空值表现及布局均不改变。
- 验证初次加载与重新渲染后的四个顶部标签一致，并确认逐日列表表头未变。
