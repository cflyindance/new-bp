# 菜单路由配置二级导航设计

已获用户确认，变更 NAV-ROUTING-20261106-02，基线 main@ec151927。

- 菜单路由配置作为父导航；点击复用 M 平台公共覆盖式子导航滑层，不内嵌展开。
- 子项顺序：导航编排、页面注册中心；使用 `/m-platform/nav-blueprint/navigation`、`/m-platform/nav-blueprint/page-registry` 独立地址。
- 父根地址和旧编辑地址默认导航编排。刷新、浏览器前进后退按地址恢复页面及唯一选中态。返回按钮仅返回导航层，不保存数据。
- 移除页内 Tab，页面标题随子页面变化。保留原操作入口、业务表单和目录浏览功能。
- 两子页面共用既有 `m:page:routing` 权限；不新增资源、授权或修改角色持久化数据。隐藏时两入口都不可访问，只读时目录仍能搜索和查看。
- 子页面切换如原 Tab 一样保留当前节点及内存草稿，不自动保存或发布。原编辑器切换菜单时的未保存提示、发布校验、JSON 与仓库逻辑不变。
- 验收覆盖父层打开/返回、两个地址及旧地址、刷新/历史导航、无 Tab、唯一选中、目录搜索详情、编辑草稿往返保留、原菜单切换提示、权限不扩展。

未包含业务参数、校验规则、授权策略或后端接口调整。
