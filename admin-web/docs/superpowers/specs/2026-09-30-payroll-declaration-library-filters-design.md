# 声明模板列表筛选与员工选择入口

用户已确认：增加门店、模板范围、状态组合筛选；列表新增操作列“选择员工”，保留详情分配入口。

## 页面与交互

模板列表上方增加一行筛选：门店（全部门店/授权具体门店）、模板范围（全部/企业通用/指定门店）、状态（全部/草稿/已发布/已停用）及重置。默认均为全部，选项变化立即更新结果，三项 AND 组合。筛选不改变全局门店、不修改模板与员工数据；不请求未授权门店。列表六列依次为模板名称、模板范围、门店、状态、声明内容、操作。

选择门店 A 时，保留 A 的门店模板和企业通用模板；再选“指定门店”只剩 A 的门店模板，再选“企业通用”只剩企业模板。单店账号门店选项仍仅包含其授权门店。“全部门店”指当前授权集合，而非全企业权限。

状态沿用当前列表最新版本（版本号最大）的展示状态，筛选和标签严格一致。无版本的未配置模板仅在“全部”中出现。最新版本为草稿、旧版仍有效发布时，状态为草稿，但可以选择员工：入口旁或提示中说明“使用当前已发布版本”。不将草稿正文分配给员工。

模板尚无任何数据时显示“暂无模板”；筛选结果为空时显示“暂无符合条件的模板”，保留筛选与重置。加载失败保留错误提示，不能当作空结果。进入详情、返回列表及保存刷新保留当前筛选；退出设置后重新打开或全局组织/门店范围变化时重置，避免旧门店 ID 残留。

## 选择员工

每行操作列提供“选择员工”。有效条件：family.activeVersionId 对应属于该 family 且 status=published 的版本。无有效发布版本时禁用并说明“请先发布模板”；加载/忙碌期间禁用。点击直接复用现有批量分配面板，不先打开详情。模板名称仍进入详情；详情原入口保留。

列表门店筛选不改变模板适用范围，也不自动缩小分配面板范围：企业模板进入后仍可选授权门店内员工，门店模板仍限定绑定门店。沿用原有员工筛选、替换提示、即时保存、失败重试、历史快照保护。关闭面板焦点返回发起按钮，列表筛选和滚动位置不被重置。

## 验收

- 授权门店 A/B、企业模板、各状态组合的过滤与重置正确；越权门店不出现在选项中。
- 标签状态与状态过滤一致；无版本仅全部可见；新版草稿与旧发布版并存时可分配且解释清晰。
- 六列对齐，空态 colspan=6；表格与筛选控件在窄屏可用。
- 列表入口直接打开正确模板的员工面板；禁用模板不能操作；关闭保留筛选和焦点。
- 保存刷新保留筛选；全局范围变化和重新打开按规则重置；历史声明、金额不受影响。
- 更新现有五列表格测试为六列，增加组合过滤/行操作/空态自动化，浏览器验证入口和筛选主路径。
