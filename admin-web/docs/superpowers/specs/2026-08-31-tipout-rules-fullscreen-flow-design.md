# TipOut 规则流程全屏覆盖设计

## 背景

小费分配汇总通过同源 iframe 嵌入主应用。汇总页新增的“新建/查看规则”目前只在 iframe 内跳转，因此主应用侧栏和顶部栏仍然可见。用户要求规则列表与规则编辑参照营销中心屏保流程，以覆盖整个应用视口的方式展示。

## 目标

- 汇总页继续显示在主应用内容区，侧栏和顶部栏保持可见。
- 从汇总页进入规则列表或规则新增页后，将现有 TipOut iframe 提升为覆盖整个应用视口的全屏层。
- 从规则列表进入新增或编辑页面后持续保持全屏。
- 规则列表提供左上角“返回小费分配汇总”入口；返回汇总页时退出全屏并恢复主应用布局。
- 团队管理和报表中心内嵌的 TipOut 汇总入口采用相同交互。

## 非目标

- 不调用浏览器原生 Fullscreen API。
- 不创建新规则页面或复制规则列表内容到父应用。
- 不修改规则存储、创建、编辑、复制、删除或小费分配逻辑。
- 不改变小费分配明细、员工列表和薪资页面的现有导航语义。

## 全屏架构

### 父应用控制

新增独立的 TipOut 规则流程全屏控制模块。团队管理小费管理 iframe 与报表中心小费分配 iframe 均增加稳定的数据标识；主应用每次挂载后扫描并绑定这些 iframe 的 `load` 事件。

父应用在 iframe 每次加载后读取同源子页面 URL，并根据文件名维护全屏状态：

- `rules.html`：进入全屏。
- `rule-add.html`：进入或保持全屏。
- `index.html`：退出全屏。
- 其他 TipOut 页面：保持当前状态，不擅自切换。

全屏状态直接作用于同一个 iframe：使用固定定位覆盖视口、100vw × 100dvh、高于侧栏与顶部栏的层级、无边框和不透明背景。规则列表到规则编辑的跳转继续使用同一个 iframe 浏览上下文，不重建页面，也不丢失已有交互状态。

### 样式复用

全屏尺寸、定位、层级与背景严格复用 `marketing-screensaver-flow-fullscreen` 的屏保范式。为 TipOut 使用独立语义类名，并与屏保选择器共享同一组 CSS 声明，避免把 TipOut 状态误命名为营销屏保状态。

### 子页面返回入口

`rules.html` 的页面标题区左侧增加“返回小费分配汇总”链接，目标为 `index.html`：

- 嵌入父应用时，iframe 加载 `index.html`，父应用监听器随后退出全屏。
- 直接打开 TipOut 页面时，该链接仍按普通同窗口导航返回汇总页。
- `rule-add.html` 保留现有“返回规则列表”和取消确认逻辑；回到 `rules.html` 后仍处于全屏，再由规则列表返回汇总。

## 组件与文件边界

- `src/config/tipout-rules-fullscreen.ts`：只负责 URL 到全屏状态的解析、iframe 状态同步和幂等绑定。
- `src/main.ts`：只负责为两个 TipOut iframe 添加数据标识，并在主应用挂载后调用绑定函数。
- `src/styles/app.css`：为 TipOut 全屏类复用屏保 iframe 的固定覆盖样式。
- `dist/TipOut/rules.html`：增加规则列表返回汇总入口，不修改规则表格或业务函数。
- 验证脚本：覆盖状态解析、DOM 合同和现有 TipOut 交互回归。

## 异常处理

- iframe 地址读取失败时保持当前全屏状态，避免流程中途错误退出。
- 重复挂载或重复加载同一页面时，绑定和类名切换保持幂等。
- 未找到目标 iframe 时直接返回，不影响主应用其他模块。
- 返回汇总页后必须完整移除 TipOut 全屏类与状态属性。

## 可访问性

- 规则列表返回入口使用可聚焦的原生链接，并提供清晰文案“返回小费分配汇总”。
- 全屏仅改变 iframe 布局，不模拟浏览器原生全屏，也不额外劫持 Escape。
- 规则页面原有键盘操作、焦点行为和确认弹窗保持不变。

## 验收标准

1. 团队管理或报表中心的 TipOut 汇总页保持普通嵌入布局。
2. 无规则时点击“新建/查看规则”，直接进入 `rule-add.html?poolKind=tip`，且 iframe 覆盖整个应用视口。
3. 有规则时点击“新建/查看规则”，进入 `rules.html`，且 iframe 覆盖整个应用视口。
4. 规则列表进入新增或编辑页面后继续保持全屏。
5. 规则列表左上角显示“返回小费分配汇总”；点击后加载 `index.html` 并恢复主应用侧栏和顶部栏。
6. 直接访问 TipOut 页面时，规则列表返回入口仍可正常回到汇总页。
7. 不出现浏览器原生全屏权限提示。
8. 屏保原有全屏流程不受影响。
9. TipOut 规则存储、创建、编辑、复制、删除与分配逻辑回归通过，浏览器控制台无新增错误。
10. 带查询参数或 URL hash 的 `rules.html`、`rule-add.html` 和 `index.html` 仍能解析为正确状态。
11. 同一 iframe 重复绑定不会累积 `load` 监听器；团队管理与报表中心两个嵌入上下文均通过验证。
