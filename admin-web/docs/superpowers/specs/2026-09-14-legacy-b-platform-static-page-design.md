# 老 B 平台静态商户页设计

## 背景与目标

在现有悬浮球的“视角切换”菜单中新增“老B平台”。用户点击后进入一个独立的全屏静态页面，用于展示旧版 B 平台的商户选择界面。页面不接入接口、不实现商户跳转，仅还原参考截图的视觉与固定内容。

## 已确认范围

- “老B平台”与门店版、连锁版、M平台并列出现在悬浮球的视角切换中。
- 进入后隐藏商家后台的顶栏和侧栏。
- 老 B 平台页面继续展示悬浮球，用户可通过视角切换退出该页面。
- 商户名称、Locations 数量与权限文本使用参考截图中的固定静态数据。
- 商户卡片仅展示，不触发业务跳转。
- 不接入后端接口，不增加加载、空态或错误态。

## 方案选择

采用独立应用壳层模式：在现有 `AppShellMode` 中增加老 B 平台模式，并为它提供独立的渲染与绑定模块。

未采用以下方案：

- 普通路由加 CSS 隐藏现有壳层：容易受商家后台布局状态影响，边界不清晰。
- 独立 HTML 整页跳转：会丢失当前单页应用状态，也需要重复实现悬浮球能力。

## 页面结构

页面占满视口，使用深紫色背景，并允许内容区纵向滚动。

1. 顶部品牌区
   - 左上展示黄色 MenuSifu 标志与白色 `MenuSifu` 字样。
   - 右上展示白色用户图标与固定用户名 `Fei Chen`。
2. 标题区
   - 居中展示小标题“请选择”。
   - 下方展示主标题“您的商户”。
3. 商户卡片区
   - 桌面端为两列网格。
   - 卡片使用蓝、粉、橙的柔和渐变，圆角矩形，右侧叠加低透明度品牌水印。
   - 每张卡片依次展示 Locations 数量、商户名称、用户图标与权限列表。
   - 固定展示截图中完整可辨识的四张卡片：`大飞鸽-AD`、`敦煌`、`小飞鸽-连锁集团-13041自…`、`小飞鸽-联想PC`。
   - 权限文本按截图固定为 `Cloud Report Full Access`、`Cloud Report Open API Full Access`，以及对应卡片的 `Cloud Report BO - Overview` 或 `Cloud Report - Payment Internal Access`。
4. 悬浮球
   - 复用现有悬浮球及其视角切换菜单。
   - 当前选中项显示为“老B平台”。
   - 切换至其他视角时退出老 B 平台壳层，并进入对应现有页面。

## 响应式行为

- 宽屏下内容最大宽度约为参考截图的 1420px，保持两列布局与宽松间距。
- 中小屏减小页面边距、标题字号和卡片内边距。
- 窄屏切换为单列卡片，商户长名称保持单行截断，页面允许纵向滚动。

## 代码边界

- `src/shell/app-shell-mode.ts`：扩展老 B 平台模式的读写与判断。
- `src/shell/view-switch-control.ts`：增加“老B平台”选项、当前态与模式切换逻辑。
- 新增独立的老 B 平台 shell 模块：负责静态数据、页面 HTML 和悬浮球绑定。
- `src/main.ts`：在总挂载流程中识别老 B 平台模式并渲染独立 shell。
- `src/i18n.ts`：补充中英文入口标签与提示；页面主体按参考图保留固定中文标题和英文权限文本。
- 样式优先使用项目现有 Tailwind 能力；仅在水印、特殊渐变等无法清晰表达时增加局部样式。

## 状态与路由

- 老 B 平台状态沿用现有 shell mode 的 sessionStorage 持久化方式。
- 进入时使用专用 hash 路径，确保刷新后仍能回到老 B 平台页面。
- 从老 B 平台切换到门店版、连锁版或 M 平台时，复用现有视角切换的状态清理和目标路由逻辑。
- 老 B 平台不维护卡片选中态，也不产生业务数据写入。

## 可访问性

- 页面标题使用语义化标题元素。
- 商户列表使用列表语义，静态卡片不伪装成按钮或链接。
- 装饰性水印与图标对辅助技术隐藏。
- 文本与渐变卡片保持足够对比度；悬浮球保留现有键盘与焦点行为。

## 验证与验收

1. 悬浮球“视角切换”中出现“老B平台”。
2. 点击入口后，商家后台顶栏和侧栏消失，老 B 平台全屏页出现。
3. 页面仍展示并可操作悬浮球，菜单当前项为“老B平台”。
4. 从悬浮球切换任一现有视角后，可正常退出老 B 平台。
5. 四张商户卡片的名称、Locations 数量与权限文本和参考截图一致。
6. 桌面端呈现两列卡片；窄屏呈现单列且无横向溢出。
7. 刷新老 B 平台专用路径后仍能恢复该独立页面。
8. 运行项目构建，确认 TypeScript 与 Vite 构建成功。

## 非目标

- 不实现真实商户列表查询。
- 不实现卡片点击、商户切换或权限校验。
- 不重做悬浮球视觉或现有 M 平台页面。
- 不修改 `vendor/emenu-new`，因此本需求不触发 eMenu 嵌入包发布流程。
