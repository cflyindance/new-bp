# 自助餐新建规则：仅最终保存

日期：2026-11-07。变更编号：BUFFET-SAVE-20261107-01。实施基线 main@493bbbb8，包含远端b9cee223及已合入未推送的小费修复。本文件为设计记录，三份既有文档已同步；已实施、未提交，不另立权威入口。

## 已确认范围

用户确认：新建自助餐规则仅最后保存，不支持草稿状态和下发操作；保存后默认禁用，由列表手动启用。

## 新建流程

五步保留为“规则类型 → 限购数量 → 超限授权 → 生效范围 → 确认保存”。最后一步复核内容，不再表示发布。生效门店保留在生效范围中，不增加下发门店二次选择或发布确认页。

新建页不出现保存草稿、保存草稿并返回、草稿已保存、保存并下发、发布中、下发成功等入口或状态。最后一步仅有一个页面级“保存”主操作；前四步保留步骤切换，不提供中途保存。

## 数据与操作边界

1. 打开新建页不得向规则仓库或drafts集合插入占位记录，不占用持久草稿ID。步骤切换、场景额度保存、商品选择确认均只更新页面内待保存数据，不产生业务草稿记录。
2. 不提供自动保存、恢复草稿或可跨刷新恢复的临时持久记录。内部变量可以继续使用既有编辑模型名称，但不能据此写入status=draft。当前函数initializeDraftRule、saveEditorDraft及其定时、离开和场景调用路径需逐一隔离。
3. 最后“保存”执行完整规则类型、商品、数量、区间、授权、生效范围和现有保存适用校验；不能只把status改成disabled后跳过校验。禁用规则的启用冲突与静态可满足性在列表启用时仍重新核验，不允许本任务放宽旧校验。
4. 保存成功原子写入一条status=disabled的正式规则，保留全部作者配置，不产生draft状态记录、发布任务、下发任务或active运行快照。已有prepareActivation等列表启用链路继续负责生成运行配置，不在保存时直接调用启用逻辑。
5. 规则ID在最终成功写入时分配；提交按钮执行中禁用，重复点击不产生重复规则。存储失败不跳转、不清空输入、不虚报成功；允许重试且不重复插入。存在部分写入风险时须使用现有原子仓库事务能力，不能用多次独立saveRules模拟成功。
6. 保存成功提示“保存成功，规则已禁用”，返回原规则列表上下文；新增规则如不满足当前筛选，不擅自清空用户筛选。列表启用仍沿用现有权限、确认、校验与异常处理。
7. 有未保存修改时返回、关闭或刷新触发退出保护；页面内返回提供“继续编辑／放弃并返回”，不提供保存草稿分支。放弃只丢弃当前内存配置，不删除已有正式规则。浏览器关闭／刷新采用原生保护，确认离开后输入不恢复。
8. 非自助餐的菜单下单限制新建流程保持不变。业务规则启用、禁用、门店权限和商品计量逻辑保持不变。

## 需要明确的存量边界

本需求未授权批量删除或迁移历史草稿。建议旧草稿数据先保留，按后续单独确认的方式迁移；不要因为新建流程取消草稿就自动删除用户以前填写的内容。

本次实施限定全新会话；已有编辑、复制及历史草稿保持兼容行为，是否统一改造仍待独立确认，不能自行停用已有启用规则。

## 验收场景

| 场景 | 预期 |
| --- | --- |
| 打开新建、切换步骤、选择商品和保存场景额度 | 仓库规则数、drafts数均不变；页面有未保存状态 |
| 中途刷新并确认离开 | 不产生草稿，不恢复输入 |
| 最终数据不完整 | 停留相应步骤显示错误，规则仓库不变 |
| 保存成功 | 仅新增一条禁用正式规则，无下发页面或发布副作用 |
| 存储失败后重试／快速重复点击 | 保留输入，无半写入、无重复规则 |
| 列表手动启用 | 沿用权限和完整启用校验，不因已保存跳过 |
| 取消退出 | 保留当前输入；确认放弃退出不删除其他数据 |
| 非自助餐流程 | 原保存草稿和发布行为不受影响 |
