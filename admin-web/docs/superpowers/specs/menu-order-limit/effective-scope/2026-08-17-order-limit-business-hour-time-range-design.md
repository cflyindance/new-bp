# 营业时段内时间范围限制
> [!IMPORTANT]
> **文档状态（截至 2026-08-19）：当前有效**
> **当前重建适用性：** 营业时段指定时间范围及边界校验已在 normalize、renderStepFive 和 validate 中实现，可用于当前重建。
> **替代 / 权威指向：** [文档索引](../README.md)；[当前产品 SPEC](../../../../产品PRD/exports/2026-08-19-menu-order-limit/SPEC.md)。


## 背景

生效范围第 5 步仅可选择「全天 / 午市 / 晚市」，无法在该时段内再收窄生效时间（例如午市仅 11:00–14:00）。

## 决策

- 全天、午市、晚市均支持「该时段全时段」与「指定时间」。
- 指定时间必须落在所选营业时段边界内，且不跨日。

## 字段

`draft.conditions` 新增：

| 字段 | 取值 | 说明 |
|---|---|---|
| `businessHourTimeMode` | `full` \| `custom` | 默认 `full` |
| `businessHourFrom` / `businessHourTo` | `HH:MM` 或空 | `full` 时为空 |

父时段边界：全天 `00:00–23:59`；午市 `11:00–16:59`；晚市 `17:00–23:00`。

## 交互要点

- 切换为指定时间时预填父时段起止；切回全时段清空时间。
- 切换营业时段时，若当前指定时间越界，回退为全时段并提示。
- 发布 `timeLabel` 与第 7 步复核展示指定时间文案。

## 兼容

旧草稿缺字段按 `full` 归一化。
