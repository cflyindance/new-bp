# 滑层搜索框默认清空设计

## 目标

所有 Hub 二级滑层每次从关闭状态重新打开时，搜索框必须为空，不显示登录邮箱、浏览器自动填充值或上一次打开遗留的查询。滑层保持打开期间的重绘继续保留用户当前搜索词。

## 方案

1. 在所有滑层 `set...SheetOpen(true)` 的“关闭 → 打开”边界清除对应 Hub 的内存查询；已经打开时再次设置 `true` 不清除，避免站内导航和重绘丢失输入。
2. 通用搜索输入框使用稳定且与登录无关的 `name`，并设置 `autocomplete="one-time-code"`、关闭拼写检查，降低浏览器把账号邮箱填入搜索框的概率。
3. 输入框绑定后，在查询状态为空但 DOM 被浏览器自动填入内容时立即清空 DOM 值；不触发搜索状态写入。

## 范围

覆盖通用 `subNavPlacement: sheet` 滑层以及库存、商品、营销、促销、会员、礼品卡、报表、打印、预约等专用 Hub 滑层。搜索、清除按钮、IME 输入和滑层内重绘行为保持不变。

## 验证

- 新打开任一滑层时搜索框为空，导航完整显示。
- 输入搜索词后，同一打开周期内重绘仍保留搜索词。
- 关闭并再次打开后搜索词清空。
- 登录邮箱不会出现在搜索框。
- TypeScript 与 Vite 构建通过。
