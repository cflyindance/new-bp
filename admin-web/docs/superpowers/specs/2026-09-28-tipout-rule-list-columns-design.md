# 小费规则列表：规则名称与门店拆列

日期：2026-09-28  
状态：方案 A 已确认

## 目标

小费分配规则列表中，规则名称默认直接显示。将当前“规则与门店”合并列拆为独立的“规则名称”和“门店”两列，降低查找规则和辨认所属门店的成本。

## 页面设计

- 表格列顺序：规则名称、门店、池类型与规则摘要、分配说明、操作。
- 规则名称作为首列主信息加粗显示；门店作为第二列普通文字显示，不使用标签样式。
- “引用失效”状态提示仍紧邻规则名称；已有的失效说明仍位于分配说明列。
- 长规则名称和门店名称在各自列内遵循现有溢出处理；不能覆盖相邻列或操作按钮。
- 无规则时，空状态横跨全部五列。

## 数据与交互边界

列表继续读取现有规则的 `ruleName` 和 `store` 字段，只调整表格表头与行展示，不变更存储结构、规则校验或分配算法。门店筛选、编辑、复制、删除及规则统计保持现有行为。

## 验收

1. 有规则时，“规则名称”和“门店”分别作为独立表头及对应单元格显示；名称不是隐藏在悬浮提示或详情中。
2. 长文本不会挤占其他列，操作控件仍可使用。
3. 失效规则的提示仍可见。
4. 筛选后列结构不变；无结果时空状态横跨五列。
5. 规则数据和操作结果与改动前一致。
