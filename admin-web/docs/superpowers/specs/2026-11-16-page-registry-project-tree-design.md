# 页面注册中心：项目、目录层级与独立注册页

状态：业务方案已确认，实施规格待复核。基线：main `c913d5d4`。本任务不授权提交、合并、推送。

## 已确认范围

- 支持新增项目，项目名称由用户输入。
- 注册中心按“项目 → 多级目录 → 注册页面”组织。
- 目录层级交互参照导航编排，支持新增一级目录、新增子级、移动与排序。
- 注册中心采用与导航编排一致的左右布局；左侧项目与目录标题右侧展示注册页面入口，点击后在右侧显示表单，不跳转独立页面、不打开新增弹框。
- 注册目录不自动生成商家导航，不改变导航编排的权限、关联和发布规则。
- 继续使用当前浏览器、当前站点的本地存储。

## 注册中心

左侧展示项目选择及当前项目目录树；右侧展示当前目录的注册页面。项目为空时展示新增项目入口，注册页面按钮不可用，并说明先创建项目。目录为空时允许直接注册到项目根级。

项目名称去除首尾空白后必填；同一注册中心项目名称精确重复时阻止保存。项目使用稳定内部 ID，不使用名称作为关联键。新增成功选中新项目；取消不创建记录；写入失败保留输入。

目录使用稳定 ID、项目 ID、父目录 ID 和同级顺序。目录名称去除首尾空白后必填，同一父目录下精确重名时阻止保存。目录不填写路由参数，不作为可关联页面出现在导航编排的页面选择器中。不限制层级数量；移动不得选择自身或后代，暂不提供跨项目移动。上移、下移作用于同父级目录，边界按钮禁用。展开、选择及操作后保留左侧滚动位置。

目录更多操作包含新增子级、重命名、指定移动、上移和下移；点击空白关闭。项目删除、目录删除与项目重命名不在本任务范围内，避免引入未确认的级联处置。

右侧列表沿用页面搜索、状态筛选、详情查看和注册规范入口。筛选作用于当前项目、当前目录的直属注册页面；根级不混入下级目录页面。点击目录切换列表，搜索无结果不改变目录选择。

## 右侧注册表单

入口：左侧项目与目录标题右侧点击注册页面。保留左侧树、展开和滚动状态，右侧切换为表单；点击入口不改变 URL。刷新保留项目与目录选择，但不恢复未保存表单。项目或目录已失效时展示错误，不能静默注册到其他项目。

右侧表单头部展示注册页面标题、所属项目及目录路径，操作为取消和保存注册。保留现有页面名称、页面唯一标识、维护模块、英文名称、页面类型、商家后台路由及按类型展示的入口参数。项目、所属目录默认来自入口，可在表单中选择本项目其他目录；维护模块与项目名称是不同字段，不相互覆盖。

保留现有 ID、路由全目录唯一校验、HTTP(S) 校验、四类页面参数及权限检查。仅保存当前类型需要的技术字段。保存成功关闭新增状态，返回入口项目和最终归属目录并定位新页面；不自动关联或发布导航。

有输入变更时，返回、应用内离开或切换导航需确认放弃；取消离开保留输入。刷新或关闭浏览器通过原生 beforeunload 提示保护，不能承诺刷新后恢复未保存内容。无修改时直接返回。保存失败保留输入并展示错误，不跳转、不显示成功。

## 存储与兼容

项目、目录、页面归属与页面注册记录必须使用同一次本地存储写入提交，避免页面写入成功而归属失败。采用带版本的统一注册中心存储模型；不覆写现有 v1 原始数据作为迁移前置动作。

新版存储键不存在时，先校验并读取旧 v1；首次成功写入将历史本地页面与新增数据一并写入新版单一快照，旧 v1 保持不变。新版存在后只读写新版，不再次叠加 v1。新版不存在但 v1 读取或校验失败时，同样禁止创建项目、目录和页面；新版异常时不得回退 v1 后继续写入。

现有内置页面及无项目归属的历史本地页面保留在“未归类页面”只读入口，不凭维护模块推断项目，不丢弃记录。历史本地页面继续可在导航编排选择；本任务不强制迁移归属。新格式读取失败、未知版本、重复身份或非法目录关系时，保留原始数据、显示错误并禁止写入，不能用空模型覆盖异常数据。

内置页面仍由代码清单维护，项目目录仅组织本地新增注册。注册中心写权限继续使用 `m:page:routing`，渲染禁用与提交检查同时执行；新增项目、目录与保存页面均不得绕过只读限制。项目目录数据不赋予页面访问权限。

## 验收范围

1. 自定义项目创建、重复名称、取消、写入失败、刷新保留。
2. 连续多级目录创建、移动防循环、同级排序、展开与操作保留滚动位置。
3. 同页右侧新增、入口不跳转、左侧保留、刷新选择恢复、入口失效、保存上下文及放弃编辑提示。
4. 四类页面注册、原有技术参数校验、保存后导航编排立即可选择。
5. 历史 v1 数据兼容、异常存储不覆写、配额不足不产生半条记录。
6. 只读权限下禁止全部新增写入，已有页面搜索和详情仍可用。

## 交付边界

仅本地浏览器持久化，不包含后端服务、跨浏览器同步、创建真实业务页面、自动部署或变更菜单发布业务。实现后提供独立功能分支预览与真实页面验证；未验证项如实列出。

### 项目微应用配置与页面路径

| 字段／操作 | 逻辑说明 |
| --- | --- |
| 微应用标识 | 新增项目必填，去首尾空白；项目下新注册页面复用，不在页面重复输入。 |
| 应用入口 URL | 新增项目必填，只允许 HTTP(S)；项目下新注册页面复用。 |
| 微应用路由 | 新增项目必填，以 / 开头，不含查询或 hash；写入 microAppConfig.path，不与页面路径自动拼接。 |
| 页面路径地址 | 页面级必填，沿用原绝对路径及全目录唯一校验；对应 routing.path。 |
| 页面类型与配置 | 配置微应用的项目下，新页面固定微应用类型，三项项目参数只读展示。保存时从最新项目取值，不接受页面伪造覆盖。 |
| 历史兼容 | 未配置微应用的既有项目保留原四类注册，不覆盖历史页面快照。新增项目不能省略微应用配置。 |


## 注册中心子导航

菜单路由配置下的页面注册中心为父导航，子项为项目管理与页面管理。项目管理负责新增项目和项目配置列表；页面管理保留项目选择与目录树及右侧表单，不重复新增项目入口。直接访问子页面与刷新保持对应子导航，返回逐层退出；继续使用原 routing 资源权限。
