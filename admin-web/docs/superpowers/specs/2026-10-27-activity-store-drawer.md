# 门店活跃分析详情抽屉设计

用户已采用方案：门店列表点击门店或查看详情，右侧宽抽屉展示门店详情；产线通过全部产线及六条产线页签切换，设备明细在设备行下展开。独立设备活跃分析保持现状。

固定抽屉头展示门店、品牌、活跃状态、最近点单和当前有效期间；正文滚动，页签明确选中。全部产线展示六条产线汇总及按物理设备 ID 去重的设备列表；单产线页签展示该产线统计和设备。沿用现有全部/产线/设备 scope 订单和绑定口径，不改数据计算。零订单、历史绑定、尚未配置和异常状态继续展示，异常指标为 —。

URL 继续支持原门店、产线、设备详情路径，访问时以列表为背景打开抽屉。全部产线中的设备展开使用 /store/:storeId/device/:deviceId；单产线继续原 /store/:storeId/line/:line/device/:deviceId。无效或跨门店/产线设备不显示详情，给出返回列表入口。关闭回列表地址；浏览器后退前进可恢复层级。切换产线收起设备；展开同一设备再次点击收起，同一时刻最多展开一台。

门店列表筛选和有效日期在模块会话中保留，抽屉沿用当前有效日期；日期调整在列表完成。打开/关闭和抽屉内切换不会修改列表筛选。记录列表滚动及触发入口；关闭后恢复滚动和焦点。展开设备保留抽屉正文滚动，切换产线回正文顶部。

支持关闭按钮、遮罩空白点击和 Escape；点击抽屉内部不关闭。对话框有 aria-modal、命名、焦点进入、Tab 焦点循环及背景 inert，窄屏占满宽。新交互均标记既有只读浏览操作；权限资源、父级门禁、保存授权、角色并集和统计逻辑不变。

实现范围：新增纯路径模型并验证新旧路径和对象归属；改 merchant-activity-ui.ts 的列表操作、抽屉、页签和内联设备明细，扩展限定 CSS，复用公共门店/产线/设备统计。删除不再使用的旧独立页面渲染，保留旧路由兼容，不新增后端。
