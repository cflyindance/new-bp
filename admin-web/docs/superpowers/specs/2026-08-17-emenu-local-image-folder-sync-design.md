# eMenu 本机图片文件夹同步 · 设计说明

日期：2026-08-17  
状态：已确认并已实施（2026-08-17）  
范围：仅 `admin-web/vendor/emenu-new`（eMenu 自身项目）；不改 POS `/kpos` 后端，不新增本地 Node 写盘服务

## 1. 背景与目标

门店在 POS 本机通过浏览器打开 eMenu 设置页时，需要把**本机某个单层图片文件夹**里的图片同步到固定目录：

`C:\Wisdomount\Menusifu\data\static\images`

约束（已确认）：

| 项 | 结论 |
|---|---|
| 操作场景 | POS 本机本地配置（非云端远程下发） |
| 上传形态 | 仅「选择文件夹」，不做 zip |
| 同名策略 | 目标目录已有同名文件 → **保留原图，不覆盖** |
| 目录结构 | 仅允许单层文件夹；有子目录则整次拒绝 |
| 改动边界 | 只能改 eMenu 自身项目；不能改 POS、不能加本地写盘服务 |
| 运行环境 | 普通 Chrome / Edge 浏览器 |

硬限制：网页无法在无授权情况下静默写入任意 `C:\` 路径。在上述边界下，采用 **Chrome/Edge File System Access API（目录授权写盘）**。

**安全上下文前提（必须满足）**：File System Access 仅在安全上下文可用——`https://` 或 `http://localhost` / `http://127.0.0.1`。  
门店若用 `http://局域网IP:端口` 打开 eMenu，本功能不可用。能力检测须区分「浏览器不支持」与「非安全上下文」并分别提示。默认 POS 场景（`http://localhost:22080`）满足前提。

## 2. 方案选型

采用 **方案 1：浏览器目录授权直接写盘**。

| 方案 | 说明 | 结论 |
|---|---|---|
| 1 目录授权写盘 | eMenu 前端用 `showDirectoryPicker` 授权目标目录并写入 | **采用** |
| 2 复用 POS 图片上传 API | 调现有 `/kpos/webapp/file/image/upload/kiosk/{type}` | 否：落地路径由 POS 决定，无法保证等于 `data\static\images` |
| 3 POS/本地服务写盘 | 扩展本机写盘接口 | 否：与「都不能改」冲突 |

## 3. 整体架构与数据流

全程在 eMenu 前端完成，不经过 POS 新接口。

```
操作员（Chrome/Edge）
  │
  ├─① 选择源文件夹（只含图片、不要子目录）
  │     └─ 校验失败 → 拦截并提示，不写盘
  │
  ├─② 授权目标目录（首次或失效时）
  │     └─ 引导选择：C:\Wisdomount\Menusifu\data\static\images
  │
  └─③ 逐文件处理
        ├─ 目标已有同名 → 跳过（保留原图）
        ├─ 目标没有     → 写入
        └─ 结束后汇总：新增 / 跳过 / 忽略非图片 / 失败
```

技术要点：

- 读源目录、读写目标目录均使用 File System Access API
- 写盘前用目标目录文件名集合（Windows 下不区分大小写）做同名判断
- UI 可固定展示期望路径文案，但**无法在代码中静默锁定盘符路径**；必须由操作员选中该文件夹完成授权

## 4. 设置页交互

**放置位置**：`SystemSetting`（与现有数据备份 / 恢复同页或同级入口），模块名建议：「本机图片目录同步」。

**页面元素**：

1. **说明文案**：目标路径 `C:\Wisdomount\Menusifu\data\static\images`；仅支持单层图片文件夹；同名保留本机原图  
2. **主按钮**：`选择文件夹并同步`  
3. **次要操作**：`重新授权目标目录`（首次或权限失效时）  
4. **结果区**：`新增 N · 跳过同名 M · 忽略非图片 P · 失败 K`；失败时列出少量文件名与原因  

**主按钮流程**：

1. 若尚未授权目标目录 → 先弹出系统目录选择，引导选到上述路径  
2. 再弹出源文件夹选择  
3. 校验通过后开始写入  
4. 用页面内 toast / 结果区反馈（禁止 `alert` / `confirm` / `prompt`）

**取消系统目录选择器**：用户在任意一步取消选择 → **静默中止**，不写盘、不弹错误（可保留上次结果区不动）。

**能力不可用时**（分别提示，勿混为一谈）：

- 非安全上下文（如 `http://局域网IP`）→ 提示改用本机 `localhost` / `127.0.0.1` 或 HTTPS 打开  
- 浏览器无 File System Access → 提示「请使用本机 Chrome 或 Edge 打开设置页」

## 5. 校验、同名策略与错误处理

### 5.1 源文件夹校验（不通过则整次中止，不写任何文件）

1. 存在**子目录** → 提示「请先整理为单层文件夹后再同步」  
2. **没有任何图片文件** → 提示「未找到可同步的图片」  
3. 允许扩展名（定稿）：`.jpg` / `.jpeg` / `.png` / `.gif` / `.webp` / `.bmp`  
4. 同目录非图片文件：**忽略，不报错，不阻断整次同步**  
5. 源目录内若存在仅大小写不同的重复图片名（极少见；在区分大小写的介质上可能出现）→ **整次拒绝**，提示整理后再同步  

### 5.2 写入策略与同名判断

同名判断适用范围：**源文件 ↔ 目标目录已有文件**；Windows 习惯，**不区分大小写**（`A.JPG` 与 `a.jpg` 视为同名）。

| 情况 | 行为 |
|---|---|
| 目标目录已有同名 | 跳过，保留原图 |
| 目标目录没有 | 写入新文件 |
| 单个文件写入失败 | 记入失败列表，继续处理其余文件 |
| 目标目录无写权限 / 授权失效 | 中止并提示「请重新授权目标目录」 |

### 5.3 结果汇总（必须展示）

结果区统一展示四项：

- 新增成功数  
- 同名跳过数  
- 忽略的非图片数  
- 失败数 + 前几条失败原因  

### 5.4 明确不做（YAGNI）

- 不做 zip  
- 不自动创建子目录  
- 不同步后自动清缓存 / 通知 POS 热更新（若后续业务需要再单独立项）  
- 不做云端远程下发  

## 6. 技术落点

仅改 eMenu 项目（`vendor/emenu-new`）：

| 部分 | 建议落点 |
|---|---|
| UI | `src/pages/SystemSetting/`（入口与现有 Backup 按钮同级或同页新增一块） |
| 同步逻辑 | 独立模块，例如 `src/utils/localImageFolderSync.js`（或同级目录） |
| 文案 | `src/locales` 中英文补齐 |

逻辑模块职责：

1. 能力检测：区分「非安全上下文」与「浏览器不支持 File System Access」  
2. 授权 / 重授目标目录（尽量持久化目录句柄；环境不支持持久化则每次或失效时重授）  
3. 选源目录 + 扁平 / 扩展名校验（扩展名匹配不区分大小写，如 `.JPG` 视为合法）  
4. 同名跳过 + 逐文件写入 + 结果汇总（失败列表最多展示 10 条）  
5. 同步进行中禁用主按钮，防止重复触发  

**不改**：

- POS `/kpos` 任何后端或配置  
- admin-web 本地 Node 写盘服务  
- 云端下发 / Sync Agent  

## 7. 验收标准

1. 本机 Chrome/Edge 打开 eMenu 设置页，可选单层图片文件夹并同步成功  
2. 文件出现在已授权的 `...\data\static\images`  
3. 同名文件不被覆盖  
4. 含有子目录的源文件夹被拒绝且不写盘  
5. 非图片被忽略；部分失败不影响其余成功文件  
6. 非 Chromium / 无 File System Access、以及非安全上下文时，分别有明确不可用提示  
7. 无浏览器原生 `alert` / `confirm` / `prompt`  
8. 用户取消目录选择时静默中止，不产生错误提示、不写盘 

## 8. 风险与说明

| 风险 | 说明 | 缓解 |
|---|---|---|
| 无法代码级锁定目标路径 | 浏览器安全模型要求用户选择目录 | UI 固定展示期望路径；首次引导操作员选对目录 |
| 权限可能失效 | 清站点数据、换浏览器配置文件等可能导致目录句柄失效 | 提供「重新授权目标目录」；失效时明确提示 |
| 仅 Chromium 可用 | Firefox / 部分内嵌 WebView 可能不支持 | 能力检测 + 明确文案；本需求场景已确认用 Chrome/Edge |
| 非安全上下文 | `http://局域网IP` 下 API 不可用 | 能力检测单独提示；约定用 `localhost` / HTTPS 打开 |
| 同步后业务是否立即读到新图 | 取决于 POS/eMenu 如何引用该目录 | 本次不做热更新；若有问题后续单独立项 |
