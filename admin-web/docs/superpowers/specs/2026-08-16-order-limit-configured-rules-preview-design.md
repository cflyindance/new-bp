# 限购数量已配置规则全量预览设计

> **状态更新（2026-08-18）：独立预览入口已被替代。** 「限购数量」主区现直接展示包含已配置与未配置项的完整商品规则列表，并沿用本文的门店、人数、轮次、产线、菜单字段及筛选 / 搜索 / 分页能力，因此无需再打开独立「查看已配置规则」弹层。当前口径以 `2026-08-18-order-limit-product-quantity-merge-design.md` 为准。

## 背景

「数量与频次限制 > 限购数量」当前按单个配置门店、单个人数场景、单个轮次、单条产线编辑数量矩阵。门店和产线变多后，运营难以在离开步骤前二次确认「哪些门店配了哪些菜单、数量分别是多少」。商品配置步骤已有「查看已选商品」只读弹层可复用。

## 目标

- 在限购数量步骤提供只读全量预览，覆盖全部参与门店、全部人数场景、全部轮次、全部产线中的已配置限购规则。
- 每行清楚展示门店、场景维度、产线、菜单目标与限购数量，便于二次核对。
- 复用现有选品预览弹层交互壳，不打断当前编辑上下文。

## 已确认方案

采用「产线配置标题旁入口 + 只读弹层」方案：

- 只读核对，不在弹层内改数量。
- 完整展开人数场景与轮次，不折叠为「仅当前场景」。
- 仅展示 `configured === true` 的单元格；未配置行不出现。
- 交互形态对齐「查看已选商品」，不采用页内长表或独立全屏页。

## 入口

在步骤 4「产线配置」标题区右侧增加按钮：

- 文案：`查看已配置规则（N）`
- `N` = 全部参与门店中已配置限购单元格总数
- `N === 0` 时按钮禁用，文案仍显示 `(0)`
- 当步骤 4 处于「暂无参与门店」空态时，不渲染该入口

主编辑区（配置门店、人数/轮次 Tab、产线 Tab、批量工具条、数量矩阵）保持现有行为不变。

## 弹层结构

复用选品预览弹层壳：

1. 标题：`查看已配置规则（N）`，`N` 为未筛选前的全量已配置行数
2. 关闭：关闭按钮、遮罩点击、`Esc`
3. 筛选条：门店、人数场景、轮次、产线、菜单搜索
4. 只读表格
5. 分页：默认 20 条/页，可选 10 / 20 / 50

不提供勾选列、删除、编辑、批量操作或「跳转编辑」入口。

## 数据行

遍历口径对齐现有 `eachLimitCell`（或等价实现）：以 `addedStoreIds(draft)` 为门店集合，对每人人数场景、每轮次（仅 `period === "multi_round"` 时展开多轮，否则固定 roundIndex=0）、该门店 `productLines`、以及 `targetsForLine(draft, lineId, config)` 得到的目标：

1. 读取 `storeConfigs[storeId].limits[limitKey(partyIndex, roundIndex, lineId, targetId)]`
2. 仅当 `cell.configured === true` 时生成一行
3. `rowId = storeId|partyIndex|roundIndex|lineId|targetId`

不得改用草稿级全局产线/目标列表，避免跨门店串用商品范围。

### 列定义

| 列 | 内容 |
|---|---|
| 配置门店 | 门店名称 |
| 人数场景 | `formatRange(partyRange, "人")` |
| 轮次 | 多轮：`formatRange(roundRange, "轮")`；单轮：`—` |
| 产线 | 产线名称 |
| 菜单 | 分类规则显示分类名；菜品规则显示菜品名，并附分类路径辅助信息 |
| 限购数量 | 已配置整数；`0` 展示为 `0（禁止）` |

### 默认排序

门店列表顺序 → 人数场景索引 → 轮次索引 → 产线列表顺序 → 菜单名称。

## 筛选

- 门店 / 人数场景 / 产线：下拉，首项为「全部…」
- 轮次：仅多轮规则显示；单轮规则不渲染该筛选项
- 菜单搜索：对菜单展示名做包含匹配（大小写不敏感，沿用现有规范化）
- 筛选项只来自当前已配置行中实际出现过的值，避免空筛
- 切换任一筛选条件时回到第 1 页

筛选后若无结果：弹层内空态「当前筛选条件下暂无已配置规则」。

## 临时状态

在 `editorState` 增加独立预览状态（命名示例：`configuredLimitPreview`），字段包括：

- `open`
- `storeId`
- `partyIndex`（空字符串或哨兵表示全部）
- `roundIndex`（同上；单轮可忽略）
- `lineId`
- `query`
- `page`
- `pageSize`

该状态不写入 `editorDraft`，不参与草稿持久化、兼容规则或发布快照。

## 生命周期

- 打开：按当前草稿汇总已配置行 → 筛选重置为全部 → `open=true` → 聚焦标题
- 关闭：清空临时筛选与分页到默认；不改变步骤 4 当前 `activeStoreId` / 人数 / 轮次 / 产线
- 弹层打开期间若主编辑区改了数量并触发重绘：按最新草稿刷新预览行；只读无写回冲突
- 离开步骤 4：强制关闭预览并重置临时状态

## 非目标

- 弹层内编辑、删除或批量改数量
- 从未配置项跳转到对应编辑上下文
- 导出 Excel / 打印
- 改变现有 `limits` 数据模型或发布裁剪逻辑
- 改变批量设置常驻工具条与单行数量输入行为

## 验证

新增专项脚本（建议 `scripts/verify-order-limit-configured-limit-preview.mjs`），至少断言：

1. 步骤 4 渲染 `查看已配置规则` 入口与预览标记
2. 行生成只包含 `configured === true` 单元格，并覆盖门店/人数/轮次/产线/目标维度
3. `0` 展示为禁止文案；单轮轮次列为 `—`
4. 预览状态初始化存在，且不进入默认草稿 / 发布快照
5. 打开、关闭、离开步骤 4 的清理路径存在
6. 提供筛选、分页、空态相关标记与样式

同步跑现有数量与频次专项脚本、目标 JS 语法检查；本地浏览器验收至少覆盖：

- 两家及以上参与门店、两条及以上产线
- 至少一个人人数多场景；如有多轮规则再验一轮展开
- 含普通正整数与 `0（禁止）`
- 筛选、搜索、分页、Esc/遮罩关闭后主编辑上下文不变
