# 菜单路由配置顶部元信息精简设计

## 目标

精简菜单路由配置页面顶部区域，移除“配置名称”和“ID”的可视展示，减少与菜单编辑任务无关的信息干扰。

## 调整范围

- 删除顶部“配置名称”标签及输入框。
- 删除顶部“ID”标签及字段值。
- 保留“最后更新”信息，并将其放置在原元信息行的左侧起始位置。
- 页面标题、版本状态、操作按钮和状态消息保持不变。

## 数据与行为约束

- 仅修改页面渲染，不删除或修改菜单文档中的 `name`、`_id` 字段。
- 不改变草稿保存、发布、导出 JSON、校验及菜单节点编辑逻辑。
- 不新增替代输入入口。

## 验收标准

- 页面顶部不再出现“配置名称”输入框及“ID”文案和值。
- “最后更新”仍正常展示并左对齐。
- 相同菜单文档直接导出时，改造前后的 JSON 字段集合和值完全一致。
- 若通过保存或发布流程比较结果，仅允许 `updatedBy` 等现有流程本身会更新的审计时间字段产生预期变化；`name`、`_id` 和菜单业务字段必须保持一致。
- 完成菜单编辑、保存草稿并重新加载后，原有 `name`、`_id` 仍存在且值不变。
- 对同一份有效或无效配置，改造前后的字段校验结果、草稿保存结果及发布允许/拦截结果一致。
- 菜单配置相关回归测试与 TypeScript 静态检查通过。
