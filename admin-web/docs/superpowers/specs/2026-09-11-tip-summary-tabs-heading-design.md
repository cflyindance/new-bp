# 小费分配页面 Tab 标题区布局设计

## 目标

移除分配汇总页面可见标题“小费分配”，将“分配汇总 / 员工对账”视图切换 Tab 移到原标题位置，使页面入口更直接，同时保持现有业务、筛选和切换逻辑不变。

## 布局

- 页面顶部标题栏左侧展示现有 `summaryViewSwitch` Tab。
- 标题栏右侧继续展示“新建/查看规则”。
- 原可见 `h1` 文案“小费分配”删除；保留仅屏幕阅读器可见的页面标题，并继续作为页面 `aria-labelledby` 目标。
- 筛选容器内不再包含 Tab，日期范围、门店、角色、员工和日期排序按现有顺序向左补位。
- 不复制 Tab，页面内继续只有一组 `dateTaskTab` 和 `employeeReconciliationTab`。

## 响应式行为

- 桌面端 Tab 位于标题栏左侧，规则按钮位于右侧。
- 移动端标题栏保持现有纵向布局，Tab 使用可用宽度，两项等宽；规则按钮沿用现有移动端标题操作区规则。
- 筛选条件折叠按钮只控制筛选字段，不控制顶部 Tab，切换视图入口始终可见。

## 逻辑边界

- 保留 Tab 的 ID、`role="tablist"`、`role="tab"`、ARIA 属性、键盘事件和 `setSummaryView` 绑定。
- 不修改日期/员工视图状态、筛选显示隐藏、导出、分配或规则入口逻辑。
- 只修改原生页面 `src/team/tips`，不修改旧 TipOut 项目。

## 验收标准

1. 页面不再显示“小费分配”标题。
2. “分配汇总 / 员工对账”出现在原页面标题位置。
3. 筛选条件区域内不再出现 Tab，其他筛选项自动左移。
4. 两个 Tab 点击和键盘切换行为保持正常。
5. “新建/查看规则”位置与功能保持不变。
6. 移动端 Tab 始终可见且两项等宽。
7. 页面仍具有有效的无障碍标题关联。

## 验证

- 静态验证 Tab 在标题栏内且位于筛选容器之前，ID 唯一，绑定未变。
- 静态验证可见“小费分配”标题已移除，隐藏语义标题存在。
- 运行现有小费原生页面回归验证和生产构建。
- 浏览器验证桌面和窄屏布局以及两个 Tab 的切换。
