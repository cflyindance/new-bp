# 分配工时明细隐藏小费池列

日期：2026-09-28  
状态：已确认

## 目标与范围

员工分配汇总与员工每日小费详情中的同名“分配工时明细”弹框同步去掉“小费池”展示列。保留规则名称、规则类型、工时来源、分配工时四列，列顺序一致。

## 实现边界

这是展示层改动。工时记录中的 `poolId`、`poolName`、`poolKind` 及按池、规则、类型汇总的逻辑保持不变，避免同名规则或历史记录发生错误合并。两处弹框的行内容分别不再输出 `poolName` 单元格，表头和每行均为四列。

现有的弹框入口、关闭方式、工时值与来源文案不变。不删除规则类型列，不变更小费分配或金额计算。

## 验收

1. 员工分配汇总与员工每日小费详情的“分配工时明细”均展示四列表头：规则名称、规则类型、工时来源、分配工时。
2. 每行恰有四个单元格，规则名称、规则类型、来源和工时对应各自表头。
3. 小费池与加收服务费池仍能正确显示规则类型，旧记录的未知类型仍显示“—”。
4. 工时按原有池、规则、类型粒度汇总；其他展示及交互不变。
