# 限购数量当前页全选设计

## 目标

在“限购数量”的商品规则列表中，为现有行多选、批量应用数量和批量删除补充当前页全选能力。用户可从“配置门店”左侧的表头复选框一次选择或取消选择当前页全部规则。

## 页面与状态

- 保留现有每行复选框，选择列继续位于“配置门店”左侧。
- 选择列表头新增可操作复选框，替换当前仅供读屏使用的“选择”占位。
- 表头复选框有三种视觉状态：
  - 当前页未选择任何规则：未勾选。
  - 当前页仅选择部分规则：半选。
  - 当前页所有规则均已选择：已勾选。
- 空列表时表头复选框禁用。
- “已选 N 条规则”继续显示实际选择数量。

## 全选范围

- 全选和取消全选仅作用于当前分页的 `pageRows`。
- 点击未勾选或半选的表头复选框时，选择当前页全部规则。
- 点击已勾选的表头复选框时，取消选择当前页全部规则。
- 当前实现会在翻页、修改筛选、搜索、调整每页条数或重置筛选时清空选择，本次保持该规则。
- 行勾选变化后，表头复选框立即重新计算未选、半选或全选状态。

## 批量应用数量

- 用户选择当前页的一条或多条规则后，在现有批量输入框填写非负整数并点击“应用数量”。
- 数量只覆盖当前已选规则行，不影响未选规则。
- `0` 继续表示禁止下单；空值、负数或非整数继续提示错误。
- 应用成功后沿用现有规则清空选择并提示应用条数。

## 批量删除

- 批量删除继续使用现有商品级语义：从已选规则行提取并去重商品，删除商品及其全部数量配置。
- 已配置数量的商品继续展示二次确认；无已配置数量时沿用现有直接删除逻辑。
- 删除成功后清空选择并提示实际移除的商品数量。

## 可访问性

- 表头复选框提供“全选当前页商品规则”的可访问名称。
- 半选状态通过复选框的 `indeterminate` 属性表达，而不是仅依赖视觉样式。
- DOM 结构保持原生复选框，支持键盘操作。

## 验证

- 验证表头复选框位于“配置门店”左侧，并在空列表时禁用。
- 验证未选、部分选择、全部选择对应的 checked/indeterminate 状态。
- 验证全选和取消全选只影响当前页规则。
- 验证行选择、全选、筛选和分页后选择数量及按钮状态同步。
- 验证批量应用数量和批量删除继续使用现有业务语义。
- 运行 JavaScript 语法检查及全部菜单限购回归脚本。

## 不在范围内

- 不提供跨分页或跨筛选结果全选。
- 不改变批量应用数量的输入控件和校验规则。
- 不改变批量删除的商品级删除范围与确认规则。
- 不调整列表其他字段、筛选项和分页规格。
