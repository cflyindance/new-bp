# 菜单路由配置高级设置分组设计

## 目标

优化菜单节点编辑区的高级设置层级，使其与“基础信息”“层级与页面”的结构一致。高级设置应默认完整展示，并通过分类标题帮助用户快速定位配置项。

## 页面结构

“高级设置”作为表单中的一级区块标题，与“基础信息”“层级与页面”同级。该区块不使用折叠容器，也不提供展开或收起操作，因此进入菜单编辑状态后始终展示全部内容。

高级设置内部按以下顺序划分三个分类：

1. **多语言设置**
   - 简体中文
   - 繁体中文
   - English
   - i18nKey
2. **状态与权限**
   - 是否显示
   - 是否禁用
   - 启用权限控制
   - 设置服务与权限
3. **扩展信息**
   - extraInfo

每个分类使用小标题和分隔线建立视觉层级。字段栅格、标签样式、横向宽度和垂直间距沿用“层级与页面”区块的现有风格，不增加嵌套卡片、标签页或新的交互控件。

## 行为与数据约束

- 不新增、删除或重命名任何 JSON 字段。
- 不改变现有字段与 JSON 的映射方式。
- 不改变服务与权限弹窗及其选择规则。
- 不改变字段校验、节点问题标记、草稿保存和发布拦截逻辑。
- 新增和编辑菜单使用相同的高级设置分组结构。

## 验收标准

- 菜单节点处于新增或编辑状态时，“高级设置”始终可见且无需展开。
- “高级设置”的标题层级与“基础信息”“层级与页面”一致。
- 三个分类标题及其字段归属与本设计一致。
- 页面不出现原有高级设置折叠边框和折叠交互。
- 现有菜单配置回归测试通过，导出 JSON 结果不因本次视觉调整发生变化。
