# 员工对账工时字段简化设计

## 目标

员工对账详情的“工时”列只展示工时数值及来源标签，不展示小费池名称或小费规则名称。

## 展示规则

- 打卡工时：显示 `8 h`，不显示来源标签。
- 手动录入工时：显示 `6 h`，右侧显示小标签 `录入`。
- 未打卡且未录入：显示 `0 h`，不显示标签。
- 混合工时：每条工时仍分行展示；仅手动录入行显示 `录入`，所有行均不显示规则名称。

## 范围

仅修改员工对账详情表格的工时单元格渲染。保留底层手动工时记录中的小费池、规则标识和名称，CSV、PDF、邮箱等导出逻辑不变，以维持审计及核对能力。

## 实现

`attendanceMock.js.txt` 继续生成带来源的工时行，但界面渲染函数 `makeWorkHoursCell` 不再输出 `line.label`，只输出格式化后的小时数与手动录入标签。

## 验收

- 页面中工时列不出现 `Tip Pool` 或规则名称。
- 手动工时仍正确显示小时数和 `录入` 标签。
- 打卡工时及未录入的 0 小时展示不受影响。
- 导出数据仍保留原有手动工时明细。
