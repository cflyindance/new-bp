# 员工声明模板五列表格

## 已确认展示

将员工声明设置中的卡片列表改为表格，每份模板一行，列顺序固定为：模板名称、模板范围、门店、状态、声明内容。不新增语言代码、版本号或操作列。

| 列 | 数据与行为 |
| --- | --- |
| 模板名称 | 沿用现有 languageDisplayName，不新增名称字段。名称为可键盘操作的按钮，打开原模板详情弹框。 |
| 模板范围 | 有 storeId 时显示“指定门店”，否则显示“企业通用”。 |
| 门店 | 指定门店显示名称，名称缺失时显示门店 ID；企业通用显示“全部门店”。 |
| 状态 | 沿用现有版本选择逻辑与“草稿／已发布／已停用／未配置”状态。 |
| 声明内容 | 同一选中版本的 source，作为纯文本预览，最多两行，超出省略；点击模板名称进入详情查看完整正文。空正文显示“—”。 |

## 交互及边界

沿用新增、详情、编辑、发布、停用入口；此次只改列表结构和样式，不改模板数据、门店权限或员工声明解析。正文中的变量在列表保留原始占位符，不套用某一员工的数据。多语言内容安全转义，正文支持自动文字方向和长文本换行。

采用语义化 table、表头 th 和五个独立 td，名称列使用原 data-declaration-family 标记接入已有点击处理。桌面完整展示五列；窄屏由表格容器横向滚动，不压缩为卡片，不推动整页横向滚动。无模板时用跨五列空态，加载及错误提示保留。

## 验收

1. 企业通用、指定门店、不同状态的模板均正确显示五列，状态与正文来自同一版本。
2. 两行以上正文截断，不增加行高；详情保留完整正文和编辑规则。
3. 点击名称与键盘 Enter 均打开正确模板，关闭后可再次进入。
4. 特殊 HTML 字符不执行，多语言正文和空内容正常显示。
5. 新增模板、门店选择、员工语言隔离原有回归通过。

实现范围为 payroll-declaration-settings.ts 的列表渲染、payroll-page.css 的局部表格样式和对应渲染测试。无需 API、数据迁移或依赖更新。
