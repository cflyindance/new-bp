- 本机模块列偏好沿用现有storage key，没有账户隔离证据，不宣称按登录用户隔离。
- 商品源是项目内置共享菜单目录；真实门店目录接口、目录权限和动态菜单变化未接入或验收。目录缺失身份显示无法核对，不以商品编码伪装名称。
