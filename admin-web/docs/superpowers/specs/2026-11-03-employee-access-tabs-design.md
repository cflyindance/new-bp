配置：两个维度的 DOM 和草稿独立保留，页签切换不触发离开提示，不写入存储。当前维度只有一个保存按钮；没有修改显示无未保存修改。M 角色多选，角色多于5个时搜索；商户角色与品牌/门店范围绑定表沿用编辑流程，添加授权在区域标题右。系统兼容管理员或不可编辑维度不显示无效保存按钮。无查看商户权限时不读取/挂载其明细。
