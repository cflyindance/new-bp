# 自助餐规则移除默认授权范围

状态：用户已确认，已实施、未提交。变更编号：BUFFET-20261106-01。本文为本任务设计记录，产品权威入口沿用《自助餐规则场景配置融合设计》及其配对研发、个人规范文档。

## 范围

自助餐规则新建、编辑的超限授权步骤，移除整个“默认授权范围”标签、下拉框及历史默认值提示，同时移除“授权原因必须填写”设置。保留授权开关、可选授权范围和对应角色权限。非自助餐的菜单下单限制流程不受影响。

## 页面与交互

移除两个字段所在区域，不留空白占位。确认发布摘要不展示默认范围或授权原因设置，仍展示已启用的授权范围。自助餐规则列表可配置字段中的默认授权范围和授权原因也不再作为有效配置结果展示。

授权仍需显式完成密码及权限校验；本设置页不预设授权人本次选择的范围，不自动放行。实际消费端选择界面的实现需单独核对，本任务不凭配置页变化宣称所有外部终端已同步。

## 数据兼容与校验

历史 authorization.defaultScope 和 reasonRequired 保留，不批量迁移、清空或扩大历史授权；默认范围不再是自助餐编辑流程的必填项，不作为展示或阻止保存的依据。页面不再提供这两个字段的编辑事件入口。授权启用时，至少一种可用范围及各范围对应权限仍为必填。关闭授权时维持硬性拒绝。不据此修改外部终端的原因输入规则。

新旧草稿均不得因隐藏字段缺失、为空或不在 allowedScopes 中而被默认范围校验拦截。正常规则结构、数量、生效范围和发布校验维持原样。非自助餐的 defaultScope 校验保持。

## 验收

1. 授权开启：无默认范围字段、历史提示和摘要，无原因必填设置；角色和范围仍可编辑保存。
2. 历史默认本次操作、当前轮、当前订单，以及缺失值均可在其他配置合法时继续。
3. 授权关闭仍直接拒绝超限；无范围或缺角色仍阻止授权开启状态保存。
4. 整单、每轮、分轮次模板覆盖；非自助餐页面无回归。
5. 更新既有产品权威、研发及个人规范三份文档受影响章节，截图缺口如实登记。浏览器验收使用新功能工作区，保持 main 预览不变。不自动提交、合并或推送。
