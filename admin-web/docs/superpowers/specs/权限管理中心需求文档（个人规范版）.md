## 公共规则

**P1 本地边界**：新工作台仅保存当前浏览器的权限配置、邀请与账号状态，计算结果在编辑/效果预览中可查看。未接管真实登录及全站业务鉴权，不发真实邮件。不以“已保存”代表线上授权成功。

**P2 草稿**：角色或员工详情修改后为未保存；员工所有门店共用一次保存草稿但例外按门店隔离。返回、取消及路由离开需确认放弃；刷新使用浏览器离开提示。保存异常保留草稿。
