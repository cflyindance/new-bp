# 菜单下单限制规则列表滚动区设计

## 背景

前厅管理中心的「菜单下单限制 > 数量与频次限制」通过 iframe 展示规则列表。当前数量页外层同时存在卡片背景、边框、圆角和 iframe 自身的整页滚动条；iframe 内部又使用灰色页面背景和留白包裹「现有规则」卡片。长列表滚动时，标题操作栏和表头会一起离开视口，主内容层级不够直接。

## 目标

- 默认进入「数量与频次限制」时，主内容直接展示「现有规则」列表。
- 去掉数量页 iframe 外层的卡片背景、边框、圆角和阴影。
- 去掉 iframe 内规则列表外围的灰色背景和多余留白。
- 页面和 iframe 容器本身不产生纵向滚动条。
- 「现有规则」标题操作栏与表头固定，仅规则数据行区域纵向滚动。
- 小屏或列宽不足时，规则列表区域保留横向滚动能力。

## 已确认方案

采用“列表区内部滚动”方案：外层页面只负责布局，滚动责任收敛到「现有规则」的数据视口。

### 外层承载区

数量页 tab panel 保持 `flex` 和 `min-height: 0`，但移除 `rounded-xl`、`border`、`bg-card` 与 `shadow-sm`。iframe 继续占满 panel，新增、编辑、门店选择和发布确认等全屏流程保持现有切换逻辑。

### iframe 列表页

- `html`、`body` 与 `.page` 在 embedded 模式下占满可用高度并禁止整页滚动。
- embedded 模式移除 body 灰色背景与 `.page` 外边距/留白，使规则列表成为主内容。
- `#rulesPanel` 使用纵向 flex 布局，占满 `.page` 的可用高度，并设置 `min-height: 0`。
- `.section-head` 保持在规则区顶部，不进入滚动容器。
- `.section-body` 成为唯一的列表滚动视口，使用 `min-height: 0`、`overflow: auto`。
- 表头在 `.section-body` 内使用 sticky 定位，滚动数据行时保持可见，并设置不透明背景与合适层级，避免内容透出。

## 交互行为

- 默认加载后直接看到「现有规则」、规则数量和「新增规则」按钮。
- 长列表滚动时，标题操作栏与表头保持可见，编辑、复制、启停和删除按钮随对应数据行滚动。
- 点击「新增规则」后仍进入现有全屏步骤页；返回列表时恢复现有列表页布局，不引入新的路由或状态。
- 空列表时，空状态仍显示在规则列表滚动视口中。
- 键盘、鼠标滚轮和触控板均作用于规则列表视口；可操作控件的焦点样式保持不变。

## 响应式行为

- 桌面端：规则数据区在可用高度内纵向滚动，标题操作栏和表头固定。
- 窄屏端：同一 `.section-body` 同时承担横向和纵向滚动，避免压缩列内容或改变表格字段。
- 不新增分页、虚拟列表或系统自动折叠列。允许用户通过“字段设置”主动隐藏可选字段；规则名称、状态、操作固定展示。该偏好不改变 `.section-body` 的横纵滚动职责。

## 影响范围

预计仅修改：

- `src/config/foh-menu-order-limits-ui.ts`：移除数量页 iframe panel 的装饰性容器样式。
- `dist/Configuration center/order-limit.html`：调整 embedded 模式高度、背景、列表 flex 结构与滚动归属。
- 新增聚焦验证脚本，覆盖承载区样式与列表滚动结构。

不修改规则数据、存储、路由、增删改操作、全屏编辑流程、其他两个菜单下单限制 tab 的布局。

## 验证方案

### 自动验证

- 验证数量页 panel 不再包含背景、边框、圆角和阴影类。
- 验证 embedded 模式禁用整页滚动并移除灰色背景与外层留白。
- 验证 `#rulesPanel` 为占满高度的 flex 容器。
- 验证 `.section-body` 是列表滚动视口。
- 验证表头使用 sticky 定位。

### 浏览器验证

- 默认进入数量与频次限制时直接显示现有规则列表。
- 长列表仅在数据区出现纵向滚动条。
- 滚动时「现有规则」操作栏和表头保持固定。
- 外层灰色背景、卡片边框、阴影和外层滚动条消失。
- 点击新增规则进入全屏编辑页，再返回列表，布局和滚动责任保持正确。
- 控制台无错误。

## 非目标

- 字段设置改造可以动态调整可见列，但不得改变本方案定义的滚动容器、sticky 表头和 embedded 高度链。
- 不新增筛选、搜索、分页、批量操作或虚拟滚动。
- 不统一重构其他 tab 或其他 iframe 页面。
