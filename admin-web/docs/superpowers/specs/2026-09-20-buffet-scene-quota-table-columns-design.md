# 自助餐场景额度商品表格独立列设计

## 背景

“配置额度”弹窗中的限购商品表格目前将产线、分类、门店和商品编码混合展示，商品名称还带有产线后缀。信息难以按列扫描，并产生重复内容。

## 目标

在不改变筛选、批量设置、跨门店额度保存和场景商品增删逻辑的前提下，将商品相关信息拆分为语义清晰的独立列。

## 表格结构

采用已确认的方案 A。列顺序为：

1. 勾选
2. 商品（分类限购时显示“分类”）
3. 产线
4. 分类
5. 门店
6. 限购数量
7. 状态
8. 操作

展示规则：

- 商品列只展示商品名称，不展示商品编码。
- 商品名称不附加产线名称。
- 产线、分类和门店各自独立成列。
- 不在其他列中重复展示商品编码。
- 空结果行的跨列数量与新表头保持一致。

## 行为保持

- 门店、产线、分类、状态和关键词筛选行为不变。
- 跨门店默认集合展示行为不变。
- 单项额度、批量额度、状态和移除操作的数据归属不变。
- 添加或删除商品仍只影响对应门店的当前场景。
- 分页、当前页全选和批量删除行为不变。

## 样式

- 使用现有表格视觉体系，不新增设计语言。
- 为产线、分类、门店提供独立列宽，商品列保留较高视觉优先级。
- 在弹窗宽度不足时继续使用现有横向滚动，不压缩额度输入框或操作按钮。

## 验收标准

- 表头依次展示商品、产线、分类、门店、限购数量、状态和操作。
- 商品行各字段与表头严格对应。
- 页面不展示商品编码。
- 商品名称中不再显示产线后缀。
- 全部门店与单门店筛选下的行数和门店归属正确。
- 编辑单项额度、批量设置额度及移除商品仍写入正确门店和当前场景。
- 相关静态验证、语法检查和本地浏览器验收通过。
