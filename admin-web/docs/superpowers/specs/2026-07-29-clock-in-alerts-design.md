# 员工打卡 · 打卡管理提醒字段 — 设计文档

> 日期：2026-07-29  
> 模块：团队管理 / `/team/clock-in` 打卡管理  
> 状态：已实现  
> 主要改动文件：`src/config/team-clock-in-ui.ts`

## 1. 目标

按排班时间重写「提醒」列逻辑：展示迟到/早退/休息超时时长，以及未打卡类状态；重叠处用新文案替换旧文案，保留无替代的旧提醒。

## 2. 已确认决策

| 项 | 决策 |
|----|------|
| 实现 | 方案 1：重写 `computeAlerts` |
| 未打上班卡 | 仅「有下班卡、无上班卡」 |
| 未打上下班卡 | 当日无任何打卡，且已过排班开始 + 迟到宽限 |
| 迟到分钟 | 从宽限截止起算（超过宽限才提示） |
| 早退 | 有下班卡且早于排班结束；相对排班结束算分钟 |
| 休息超时 | 按 breakLabel 匹配系统休息时长；进行中用 now；超时分钟各段求和 |
| 未打下班卡 | 仅上班卡，且已过排班结束 + 1 小时 |
| 旧提醒 | 保留「提前打卡」「无排班」；去掉纯「迟到」「超时未下班」及旧「未打上班卡」 |

## 3. 提醒表

| 提醒 | 条件 | 文案 |
|------|------|------|
| 无排班 | 开启必须排班且无 assignment | `无排班` |
| 提前打卡 | 上班卡 < 排班开始 − 允许提前分钟 | `提前打卡` |
| 迟到 | 上班卡 > 排班开始 + 宽限 | `迟到 N 分钟` |
| 早退 | 下班卡 < 排班结束 | `早退 N 分钟` |
| 休息超时 | 休息段实际 > 规则时长 | `休息超时 N 分钟` |
| 未打上班卡 | 无 in、有 out | `未打上班卡` |
| 未打下班卡 | 有 in、无 out，且 now > 排班结束 + 1h | `未打下班卡` |
| 未打上下班卡 | 无任何打卡，且 now > 排班开始 + 宽限 | `未打上下班卡` |

历史日：`now` 视为该日已结束（一律满足「已过宽限 / 已过下班+1h」类时间门闩）。

## 4. 验收

- [ ] 宽限内打卡不显示迟到；刚过宽限显示 `迟到 1 分钟` 起
- [ ] 早于排班结束下班显示早退分钟
- [ ] 休息超出规则时长显示休息超时；进行中也会算
- [ ] 仅下班卡 → 未打上班卡；全无 → 未打上下班卡；仅上班且过下班 1h → 未打下班卡
- [ ] 仍可出现提前打卡 / 无排班
