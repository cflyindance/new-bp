# 品牌管理列表UI对齐

依据：用户提供品牌管理设计截图并明确要求调整样式和交互；目标为M平台商户管理中心品牌管理。基线main@a06ba365，包含两条本地未推送提交；不提交/合并/推送。

## 页面
品牌管理采用灰底侧栏与白色圆角内容面板。上方为圆角搜索和蓝色新增品牌；下方为服务状态、开通进度、创建日期范围胶囊以及重置。表格为品牌图标/名称/BID、服务状态圆点、阶段进度条、品牌菜单数量、关联门店数量、主管理员、创建日期及省略号操作。

## 业务与交互
- 使用现有真实管理数据和资源权限；不使用截图中的虚构品牌替换数据，不新增占位导航。创建日期取createdAt，数量继续按既有菜单页面与门店归属统计。
- 服务状态保留待启用/已启用/已暂停/已关闭的准确含义；进度条表示五个既有阶段的顺序，不是运营任务完成百分比。进度筛选原始值与业务函数保持一致。
- 仅保留截图中的品牌筛选维度：搜索、状态、进度和日期；旧menu/stores筛选条件从本页状态中忽略，避免隐藏条件限制结果。门店管理筛选保持原状。
- 搜索300ms防抖，回车立即查询；下拉选择即时生效。日期浮层修改后点击应用保存，开始晚于结束提示且不应用；清除日期立即应用。点击外部或Escape关闭浮层并放弃未应用日期；重置清空全部筛选。筛选通过sessionStorage保留，仅影响当前会话。
- 品牌名称/详情进入概览；菜单数量进入品牌菜单；关联门店数量进入品牌门店。未配置和零数量准确展示。主管理员省略且提供完整title，日期YYYY-MM-DD。
- 省略号浮层仅有详情、允许时的代登录；一次只开一个，外部点击、Escape、滚动和筛选刷新关闭，Escape还原焦点。详情和代登录沿用原路由、上下文、权限、Loading与业务校验；只读用户可筛选和浏览，写入仍被原运行时守卫阻止。
- 布局样式限定品牌管理列表，不改其他M/B页面。保留可访问导航、键盘焦点、深色模式与窄屏横向表格滚动。无外部字体或新增依赖。

## 验证及文档
外部浏览器核对默认、筛选/重置、日期错误、空结果、省略号开闭、详情/菜单/门店跳转、代登录、只读权限、窄屏和深色。更新三份商户文档有效章节、版本和页面图，技术证据集中于验证记录。类型检查与有针对性的交互验证；不改eMenu源码。
