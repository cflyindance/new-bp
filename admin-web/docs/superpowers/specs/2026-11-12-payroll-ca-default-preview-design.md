## 当前契约

- 页面保留既有双周默认演示、员工/门店切换、三张汇总卡、四类规则蓝色明细入口与抽屉。
- 仅默认演示首位员工提供显式加州核算上下文；数据限定demo周期与demo员工ID，取完整受影响工作周，期外工时仅参与周判断。
- 首周周日14h、周一至周五各8h、周六10h；次周周日至周五各8h、周六休息。基数20，默认双周合计112h/$2600；Regular80、OT4、OT2 2、每周16、第7天10。
- 演示数据使用现有核算器及投影，不手工拼接工时金额，不保存到实际工资快照。其他员工、无考勤及多角色演示保持既有定义。
- 未配置时显示“未启用加州加班核算，可在‘更多 → 编辑’中设置。”，保留旧工资结果，不补零、不自动启用；已确认历史工资只显示只读历史状态，不提示去编辑。
- 缺数据或不适用情况保留原阻断原因；ready状态不增加重复说明。
