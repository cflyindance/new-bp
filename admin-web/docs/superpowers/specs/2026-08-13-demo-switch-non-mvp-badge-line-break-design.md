# Demo 视角卡片非 MVP 标签换行设计

## 目标

在 Demo 视角切换的平铺面板中，将「集团总部」与「M平台」卡片内的「非MVP版本」标签放到名称下一行，并与名称左边缘对齐。其余卡片、旧版下拉视角控件和全局标签样式保持不变。

## 设计

- 仅修改 `renderFlatChainCard` 中的集团总部分支和 `renderFlatMPlatformCard`。
- 卡片仍使用现有两列网格、整卡按钮、左侧选中图标和状态样式。
- 在选中图标右侧增加纵向文本容器：第一行显示视角名称，第二行渲染现有 `renderNonMvpBadgeHtml()`。
- 通过局部容器抵消共享标签自带的左边距，使第二行标签与名称左对齐；不修改共享标签函数，避免影响侧栏等其他消费者。
- 卡片可随两行内容自然增高，但两个目标卡片仍遵循同一网格行高。

## 可访问性与交互

- 按钮语义、`aria-current`、禁用态、提示文案和点击目标不变。
- 标签仍是按钮文本内容的一部分，读屏顺序保持“视角名称、非MVP版本”。
- 键盘焦点样式、选择视角及 Demo 面板开关行为不变。

## 验收

- 「集团总部」和「M平台」中的「非MVP版本」均显示在名称下一行并左对齐。
- 「门店版」「品牌多门店」以及版本切换、周边产品卡片布局不变。
- 旧版嵌套视角切换不受影响。
- 结构校验、TypeScript 检查和目标页面浏览器回归通过。
