# 员工分配汇总区间累计文案

日期：2026-09-28  
状态：已确认

## 目标与范围

在小费管理的“员工分配汇总”视图，明确员工列表与角色汇总卡片展示的是当前所选门店、日期区间及筛选条件内的累计数据。仅修改该视图的展示文案，不修改计算、筛选、排序、跳转或其他页面。

## 文案映射

| 原文案 | 新文案 | 展示位置 |
| --- | --- | --- |
| 打卡工时 | 打卡总工时 | 员工列表表头 |
| 分配工时 | 分配工时 | 员工列表表头，保持原名 |
| 分配前小费 | 分配前总小费 | 员工列表表头、角色汇总卡片 |
| 贡献入池 | 贡献入池总额 | 员工列表表头、角色汇总卡片 |
| 从池分得 | 从池分得总额 | 员工列表表头、角色汇总卡片 |
| 分配后小费 | 分配后总小费 | 员工列表表头、角色汇总卡片 |

“分配工时”可能由不同规则形成多个口径，汇总单元格可能显示“多口径（N）”。它不是跨规则可直接相加的唯一总工时，因此不添加“总”。

## 实现边界与验收

- 保留现有金额与工时数据、部分确认提示、排序标识和表格结构。
- 切换日期、员工、角色及分配状态筛选后，新文案保持一致，数据继续使用原有计算结果。
- 不批量替换整个小费模块中的同词文案；日期分配汇总、员工每日小费、规则页等不在本次范围。
- 浏览器回归检查员工列表表头和角色汇总卡片，验证原有排序与卡片筛选仍可用。
