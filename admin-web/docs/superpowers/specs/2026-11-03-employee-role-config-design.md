# 员工角色与权限统一配置设计

已确认：用户采用上一轮建议。本次从已核验本地 main@a0ed2503 开发，实现阶段不自动提交。后续用户已授权提交并合并本地 main，未授权推送。

入口：员工列表移除独立商户访问授权和分配角色按钮，改为“配置角色与权限”。角色列两行展示 M 平台角色名、商户角色名及品牌/门店数量。无商户角色查看权限只显示无查看权限，不读明细。查看权限进入两维只读预览。

统一配置页面：返回按钮在标题左，权限预览在右；展示员工姓名、邮箱、账号启停状态；上下两个区域：M 平台角色多选 + 保存 M 平台角色；商户访问授权绑定表 + 添加/编辑/移除 + 保存商户访问授权。每行商户绑定保留角色与品牌/门店范围。系统 ent001 兼容授权只读。

保存：复用 saveMState 与 saveProviderState。分别确认、分别保存、分别显示已保存/未保存/错误，不创建跨存储事务。一类成功不能清空另一类草稿。权限、最后管理员、并发版本及授权上限校验保持。失败保留草稿；取消确认不保存；已保存不重复写日志。

草稿：任一维度未保存时离开、返回、切换预览都提示放弃。两类均保存或无变更才解除保护。

兼容：旧 /staff/:id/merchant-access 进入统一页，新配置为 /staff/:id/roles；旧员工权限 /staff/:id 进入统一只读预览。两类页面与操作权限独立判断；没有商户角色页权限不读或挂载其区域；商户保存仍需 provider-roles/manage，M保存仍需 staff/assign。新页面需员工页可见，不新增菜单或提高权限。

预览：M 平台按角色并集和账号状态解析；商户按已保存员工绑定选择其可访问品牌或门店，再求多角色并集与品牌/门店菜单上限交集；管理员查看范围仍限制于自己可访问目标。账号停用时两类均不生效，草稿不进入生效预览。代登录前置条件不变。

文档：同一任务更新三份既有权威文档至 V1.13，用 EMPLOYEE-ACCESS-CONFIG-20261103-01；逐操作截图就近引用，缺失异常截图明确登记。
