# 计时与自助餐规则 · 计价规则解耦设计

> 日期：2026-08-20  
> 模块：前厅管理中心 / 设置 / 计时与自助餐规则

## 目标

移除功能选项「按照时长收费」，保留「按时计价规则」管理能力。创建或编辑计价规则时不再选择 KTV 或 VIP 包间，仅配置规则本身。

## 页面行为

1. 「计时与自助餐规则」不再展示 seq 443「按照时长收费」开关。
2. 将「按时计价规则」从 seq 443 行内面板改为该分组的组级独立管理区，固定排在其他功能项之前，支持新建、编辑、启停和删除。移除 catalog 中的 443 后，规则区不得依赖遍历到 443 才渲染。
3. 规则列表移除「适用场景」列。
4. 新建和编辑抽屉移除「适用场景」字段及其前置提示。
5. 计价规则不再受 seq 443 开关状态控制。

## 数据兼容

- 将 `DurationBillingRuleInput.scenes` 改为可选兼容字段；规范化和校验允许空数组。
- 新建规则时写入 `scenes: []`。
- 读取规则时同时接受历史非空场景数组、空数组及缺少 `scenes` 的记录；缺少字段时规范为 `[]`，不因升级丢弃旧规则。
- 打开编辑抽屉时记录原规则；保存旧规则时复用原 `scenes`，不因界面移除该字段而覆盖历史值。新规则和已是空场景的规则继续保存 `[]`。
- 暂不升级 localStorage 键版本，避免已有规则和桌位绑定失联。

## 下游联动

- 桌位绑定计价规则的展示条件不再检查 seq 443 开关。
- 桌位是否可绑定仍遵循现有桌位类别约束；本次只解除「按照时长收费」开关和 KTV/VIP 场景选择依赖。
- 规则启用状态、门店隔离、计价金额、单位分钟及向上取整逻辑保持不变。

## 配置目录与文档

- 从 `module-settings-catalog.ts` 及其生成源、`foh-settings-groups`、22 组 baseline、产线范围 seed/manual override、toggle 列表、AI 多选映射和对应验证脚本中移除 seq 443 功能项。
- 分组序列由 `[443, 571, 674, 577, 578, 579, 580]` 调整为 `[571, 674, 577, 578, 579, 580]`；设置 catalog 中不得再存在 seq 443。
- 将原 KTV/VIP 场景化描述改为通用「按时计价规则」描述。
- 更新现有 KTV 按时计价设计、README 和实现计划中关于 seq 443 总闸及场景必选的说明。

## 验收标准

1. 「计时与自助餐规则」中看不到「按照时长收费」。
2. 用户无需开启开关即可查看并创建计价规则。
3. 创建规则时没有 KTV/VIP 包间选项，保存成功。
4. 规则列表不展示适用场景列。
5. 旧规则仍能正常显示、编辑、启停和删除。
6. 合规桌位可直接选择已启用的计价规则，不依赖 seq 443。
7. 组级规则区在 catalog 不含 443 时仍存在，且排在该组其他功能项之前。
8. 存储测试覆盖：新建空 `scenes` 成功、读取缺少 `scenes` 的旧结构成功、编辑历史规则后原场景值保留。
9. 桌位绑定测试分别将历史 443 值设为关闭和开启，两种情况均不影响规则选择。
10. 重新运行设置分组/产线范围相关生成与校验命令，确保 catalog、baseline、范围映射一致；专项验证及项目 TypeScript 构建通过。
