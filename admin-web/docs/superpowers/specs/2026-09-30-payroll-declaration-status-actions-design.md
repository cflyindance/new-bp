# 声明模板状态操作

## 已确认范围

草稿支持修改、删除；已发布支持停用；已停用仅查看，不可删除或分配员工。删除新版草稿仅删除草稿，保留旧发布版和员工关联。删除和停用前二次确认，不改变历史已确认声明。

## 页面行为

沿用当前六列模板列表及组合筛选，在操作列按最新版本状态展示按钮：草稿“修改、删除”；已发布“选择员工、停用”；已停用“查看”。模板名称仍可进入详情。详情同样遵守状态约束；已停用正文只读，移除保存/发布/删除/分配及创建新版本入口。已发布正文只读，保留原创建新版本流程。

新版草稿与有效旧发布版共存时，列表按最新版本显示草稿，“删除”明确标注删除当前草稿；详情可继续使用有效发布版分配员工并提示版本。此规则沿用现有有效发布版判断，不误把草稿正文分配。状态“已停用”指列表最新版本已停用且无可使用的当前发布版。

修改进入原编辑页面。已存在草稿的正文修改保存必须更新该草稿，不再每次产生重复草稿版本。语言名称、代码、模板范围和门店沿用既有 family 不可变约束，本次不扩大可编辑范围；“修改”针对声明正文。新建仍先创建 family，再创建首个草稿。

## 删除语义

弹出明确确认：删除模板名的草稿 Vn；有旧发布版时说明旧版和员工关联不变。取消不写入。仅删除确认指定的 draft versionId；不按模板 family 批量删版本。

若删除后仍有版本，保留 family，并刷新到剩余最新版本；若没有版本且无偏好/覆盖/快照关联，清理空 family，使未发布的新模板从列表消失。有关联时拒绝删除而非级联删除。已发布或已停用版本即使绕过 UI 调用接口也拒绝删除。

历史遗留多个草稿时，每次只删除当前确认的草稿，剩余版本仍可查看；不擅自清理其他版本。

## 停用语义

确认框说明：停用后不能新分配；已关联员工保留原默认选择，未确认声明按现有模板不可用机制提示，不能静默切为系统默认；历史已确认声明和打印快照不变。取消不写入。停用后刷新列表且保留筛选，不自动恢复旧发布版。

## 接口与一致性

repository 增加草稿更新、删除能力；browser demo 和开发 Mock API 均实施相同状态、组织/门店、权限及并发校验。更新/删除请求带 versionId 与 expectedFamilyRevision；成功增加 family revision（删除空 family 除外）。发布/停用已使用 revision，继续复用。过期 revision 或草稿已被发布则冲突，不覆盖新状态，保留输入并提示重新加载。

删除和停用确认时冻结目标 ID；确认后重新检查目标状态，不能把用户确认应用到另一行。提交中禁用重复操作；失败保持页面并显示原因；成功刷新列表、关闭被删版本编辑器。切换全局范围的旧请求不能更新新页面。

此仓库服务端为开发 Mock，不宣称已交付生产鉴权。接口错误不能静默回退演示存储。无改动考勤、薪资金额、员工偏好、周期覆盖和确认快照的写入路径。

## 验收

- 草稿修改保持同一 versionId；重复保存不堆积草稿；发布正文为最后成功保存内容。
- 新模板草稿删除后消失；新版草稿删除后旧发布版、员工关联及冻结快照完整保留；多草稿只删除指定版本。
- 停用确认/取消行为正确，已停用无删除及编辑入口；非法状态直接 API 调用也拒绝。
- 越权、并发发布后删除/编辑、重复点击、请求失败均不导致错误删除或覆盖。
- 组合筛选、选择员工、弹框布局原回归继续通过；浏览器验证各状态入口、取消及专用测试数据操作。不得删除用户既有模板来验收。
