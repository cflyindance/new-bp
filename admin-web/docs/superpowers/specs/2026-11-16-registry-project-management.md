# 注册中心项目管理

范围：项目编辑、启停、空项目删除、名称或微应用标识搜索、状态筛选。旧项目缺少 status 时按 active 处理。

编辑项目沿用必填及 HTTP(S)、绝对微应用路由和项目名称唯一校验；失败保留输入，取消不写入。更新项目配置不批量改写已有页面或已发布导航快照，后续页面保存读取项目最新配置。

项目停用后禁止页面写入和新增导航关联，不删除目录、页面或已发布导航。启用后恢复新增能力。页面目录关联选择器将停用项目的页面按不可选展示；提交时继续复核状态。状态和配置统一持久化于本地 v2 快照。

删除仅允许无目录且无页面归属的项目；输入名称精确匹配才可删除，提交时重新检查非空限制。取消不删除，删除失败保持弹框。演示项目有预设结构，因此不允许删除，不会出现删除后自动初始化回来的流程。

筛选按名称或微应用标识不区分大小写包含匹配，与状态取交集；查询按钮执行，重置恢复空搜索及全部状态。只读可筛选和浏览，编辑、启停、删除必须同时校验 UI 权限和写入权限。

验证脚本：verify-project-management.mjs，覆盖编辑、标识搜索、状态筛选、停用刷新持久化、错误名称阻断、空项目精确删除及非空项目保护。尚未验证生产权限账号和多标签并发。
