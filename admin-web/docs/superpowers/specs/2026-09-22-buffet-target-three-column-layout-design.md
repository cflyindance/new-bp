# 自助餐规则限购对象三列布局

## 背景与目标

当前 `main` 正式页面的规则类型步骤已有三种限购对象：按分类、按菜品、按菜品集。现为双列栅格，第三张卡片换行。用户选择可视化伴侣方案 A：三列等宽。

## 设计

- 自助餐规则在桌面宽度下，将现有三张选项卡按原顺序横向排列，等宽三列并填满内容区。
- 保留卡片标题、说明、选中态、点击区域及选择后的配置逻辑；不改数据结构或保存逻辑。
- 窄屏沿用现有断点，自动变为单列，避免文字溢出或横向滚动。
- 非自助餐配置只有两种限购对象，继续维持双列；“限购主体”等其他双选项区域不受影响。

## 实施边界

在正式页面的“限购对象”容器上，按是否为自助餐配置选择现有三列或双列栅格类。不新增卡片组件，不改变选项集合。

## 验收

1. 自助餐桌面宽度下，三张卡片一行等宽、无横向滚动或内容裁切。
2. 非自助餐两张限购对象卡片继续双列展示。
3. 切换任一限购对象，选中态与后续配置行为不变。
4. 窄屏时卡片纵向排列、说明完整可读。
