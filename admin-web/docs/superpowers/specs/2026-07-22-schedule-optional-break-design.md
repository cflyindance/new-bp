# 安排排班 · 可选休息设计

日期：2026-07-22  
范围：团队管理 → 排班 → 安排排班弹窗

## 背景

当前「休息类型 / 休息名称」均为必填，但短工时（如 2 小时）通常不需要休息。美国常见口径：超过约 4 小时工时才安排休息。

## 决策摘要

| 项 | 结论 |
|----|------|
| 交互模式 | 增加「安排休息」开关（方案 1） |
| 工时阈值 | 固定 **4 小时**（首版不做门店配置） |
| 短工时（≤4h） | 默认关闭；仍可手动打开并配置休息 |
| 长工时（>4h） | 默认开启；可手动关闭，关闭原因**选填** |
| 改时间跨阈值 | **不覆盖**用户已手动改过的开关；仅首次打开 / 切换班次模板时套默认 |

## 交互

1. **安排休息 = 开**：展示并必填休息类型、休息名称。
2. **安排休息 = 关**：隐藏类型/名称；长工时显示「关闭原因」选填输入。
3. 修改上/下班时间只更新工时展示，不自动改开关。
4. 切换班次模板：按新班次工时重新套默认，并重置「用户已改开关」标记。

## 数据

`ShiftAssignment` 扩展：

- `breakEnabled?: boolean` — 是否安排休息；缺省时兼容旧数据：有 `breakId`/`breakName` 视为开启
- `breakSkipReason?: string` — 长工时手动关闭时的可选原因

关闭休息保存时：不写休息明细字段（或清空）。

## 展示

- 排班表格子：有休息仍显示休息摘要；无休息不显示休息文案。

## 非目标（首版）

- 不做阈值门店配置
- 不改打卡合规引擎 / 「休息与加班」全局规则页
