## 1. 交付边界

在现有仓库创建 `apps/menu-design` 独立前端项目，具有独立HTML、源码、配置及构建命令。共享 `src/shell/demo-switch-control.ts` 的全局悬浮球实现。共享组件只提供导航和主机设置，不挂载商家主程序或导入其登录启动流程。

在独立壳层内，以项目自有编辑工作区承接现有三步菜单设计功能；若以同源iframe隔离旧编辑器样式，全局悬浮球由壳层唯一挂载，工作区不再挂载悬浮球。编辑器代码迁入独立项目，不链接运行在59317的历史原型。该iframe不是商家后台壳层，也不要求商家登录。

独立页面路径拟定为 `/menu-design/`，部署子路径需使用配置的站点根路径解析。独立构建产物输出到 `apps/menu-design/build`；由宿主发布脚本复制到站点 `menu-design/`，不得清空宿主dist。开发态由宿主静态挂载此产物，也可单独运行菜单设计开发服务器。宿主配置与独立开发端口在实施计划中固定，不自动扩大AI来源白名单。

## 2. 入口、导航与认证契约

| 字段 | 类型 / 值 | 来源与规则 |
|---|---|---|
| productId | 固定字符串 `menu-design` | 只用于导航注册及当前产品判断，不是账号或权限 |
| label | 中文“菜单设计”；英文“Menu Design” | 共享i18n字典 |
| launchUrl | 由部署基路径解析的 `/menu-design/` | 只能指向已配置入口，禁止任意外部参数成为跳转地址 |
| openTarget | `_blank` | 使用noopener；不得把商家token放入URL |
| currentProduct | `menu-design` | 由独立入口上下文提供，不覆写商家标签页持久化shell模式 |
| authRequired | `false` | 只作用于菜单设计启动，不改商家/PIT鉴权逻辑 |
| merchantBaseUrl | 配置的同站宿主入口 | 用于悬浮球返回，不能由未经验证的查询参数指定 |

源页面点击入口后保留路由与会话。独立后台内再次选择当前“菜单设计”只关闭面板，不无限新开自己。去其他产品时通过共享导航适配器跳转宿主的既有路由；不得只改独立页面hash而造成空白。代管限制继续复用已有逻辑，菜单设计不模拟登录、不创建假账号、不清空源页面认证存储。

若弹窗被阻止，提示用户允许新标签页并提供明确的独立入口链接；不能声称已打开，也不未经同意覆盖当前页面。

2026-09-30 登录连续性修复记录（配对产品 v1.1 第0.3节，业务范围不变）：入口通过随机 `menuSession` 通道标识关联来源标签页，URL不包含邮箱或登录凭据。同源 BroadcastChannel 在离开菜单设计时请求原页实时账号；原页重新读取登录与代管状态，不使用打开时的账号快照。仅成功响应后在目标标签页建立既有会话，再由目标路由执行原权限校验。关联返回前清理目标标签页的旧认证，避免退出登录后回退页面复用旧身份；不修改源页会话。超时1.5秒、源页关闭/刷新、退出、受限代管均不授予身份，目标正常登录。跨域/端口不做会话传递，PIT独立鉴权不改变。旧入口生成的页面无通道标识，需重新从源页打开。新增自动测试覆盖实时账号、退出、缺失来源和免登录启动；真实已登录跨标签页 E2E 待登录后验证。

## 3. 编辑数据及保存

复用现有项目模型：输出宽高与单位、商品稳定ID/名称/价格/选用状态/图片、参考选择与分析结果、AI布局、页面顺序与手动覆盖、导出配置。此次不另造商品事实模型，不读取或写回真实POS。

独立项目使用独立命名空间保存草稿：本机浏览器存储，保存异常显示未保存状态，不覆盖历史原型存储。工作区刷新恢复最后成功保存的草稿；直接进入无草稿时显示首页。跨域/端口的旧原型草稿不自动迁移；新窗口未保存输入不宣称能恢复。用户可使用现有新建、复制、继续编辑功能；多项目列表、跨设备同步不在本次范围。

沿用尺寸、金额和导出计算：价格保留用户输入小数，AI不生成或覆盖价格；`px`导出按输入像素，`mm`按既有DPI换算；PDF页尺寸按px×72/96或mm×72/25.4，方向由宽高决定。此次不改变舍入、价格单位、税费或金额汇总；税费、统计、付款、业务权限均不适用。

## 4. 流程与状态

| 事件 | 前置条件 | 成功写入 | 失败/取消 |
|---|---|---|---|
| 打开独立入口 | 不要求登录 | 当前页面为菜单设计；恢复本机草稿或首页 | 加载错误提示，不跳商家登录 |
| 上传参考图 | 用户选PNG/JPG并通过既有大小与解码检查 | 保留图片，分析状态idle | 保留旧图和草稿 |
| 分析参考图 | 已有上传图，用户确认发送 | running→ready；真实分析摘要与样式 | failed/cancelled；保留图，可重试，不能继续选品 |
| 选择图库 | 有效内置模板ID | 模板可用，直接进入选品 | 无效ID不改数据 |
| 生成 | 模板可用、商品完整、用户确认发送 | AI配色、容量、坐标通过校验后替换设计；进入编辑 | 保留草稿/旧设计，提示错误，不生成模拟成功结果 |
| 编辑输入条件 | 影响生成的字段变化 | 标记原生成失效，清理过期导出资格 | 保存失败提示，不虚报持久化 |
| 导出 | 当前设计有效、预检通过且用户确认 | 冻结当前状态，完整生成下载文件 | 不交付部分ZIP/PDF，不改商品事实 |
| 离开菜单设计 | 用户点击悬浮球目标 | 导航到宿主对应入口，目标自行鉴权 | 链接不通提示，不解除权限 |

取消与迟到结果规则沿用已验证请求编号：取消后返回的结果不能写入当前草稿。独立入口迁移不得恢复旧八步门槛。

## 5. AI及文件接口

复用本机Codex桥接：`GET /status`取得当前进程令牌，`POST /run`带`X-Menu-Token`与显式consent。JSON输入含kind(analyze/generate)、画布width/height、参考图data URL及设计brief。分析需要图片；生成只传商品数量、名称长度、图片有无等布局所需数据，不额外传商品事实或凭据。每次发送前说明参考图全部可见内容会随图发送。

服务只监听127.0.0.1，来源采用明确开发地址白名单；禁止通配Origin、公开反向代理Codex或给任意访问者提供当前账户能力。静态部署无本机服务时应可编辑和导出既有有效设计；新分析/生成明确提示不可连接，不假装成功。独立项目启动说明必须列出AI桥接的单独启动方式。

现有请求体8MB、图片字符串7MB、180秒超时、单并发、输出颜色/容量/边界/重叠检查保留；额度错误/超时/格式错误均显式报错。输出槽位容量1–6；w≥0.2、h≥0.18，归一化坐标在画布内容区内。

下载不依赖原型服务：优先浏览器本地Blob下载；若沿用临时下载服务，则必须由独立项目提供限量、过期、同源校验的接口，不引用59317。PNG/JPG/ZIP/PDF使用同一菜单渲染器；PDF为栅格预览，字体嵌入及专业印前不在本次范围。

## 6. 验证算例及验收

- 未登录直接进入独立入口：显示首页，刷新结果相同；去商家后台仍要求合法会话。
- 已登录商家点击菜单设计：新增一页，原URL和认证状态不变；菜单设计中只显示一个悬浮球，产品高亮正确。
- 代管受限会话：原有受限选项保持受限，不借菜单设计入口解除限制。
- 无图片11道商品、AI容量3：ceil(11/3)=4页，最后一页2道，不丢商品或改价。
- 商品价格缺失：生成按钮不可执行；0元合法；48.55导出仍为48.55。
- 上传图分析失败或取消：图片仍在，产品选择门槛不解除；重试成功才继续。
- AI服务停止：页面可正常显示、输入和保存，调用报连接错误，不回退模拟。
- 新尺寸或商品变更：旧设计失效，必须重新生成；不能导出旧文件冒充新结果。
- 多页导出某页失败：整个导出失败，不显示可下载的部分文件。
- 构建独立项目后停止59317：入口、工作区、共享悬浮球、导出仍可加载；AI按独立桥接可用性处理。
- 手机窄屏/桌面：悬浮球可拖动并限制在视口内，展开菜单不被编辑器iframe或dialog遮挡；Esc关闭、焦点恢复。
