# 权限管理中心全操作演示数据

用户明确范围为整个权限管理中心。基线 main@0cd32dea，新独立 codex/permission-center-demo-20261103。仅实现，已获用户提交、合并及推送授权。

数据方案：默认目录保留 ent001 系统管理员、ent002 周预设、ent003 吴蓝图、ent004 郑审计，新增保留 ID 的演示待授权员工和演示停用员工（默认停用）。既有账号同邮箱的数据不覆盖，冲突 ID 不生成额外绑定。

M 平台 7 角色：原系统管理员；演示商户访问员（品牌/门店只读及进入动作）；演示预设配置员（预设可编辑、允许同步、禁止发布/恢复）；演示权限审计员（权限中心只读）；演示设备导出员（设备只读、允许独立导出）；演示空权限角色；演示设备导出副本（未绑定可删除）。周预设同时有预设/商户访问角色，吴蓝图有商户访问/设备导出角色，郑审计为只读审计，停用员工绑定设备导出但无生效权限，待授权员工无绑定。根管理员仍唯一授权管理员，最后管理员保护不削弱。

商家后台 5 角色：保留原订单/财务/概览三个查看角色，增加门店运营角色（仅现有 module:store-mgmt 范围，设置/动作可编辑）和未关联空角色（可删除）。保留原三员工品牌/门店范围，周预设额外绑定运营角色到现有第一家门店，停用员工也保留一条运营门店样例；待授权员工没有绑定。品牌和门店目录缺失则跳过相应绑定，不生成虚构对象；不调整菜单开通上限、M 入口前置条件或系统兼容管理员身份。

覆盖操作：角色新建/编辑/复制/权限配置/效果预览/成员/日志/未绑定删除/绑定删除保护；员工新增/编辑/启停/分配 M 角色/商户授权增改移除保存/双维生效预览/范围切换/未授权和停用空态；总览统计、最近记录、集中来源及角色筛选/清除与 M 前后值。配置保存继续产生真实本地操作记录；初始化合成记录明确 actor=演示数据（非真实操作人）、action 前缀演示、固定样例时间。

记录：M 默认预设角色、复制、编辑、删除历史样例和四位员工绑定，生成顺序前后快照一致；不记录密码。商户 5 个角色预设与最多 4 位员工授权预设，原3角色ID及示例范围保持。集中日志既有演示提示同时识别 M 与商户样例，不在角色页重新添加被用户移除的横幅。

初始化边界：两类授权存储键缺失时使用默认样例；已有合法空或非空快照完全保留，损坏 JSON 显式报错，不静默重置，不自动追加/复活已删除的样例。账号沿用现有 seed 合并机制，只增保留名称/ID的新演示账号，不改既有启停/邮箱/密码。无需重置现有浏览器数据；新预览端口验收完整默认样例。

实现约束：提取纯 M 演示工厂与存储选择器，账号和两类授权共享保留演示身份清单，不从用户自建账号推导默认授权。权限目录之外不创建业务数据，不模拟服务端生产权限。

验收：使用外部 Chrome 新端口，按逐操作清单浏览/操作并恢复测试改动；源工厂验证7角色、6账号、允许/禁止/只读输出、2角色并集、停用/未授权、默认管理员、范围与日志筛选。校验已有快照/坏 JSON 不覆盖，缺目录跳过，所有合成记录无凭据。按 DOC-CURRENT 新规则单独维护演示/验证记录，业务文档 V1.14 不变、同变更 PERMISSION-DEMO-SCENARIOS-20261103-01，逐操作截图与未验证项登记。已有保存授权不会自动获得新样例，交付明确说明。

实测与未执行项目逐项登记在 docs/验证记录/权限管理中心Demo数据与验证记录.md，不宣称全部操作验收通过。
