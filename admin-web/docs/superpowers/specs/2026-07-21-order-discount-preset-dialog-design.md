# 订单中心 · 折扣预设对话框交互设计方案

> **模块**：订单中心 → 设置 → 折扣（seq 446「折扣设置」）  
> **版本**：v1.0  
> **日期**：2026-07-21  
> **状态**：已落地  
> **场景**：将折扣预设的新增/编辑从行内编辑改为对话框，交互与加收（447）对齐  
> **关联**：`src/config/module-settings-discount-surcharge-presets-ui.ts`

---

## 一、背景与目标

### 1.1 现状

同一文件内两种交互：

| seq | 功能 | 新增 | 列表编辑 |
|-----|------|------|----------|
| 446 | 折扣预设 | 表格插入可编辑行 | 行内改名称 / 比例类型 / 数值 |
| 447 | 加收预设 | 打开对话框 | 只读列表 +「编辑」打开对话框 |

### 1.2 目标

折扣（446）默认改为：

1. 点击「新增折扣」→ 对话框展示新增页；
2. 列表只读展示 +「编辑」打开同一套对话框；
3. 交互与加收一致，字段仅保留折扣所需三项。

### 1.3 非目标

- 不改存储字段 `446-discount-presets` 与 `RatePresetItem` 核心结构（`id` / `name` / `kind` / `value`）；
- 不改加收（447）行为与字段；
- 不改折扣原因相关项（162 / 163 / 164）；
- 本期不做折扣/加收共用 dialog 抽象层。

---

## 二、方案选型

采用**方案 1：折扣专用轻量对话框，列表交互对齐加收**。

| 方案 | 说明 | 取舍 |
|------|------|------|
| **1（采用）** | 折扣独立 dialog；列表只读 + 编辑/删除 | 与加收一致，改动集中，YAGNI |
| 2 | 抽出共用 dialog 基建 | 超出本次对齐交互范围 |
| 3 | 复用加收 dialog 按 seq 隐藏字段 | 耦合重，易误触加收逻辑 |

---

## 三、交互与 UI

### 3.1 列表

- 有数据时展示表格：折扣名称、比例类型、数值、操作（编辑 / 删除）。
- 无数据时不渲染空表（与现状一致）。
- 取消行内 `<input>` / 比例类型 radio。
- 名称为空的历史数据列表展示为「未命名折扣」（对齐加收「未命名加收」）。

### 3.2 对话框

| 模式 | 入口 | 标题 | 保存文案 | 行为 |
|------|------|------|----------|------|
| 新增 | 「新增折扣」 | 新增折扣 | 保存 | 写入新预设并刷新列表 |
| 编辑 | 行「编辑」 | 编辑折扣 | 保存修改 | 按 `id` 覆盖后刷新列表 |

**字段（仅此三项）：**

1. **折扣名称**：必填文本；`maxlength=50`；
2. **比例类型**：百分比 / 固定金额（默认百分比）；
3. **数值**：`number`，`min=0`，`step=0.01`；百分比时上限 100；固定金额无上限（沿用当前行内编辑）；单位随类型切换（`%` / `元`）。

**关闭：** 取消按钮、遮罩点击、Esc；不保存未提交草稿（与加收一致）。

**校验：** 名称为空时 `alert` 提示并聚焦名称框，阻止保存（与加收一致）。

### 3.3 默认值（新增）

- `kind`: `percent`
- `value`: `10`（与当前行内新增默认一致）
- `name`: 空

## 四、实现边界

**改动文件：** `src/config/module-settings-discount-surcharge-presets-ui.ts`（必要时同步 `main.ts` 的绑定若已有通用入口，优先复用现有 `bindDiscountSurchargePresetEditors`）。

**实现要点：**

1. `renderPresetRow`：446 分支改为只读展示 + 编辑/删除（可参考 447，无「启用/停用」）。
2. 新增 `renderDiscountCreateDialog` 及 open / close / fill / save 一组函数（命名与 surcharge 对称）。
3. `data-rate-preset-add`：446 打开折扣对话框；447 仍打开加收对话框。
4. 写入路径与 447 对齐：dialog 保存 / 删除直接 `writeRatePresets` + `rerenderEditor`；446 移除对行内 input 的 `persistEditor` 依赖（`collectPresetsFromEditor` 在无行内 input 时自然不再被 446 触发）。
5. 删除或停用仅服务于折扣行内编辑的逻辑（如行内 `syncRowKindUi` 在 446 上的依赖）。

**持久化：** 仍通过 `writeRatePresets(446, items)` 写入 local module setting；页面级「保存并下发」流程不变。

---

## 五、验收标准

1. 点击「新增折扣」打开「新增折扣」对话框，而非插入空行。
2. 保存后列表出现只读行；再点「编辑」可回填并修改。
3. 「删除」仍可移除该预设。
4. 百分比数值不可超过 100；名称为空不可保存。
5. 加收（447）行为与 UI 无回归。
6. 刷新页面后 446 预设数据仍在（同一 storage key）。

---

## 六、风险与回退

- **风险**：旧数据在行内编辑时代产生的空名称行，编辑时仍需补全名称才能保存。
- **回退**：还原本文件中 446 的 row/dialog/add 分支即可；存储格式兼容，无需数据迁移。
