# 门店近30天营业状态设计
基线：main@fd787a40；分支codex/store-business-status-20261110。
变更：STORE-BUSINESS-30D-20261110-01。用户已确认实施；不授权提交、合并、推送。
## 规则
手工档案状态与计算结果分开：preparing筹备中、open已开业（允许自动判定）、closed暂停经营（兼容旧停业）、terminated已关闭；历史archived已归档保留，不自动迁移。人工非open状态优先。
营业事实按MID和当地营业日YYYY-MM-DD归属，截止日期是门店品牌时区的今天（门店无独立时区字段）；当前无营业日切点配置，采用当地日期。起始日期为今天减29日，共30天，含端点。每天非负销售额、小费及完整非manual且hours>0的打卡构成事实。任何可靠正向事实即可显示正常营业；只有三类事实覆盖全部30天且数据有效时，全部零才显示近30天无营业记录；未接入、过期、缺日、非法金额/时区显示营业情况未知。未知不推断暂停。
## 数据边界
现有项目没有生产销售/考勤接口，使用独立可替换的营业事实读取适配器；不得把订单数量当金额，也不读取已分配小费快照冒充原始营业事实。已登记演示MID提供明确合成场景并标明演示来源；其他门店无数据为未知。存储的事实包含MID、timezone、覆盖和更新时间，错误不降级为全零。不同门店不得共享事实。小费模块仅复用判定口径，本任务不改变小费计算。
## 页面
选择品牌门店、品牌门店列表、门店管理及概览统一展示经营状态；手动下拉只包含档案状态，不能手选正常营业。概览展示统计周期/来源/更新时间并允许有门店状态编辑权限者维护。查询筛选按同一计算状态，保留已归档筛选。保存沿用权限、成功刷新和变更记录；失败保留原状态并提示，无变化不写日志。无自动写回档案、不影响服务/代登录/菜单权限。
## 验证
30日首尾/31日前/未来、时区跨日、单独销售/小费/打卡、manual和不完整工时、数据不全/坏数据、人工覆盖、门店隔离、筛选与显示一致、状态保存权限与失败回滚。三份文档同步正文、版本、图和缺口。外部浏览器验收，预览链接带端口。

## 数据可信度优先级
时区或查询周期无法解析、MID不匹配、更新时间无效/晚于当前时间时，一律未知。其余情况下：统计窗口内且不晚于同步日期的任一有效正向事实足以证明营业，其他源缺失或非法不抹去该证据。没有正向事实时才检查完整性；必须每天销售、小费、打卡字段齐全有效，且complete=true声明三源均已覆盖该日，并且updatedAt属于当地今天，才显示近30天无营业记录；否则未知。当天complete指截至updatedAt已同步完整，非宣称整日结束；无记录表示截至同步时刻。旧同步快照中的窗口内正向事实仍有效，全零过期快照不能证明无营业记录。
