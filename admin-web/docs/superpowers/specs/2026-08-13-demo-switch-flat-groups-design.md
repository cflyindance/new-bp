# Demo 视角切换分组平铺设计

## 背景

当前 Demo 悬浮控件展开后，只显示「视角切换」「版本切换」「周边产品」三个二级触发器。用户仍需再次点击触发器，才能看到具体选项。此次调整要求点击「Demo视角切换」后直接看到所有可用视角，并按业务类别归类平铺。

## 目标

- 点击 Demo 悬浮球后，一次性展示全部可用选项。
- 按「视角切换」「版本切换」「周边产品」三组分类。
- 组内采用两列卡片平铺，清晰表达当前状态和可点击状态。
- 保留现有权限、产品版本、独立后台路由与切换规则。
- 保持悬浮球拖动、遮罩关闭、点击空白关闭和 Esc 关闭行为。

## 非目标

- 不修改商家后台、M 平台、eMenu 或 Kiosk 的业务页面。
- 不改变 MVP 与复杂版本所控制的选项可见性。
- 不新增视角、版本或周边产品。
- 不修改登录、代管或数据范围授权规则。

## 信息架构

Demo 面板使用单张浮层卡片，内部按以下顺序纵向展示：

1. 视角切换
2. 版本切换（仅允许显示版本切换的后台）
3. 周边产品

组与组之间使用轻分隔线和稳定间距。组标题使用小字号、半粗体和弱化颜色，选项使用两列网格。

### 视角切换组

候选项沿用现有规则：

- 门店版
- 集团总部（仅复杂版本且账号允许时显示）
- 品牌多门店
- M平台（仅复杂版本允许时显示）

代管模式继续锁定品牌视角。锁定时展示不可操作的品牌多门店卡片和锁定说明，不提供其他视角入口。

### 版本切换组

- MVP版本
- 复杂版本

商家后台显示该组；M 平台、eMenu 本地配置后台、Kiosk 本地配置后台继续隐藏整组。切换版本后重新挂载面板，使受版本控制的视角选项立即刷新。

### 周边产品组

- eMenu本地配置后台
- Kiosk本地配置后台

代管模式下该组保持不可操作，沿用现有受限规则。进入周边产品后台后，当前产品卡片显示选中状态。

## 视觉与状态

- 面板宽度从当前窄触发器布局增加到适合两列卡片的宽度，桌面端目标宽度约 22rem。
- 选项卡片使用现有设计令牌，不创建新的全局色值。
- 当前项使用 `primary` 浅底、主色文字、内描边和勾选图标。
- 普通项使用轻灰背景或透明背景，悬停时提升对比度。
- 不可用项降低透明度，使用禁用鼠标样式，并保留解释性 `title`。
- 长文案允许在卡片内合理换行，不依赖截断理解选项。
- 面板最大高度受视口约束；小屏时面板内部纵向滚动，悬浮球位置不变。
- eMenu/Kiosk 中隐藏版本组后，其余两组自然上移，不保留空白占位。

## 组件边界

现有三个控制模块继续拥有各自业务逻辑：

- `view-switch-control.ts`：视角选项、权限判断和视角切换。
- `version-switch-control.ts`：版本选项和版本切换。
- `peripheral-products-control.ts`：周边产品选项和独立后台切换。

每个模块新增或导出平铺渲染能力，并让现有绑定函数同时支持平铺标记。`demo-switch-control.ts` 只负责组合三组内容、控制版本组是否出现，以及悬浮面板的打开/关闭，不复制业务判断。

旧的组内下拉结构不再由 Demo 面板渲染。若项目内无其他调用方，可删除对应的二次展开结构；对外保留现有绑定函数名称，减少调用方改动。

## 交互流程

1. 用户点击 Demo 悬浮球。
2. 面板展开并立即显示所有当前可用选项。
3. 用户点击任一卡片：
   - 视角卡片调用现有视角切换逻辑；
   - 版本卡片写入版本并重新挂载；
   - 周边产品卡片进入对应独立后台默认路由。
4. 路由或版本变化后，面板按新状态重新渲染。
5. 点击遮罩、面板外区域或按 Esc，关闭整个 Demo 面板。

切换选项时不要求先关闭某个组内菜单，因为平铺模式不存在组内菜单。

## 可访问性

- 三组使用带可访问名称的分组容器。
- 每个选项使用原生 `button`。
- 当前选项使用 `aria-current="true"` 或等价的可访问状态。
- 禁用选项使用 `disabled` 与 `aria-disabled="true"`。
- 保留可见焦点环，并支持键盘 Tab 顺序按组从上到下、组内从左到右移动。

## 验证

### 结构校验

- Demo 面板包含三类稳定分组标记。
- Demo 面板不再渲染三个二级菜单触发器。
- 视角组不包含 eMenu 或 Kiosk。
- 周边产品组包含 eMenu 与 Kiosk。
- `showVersionSwitch: false` 时版本组不存在。

### 类型与差异检查

- `npx tsc --noEmit`
- 相关文件 `git diff --check`

### 浏览器验收

- 商家后台点击一次 Demo 悬浮球即可看到三组全部可用项。
- MVP 与复杂版本下，受版本控制的视角显示正确。
- eMenu/Kiosk/M 平台中版本组隐藏，视角和周边产品仍平铺显示。
- 当前视角、版本和周边产品状态高亮正确。
- 门店、集团、品牌、M 平台、eMenu、Kiosk 切换均正常。
- 遮罩、空白区域、Esc 可关闭面板；悬浮球仍可拖动。
- 页面控制台无新增错误。
