# 小费分配术语与日期排序设计

## 目标

统一小费管理术语，并让“分配汇总”日期列表支持正序、倒序切换。首次进入默认展示今天往前一个自然月至今天的数据，并默认倒序；用户选择的排序方式需要被记忆。

## 术语调整

- 用户可见的“小费分配汇总”统一改为“小费分配”。
- 用户可见的“日期任务”统一改为“分配汇总”。
- 覆盖导航、页面标题、页签、规则页返回按钮、说明、导出提示、导出报告名称及无障碍文案。
- 内部路由 `/team/tips/distribution`、视图值 `date`、DOM ID、存储结构和分配业务逻辑不改名。

## 默认日期范围与快照兼容

- 结束日期取浏览器本地时区的今天。
- 开始日期取今天往前一个自然月，含开始和结束日期。
- 月末回退采用目标月份最后一个有效日期。例如 3 月 31 日回退至 2 月 28 日或 29 日。
- 仅当快照同时包含符合 `YYYY-MM-DD` 的开始、结束日期且开始日期不晚于结束日期时，才恢复快照日期。
- 旧快照缺字段、日期为空、格式非法或开始日期晚于结束日期时，整套日期范围回退为默认最近一个月；门店、角色、员工等其他合法筛选字段仍可独立恢复。
- 从详情返回且快照日期有效时继续恢复原范围，避免破坏返回体验。

## 排序控件

- 采用已确认的方案 A：在“分配汇总”筛选栏最右侧增加原生下拉框。
- 标签/无障碍名称为“日期排序”，选项为“日期倒序”“日期正序”。
- 默认值为倒序。
- 控件仅在“分配汇总”视图显示；切换到“员工对账”时隐藏，但不清除已选值。
- 用户选择写入 `localStorage`，使用独立版本化键 `tipout-summary-date-sort-v1`，值只允许 `desc` 或 `asc`。非法或缺失值回退为 `desc`。
- 排序偏好不写入 history 快照，现有快照 schema 保持不变；旧、新快照都从独立的排序偏好读取。
- 状态优先级为：有效的 `localStorage` 值优先，否则使用 `desc`。读取异常、缺失或非法均回退 `desc`；写入异常时，本次页面会话仍保留用户刚选择的排序值。

## 列表与数据行为

- canonical `dailyRows` 保持现有生成顺序，金额汇总、员工聚合、分配、员工详情快照和导出继续消费未排序数据。
- 仅在 `renderDailySummaryList` 向日期表格写入 DOM 前，使用 `dailyRows.slice().sort(...)` 创建展示副本；不得在 `buildDailyDataset` 或 `renderSummaryViews` 的上游改变 canonical 数据顺序。
- 倒序示例：选择 01/25–01/28 时显示 01/28、01/27、01/26、01/25。
- 正序显示 01/25、01/26、01/27、01/28。
- 排序仅影响当前日期列表的可见行顺序，不改变金额统计、小费池执行结果、分配状态、详情 URL 或导出数据范围。
- 日期范围改变和视图往返后继续应用当前记忆的排序值。

## 变更边界

- `src/team/tips/templates/distribution.html`：更新标题、页签，增加排序下拉框，移除硬编码演示日期默认值。
- `src/team/tips/programs/distribution.js.txt`：日期范围初始化、排序偏好读取/写入、列表排序、视图切换显示状态。
- `src/config/navigation.ts`、`src/i18n.ts`、规则和员工对账模板、导出程序：同步中英文用户可见术语；中文使用“小费分配”“分配汇总”，英文导航标题使用 “Tip allocation”。
- `src/team/tips/tips-page.css`：仅补充排序控件在现有筛选栏中的尺寸和响应式行为。
- 更新现有小费管理验证脚本，覆盖文案、默认范围、排序、记忆和视图切换。

## 错误与兼容

- `localStorage` 读写失败时不阻断页面，当前会话仍采用倒序或用户刚选择的值。
- 日期数据缺失或无效时保持现有空状态行为。
- 旧页面快照不含排序字段时自动使用已记忆值或默认倒序。

## 验收标准

1. 页面及相关入口不再向用户展示“小费分配汇总”“日期任务”。
2. 首次进入且没有恢复快照时，日期范围为今天往前一个自然月至今天。
3. 默认按日期倒序；01/25–01/28 的顺序为 01/28、01/27、01/26、01/25。
4. 选择正序后立即重排，刷新或重新进入仍保持正序。
5. 员工对账视图隐藏排序控件，返回分配汇总后恢复控件和值。
6. 排序前后统计金额、行数据集合、详情导航和导出范围不变。
7. 日期默认值覆盖平年 3/31→2/28、闰年 3/31→2/29、5/31→4/30、1/31→上一年 12/31，并以浏览器本地日期而不是 UTC 日期作为“今天”。
8. 旧快照、空日期、非法日期和开始晚于结束日期均回退默认日期；其他合法筛选字段仍恢复。
9. 排序记忆覆盖有效值、缺失、非法值、读取异常和写入异常；员工对账往返与页面刷新后行为符合状态优先级。
10. 切换排序前后，员工对账行、员工详情快照及导出内容和顺序保持不变。
11. 运行时源码中逐项检查导航中英文标题、页面标题、页签、规则返回按钮、导出提示/报告名和 aria-label；历史设计文档不纳入术语替换范围。
