# 营业额加权扣除实施计划

基线：main@bb11e4a0。分支：codex/tips-sales-deduction-20261104。

确认规则：仅营业额计算项提供可选单角色扣除方，默认空；其他来源不提供扣除方。应扣总额来自对应营业额项入池金额，员工应扣＝该金额×个人营业额×人工权重÷所选角色员工加权营业额合计。人工权重默认1；实扣受个人余额封顶，不转嫁。

1. 编辑页在营业额项取值条件前显示扣除方与人工权重，独立贡献设置不作为当前入口；关联项删除、门店变化、取消与整页保存边界完整处理。
2. 扣除计算记录来源项ID、目标金额、个人营业额、人工权重、加权营业额、占比及实扣。日明细公式调整影响对应目标额。
3. 更新规则摘要、贡献范围、快照核验及明细字段；保留已确认结果。
4. 校验100/200/200示例、非1权重、混合来源、可选空角色、0分母、金额尾差、余额不足、取消及保存回填。
5. 同步三份权威文档和带背景真实截图。
