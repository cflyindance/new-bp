# 默认广告 Implementation Plan

> 基线：origin/main@3ed62843；功能分支 codex/ad-default-fallback-20261123。仅实现并验收，提交、合并、推送另按授权。

**目标：** 商家按门店、渠道和广告位配置长期默认广告；活动广告结束后由终端选择默认内容。

**实现：** 复用原生广告流程；新增共享默认广告策略，保持正常活动广告数据与排期兼容。后台保存不代表真实终端已下发。

1. `src/marketing-display/default-ads.ts`：类型、作用域、替换分区、播放选择契约；新增策略测试和原生编译入口。
2. 原生 position editor/create/edit：新建用途选择，默认素材禁止跳转，保存用途；已存用途不可转换，复制可设默认。
3. store-select/list/effective-time：默认广告跳过排期，替换确认、原子保存，默认类型筛选及启停状态；正常排期排除默认记录。
4. 运行共享策略、原生脚本与类型检查；实际浏览器验收新建、复制、取消替换、部分门店替换、启停、普通广告兼容。
5. 同步展示内容唯一三份文档、PC 实际截图和验证记录，列明跨仓库终端、服务端持久化与下发缺口。
