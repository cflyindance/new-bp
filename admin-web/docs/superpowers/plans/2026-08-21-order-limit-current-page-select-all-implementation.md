# 限购数量当前页全选实施计划

1. 扩展商品规则列表验证，覆盖表头复选框、当前页范围、半选状态、空列表禁用和现有批量操作。
2. 运行专项验证，确认旧实现按预期失败。
3. 在列表渲染阶段计算当前页选中数量、全选和半选状态。
4. 将“配置门店”左侧表头占位替换为原生全选复选框。
5. 渲染后同步设置复选框 `indeterminate` 属性。
6. 增加全选复选框 change 处理，仅合并或移除当前页 `rowId`，不影响其他页状态。
7. 保持筛选、搜索、分页、每页条数变化时清空选择的现有规则。
8. 运行 JavaScript 语法检查、专项验证和全部菜单限购回归脚本。
9. 使用本地浏览器验证未选、半选、全选、批量应用数量和批量删除。
10. 检查差异，提交功能分支，合并到 `main` 后复测。
