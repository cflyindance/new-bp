# 商家订阅品牌门店维度与列表统一计划

基线main@bcd20cf8，分支codex/subscriptions-brand-store-20261030。

1. 商家订阅主体仅品牌/门店；界面、创建、默认演示与有效能力合并不包含集团。历史集团记录原样保留，不展示、不计入统计或生效范围，不自动分配给品牌。
2. 所有订阅使用单一行模板：主体及BID/MID、类型标签、可点服务名及编码/来源、统一本地开始/结束、状态/快照价、统一操作区。保留原菜单预览和品牌权益全屏路径。
3. 创建存储层拒绝集团类型，集团历史记录不允许续期/停用；纯品牌向门店继承与门店增配仍生效。
4. 检查旧集团存储保持、无集团UI/默认种子/生效来源、统一行/日期、新建品牌门店选项、菜单预览/权益/权限回归，更新三份文档及实采图片。
