# 自助餐默认场景规则实施计划

1. 新增仓库级验证脚本，覆盖空仓库生成 8 条、部分补齐、草稿不覆盖、重复加载幂等、快照不变和菜单数据隔离。
2. 在共享规则流程中向模块 profile 注入默认草稿/正式规则工厂，不让 profile 复制流程默认值。
3. 在自助餐仓库增加 `loadForAuthoringList(factory)`：纯读判断完整性；缺失时使用既有锁协议锁内重读、重算并单次写回，仅修改 `rules` 与 `revision`。
4. 自助餐规则列表改用作者态加载接口；编辑、详情、发布和运行时继续使用纯读 `loadRules()`。
5. 运行全部自助餐验证和选定菜单下单限制回归，执行生产构建。
6. 浏览器确认首次列表有 8 条禁用规则，刷新不重复且无控制台错误，随后提交实现。
