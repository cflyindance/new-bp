# 自助餐人数与轮次区间实施计划

1. 更新权威规格，定义每单/每轮的人数区间与分轮次二维矩阵、边界、兼容和运行时选档。
2. 更新场景与运行时验证，先确认旧实现因固定单人数档而失败。
3. 调整共享流程 profile normalizer：按桌/订单继续固定单档，按人数保留并校验用户人数区间。
4. 复用菜单下单限制场景配置组件；按人数三周期展示人数区间，分轮次额外展示轮次区间。
5. 在数量配置与预览中按主体展示人数筛选、人数列及人数 × 轮次矩阵。
6. 运行时按人数和轮次唯一命中二维单元，并保持旧 `limit` / `roundLimits` 数据兼容。
7. 运行自助餐及菜单模块回归、生产构建与浏览器验证后提交。
