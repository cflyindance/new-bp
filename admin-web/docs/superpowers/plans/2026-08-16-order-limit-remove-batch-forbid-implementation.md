# 移除批量“设为禁止”实施计划

## 目标

移除批量设置工具栏中的【设为禁止】快捷入口及专用 `zero` 模式，同时保留显式输入 `0` 后通过【应用数量】设置禁止下单的能力。

## 实施步骤

1. 更新现有订单限购验证：断言不存在 `data-apply-batch="zero"` 和【设为禁止】文案，保留 `data-apply-batch="value"`。
2. 增加对批量应用处理的断言：只接受 `value` 模式；先拒绝空输入，再转换为数字；显式 `0` 仍保存为 `configured: true`。
3. 运行目标验证，确认旧实现按预期失败。
4. 从当前和兼容批量工具栏中删除【设为禁止】按钮。
5. 简化批量应用事件处理，删除 `zero` 模式分支，并增加空字符串校验。
6. 运行 JavaScript 语法检查和全部订单限购验证脚本。
7. 使用本地浏览器检查工具栏、空输入校验和显式输入 `0` 的保存结果，并检查控制台。
8. 检查差异，提交功能分支，合并到 `main` 后复测。

## 不在范围内

- 不改变单项输入 `0` 的语义。
- 不改变数量矩阵、批量选择、门店/人数/轮次/产线切换逻辑。
- 不改变草稿、复制、发布和历史规则兼容结构。
