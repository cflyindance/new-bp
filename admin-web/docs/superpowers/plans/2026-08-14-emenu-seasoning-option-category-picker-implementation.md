# eMenu 调味 Option 分类选择实施计划

## 目标

为公共调味 Option 增加单分类归属与分类管理，并将批量新增、单商品编辑中的“添加 Option”统一改为“类 + Option”两列选择器。

## 实施步骤

1. **扩展领域类型与本地数据迁移**
   - 增加 `SeasoningOptionCategory`、系统“未分类”常量及 Option 分类字段。
   - 在服务端数据库加载时执行幂等回填，确保旧 Option 持久化归入“未分类”。
   - 扩展种子数据与审计版本行为。

2. **实现分类与选择快照 API**
   - 增加分类查询、新增、编辑、排序、删除路由。
   - 增加非分页 `option-picker` 快照路由及 10,000 个启用 Option 上限。
   - 扩展 Option POST/PATCH 分类校验、旧客户端兼容和稳定错误码。
   - 在批量预览及单商品保存事务中重新校验 Option 与分类状态。

3. **实现共享“类 + Option”选择器**
   - 新建独立选择器组件，桌面两列、窄屏上下布局。
   - 实现分类激活、全选/取消、半选、跨分类暂存、分类名/Option 搜索。
   - 处理当前动作已关联 Option 的禁用与计数集合语义。
   - 实现焦点、Esc、焦点返回、live region 与原生半选状态。

4. **接入批量新增与单商品编辑**
   - 共享配置工作区改用新的分类选择器。
   - 批量与单商品控制器加载相同选择快照并维护相同选择状态。
   - 保留现有动作、价格、排序、预览与保存流程。

5. **扩展公共调味库**
   - Option 列表展示与筛选分类。
   - Option 新增/编辑增加必填分类。
   - 增加分类管理弹窗：新增、编辑、拖动排序、停用、删除与系统分类锁定。

6. **测试与验收**
   - 补充领域集合、迁移幂等、API CRUD/冲突/上限/失效原因测试。
   - 补充页面结构测试及中英文文案。
   - 执行 TypeScript、领域、结构、API 回归。
   - 在本地浏览器验证两列选择、分类全选/半选、搜索保留和两个业务入口。
