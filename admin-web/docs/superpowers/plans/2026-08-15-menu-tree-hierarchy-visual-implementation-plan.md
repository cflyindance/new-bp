# 菜单结构层级与选中态视觉优化实施计划

日期：2026-08-15
设计规格：`docs/superpowers/specs/2026-08-15-menu-tree-hierarchy-visual-design.md`

## 目标

在不改变菜单数据、JSON 序列化和树操作逻辑的前提下，实现自适应左栏、层级轨道、两行节点信息、强选中态和右侧完整路径。

## 任务 1：菜单树布局与轨道

文件：`src/config/json-menu-tree-ui.ts`

- 把左栏宽度调整为 `w-[34%] min-w-[340px] max-w-[400px]`。
- 移除当前每级 16px 的缩进结构，改为每级 24px。
- 一级到第四级分别形成 0、24、48、72px 缩进。
- 第四级之后停止继续增加缩进。
- 为二级及以下节点添加短横连接线，为嵌套列表保留连续竖向轨道。
- 第四级兼容层使用虚线轨道。

## 任务 2：节点信息和交互状态

文件：`src/config/json-menu-tree-ui.ts`

- 节点最小高度调整为 48px。
- 第一行放名称、校验状态点和操作区。
- 第二行放 Key、实际层级、页面类型/兼容标签和隐藏标签。
- 默认无边框，悬停使用浅灰背景。
- 选中态使用浅青底、青色细边框、左侧 4px 内嵌强调条和深青色加粗名称。
- 选中节点操作按钮常驻；未选中节点在 hover 或 focus-within 时展示。
- 保持拖拽属性、按钮 data 属性和事件绑定不变。

## 任务 3：右侧完整路径

文件：`src/config/json-menu-node-form-ui.ts`

- 使用现有 `ancestors` 和当前节点计算完整名称路径。
- 在详情标题下显示路径，单行省略并通过 `title` 提供全文。
- 保留当前层级、Key 和页面类型信息。
- 路径只在渲染层计算，不写入文档或导出 JSON。

## 任务 4：验证

- 运行 TypeScript/生产构建。
- 运行 `verify-json-menu-document-domain.ts`。
- 运行 `verify-json-menu-reference-compatibility.ts`。
- 在浏览器检查一级、二级、三级以及兼容节点的缩进和轨道。
- 检查选中、悬停、键盘焦点、隐藏、错误/警告标签。
- 检查右侧路径在切换节点后同步更新。
- 检查新增、编辑和全屏菜单预览仍可打开。
