# M 平台内部人员权限 Implementation Plan

**Goal:** 通过角色控制服务商内部员工访问、查看、设置 M 平台自身菜单，不提供员工个人例外。
**Architecture:** 独立 M 平台资源目录、角色授权存储及解析器；目录共用于侧栏与权限编辑。保留商家权限、旧 enterprise 数据及账号存储；M 平台配置不转换商家权限。
**Tech Stack:** TypeScript、Vite、原生 DOM、现有权限中心样式。
**Spec:** docs/项目文档/M平台内部权限产品权威需求文档.md
**Baseline:** main@48c9c24b7fd6f0b8ca8ec8ee0ed2fd184996c0d0。

## Constraints
仅角色授权；默认拒绝；多角色允许并集；页面只读不得写入；独立动作单独允许；仅真实编辑触发离开提示。本次已授权提交并合并 main，未授权推送。

- [x] 建立 M 平台目录、路由归属和独立动作，并以目录渲染递归滑层侧栏。
- [x] 建立持久化角色与员工绑定，校验名称、删除成员占用、最后管理员保护、保存版本冲突及失败；旧授权不自动迁移。
