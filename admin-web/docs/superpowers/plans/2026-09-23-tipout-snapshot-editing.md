# V2.9 快照查看与编辑确认 Implementation Plan

**Goal:** 查看不重算，修改不覆盖，重新确认后才更新正式结果。
**Spec:** 权威 PRD 第 18 章。
**Architecture:** 以结构化快照中的规则、公式输入和员工结果还原编辑器，不存储可执行 HTML。本页跟踪未确认草稿；通过既有未确认更新标记阻止发放。导航与日期切换守卫允许继续编辑或放弃。
**Tech Stack:** 原生 DOM、legacy runtime、TypeScript、本地快照。

- [ ] 快照保存规则和公式输入，回显员工、角色比例和金额；旧快照保留结果，缺失历史公式不冒充原数据。
- [ ] 监听编辑和增删行，启用重新确认；手工工时输入仅修改 DOM，不直接持久化或重建页面。
- [ ] 提交期间阻止编辑；保存成功清除草稿，失败保留；无修改拒绝重复提交。
- [ ] 日期/门店切换、返回、hash 导航、关闭刷新提示；未确认修改阻止发放，外部锁定优先。
- [ ] 浏览器覆盖自动保存、重复进入、编辑/取消离开/重新确认、快照金额与状态同步；运行已有自动分配和发放回归。
- [ ] 更新 PRD 实现边界并提交本地 main。
