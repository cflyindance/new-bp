# 限购数量表格简化实施计划

## 目标

在不改变数量矩阵数据结构和输入处理的前提下，从“限购数量 > 产线配置”表格中移除“状态”和“实际限额”两列。

## 实施步骤

1. 更新订单限购静态验证脚本：断言当前渲染函数不再输出两个表头及对应行单元格，同时保留数量输入绑定。
2. 运行目标验证，确认旧实现按预期失败。
3. 修改 `renderLimitRows`，移除状态文案、实际限额计算与两个单元格，只输出目标和数量输入列。
4. 修改当前 `renderStepFour` 表头，只保留目标与数量列；同步清理不再使用的状态展示变量和样式（仅在确认无其他消费者时）。
5. 保持批量模式的勾选表头和行选择单元格，使普通模式为两列、批量模式为三列。
6. 运行 JavaScript 语法检查、相关静态验证及全部订单限购验证脚本。
7. 使用本地浏览器分别检查普通模式和批量模式的列结构、输入 `0` 与正数后的数据保留，以及控制台错误。
8. 检查差异，仅提交本需求文件；随后合并分支到 `main` 并在主分支复测。

## 不在范围内

- 不修改输入精度或步进校验。
- 不修改 `configured` / `value` 数据结构。
- 不修改批量设置按钮、门店下拉、人数/轮次和产线切换逻辑。
- 不修改发布快照与历史规则兼容逻辑。
