# 整单与每轮配置布局统一 Implementation Plan

**Goal:** 整单、每轮保留直接配置，视觉布局复用已确认的人均场景样式。

**Architecture:** 内联周期容器增加工作台样式作用域，复用批量输入渲染及额度卡片、表头转换。场景弹窗保存与取消机制不变，内联不增加弹窗保存行为。

**Tech Stack:** 原生 JavaScript、CSS、Node 验证脚本。

## 约束

- 不改变额度字段、累计周期、空值和 0 的定义。
- 菜品集按种及按份共享额度独立卡片。
- 整单按种不适用的每轮份数仍不可编辑。
- 不提交或推送，保留无关修改。

## 实施

- [ ] 将 `renderQuantitySceneDialog` 的批量 HTML 装饰提取为共享函数，内联场景使用同一函数。
- [ ] 将现有 DOM 布局转换应用到内联周期容器，复用 CSS 作用域；保留内联移除商品功能。
- [ ] 内联批量展开和取消只修改本地显示状态；原商品数量写入仍使用已有批量处理。
- [ ] 运行 `node --check`、场景工作台、运行时、商品行数量及多字段批量验证脚本，检查限定文件 diff。
