# 菜品集逐商品份数上限实施计划

**Goal:** 菜品集商品直接填写各自每轮最多份数，保留共享额度及现有有效数量。

**Architecture:** 复用 `exceptionDishLimits` 的逐菜品额度和现有执行函数；将已配置默认额度展开到当前商品，例外优先，展开后移除场景默认值。仅菜品集界面移除默认及例外入口，其他对象不受影响。

**Tech Stack:** 原生 JavaScript、HTML、Node 验证脚本。

**Spec:** 用户已确认：商品行独立输入，空值未配置、0 禁止；共享额度同时生效，已有例外优先于默认。
