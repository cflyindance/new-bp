# 菜单下单限制批量目标选择实施计划

## 目标

在「限购数量 > 产线配置」中增加临时批量模式，通过现有表格勾选多个菜品或分类，只对勾选目标批量设置数量、禁止或不限制。

## 任务 1：建立失败验证

新增 `scripts/verify-order-limit-batch-target-selection.mjs`，验证：

1. 编辑器初始化包含关闭的批量模式与空选择集合。
2. 批量模式渲染表头全选与行复选框。
3. 批量动作禁用状态与已选数量绑定。
4. 批量应用只遍历当前上下文中的已选目标。
5. 批量成功、取消、切换人数/轮次/产线及离开步骤 4 都执行清理。
6. 菜品和分类共用同一目标列表逻辑。
7. 既有单行输入和“不限制”操作仍保留。

先运行取得 RED，确认失败原因来自当前“整产线全部覆盖”的实现。

## 任务 2：增加临时批量状态与状态助手

修改 `dist/Configuration center/assets/order-limit-flow.js`：

- 在 `editorState` 中增加 `batchMode` 与 `batchSelectedTargetIds`。
- 增加当前上下文目标、有效已选目标、全选状态和清理选择的助手函数。
- 批量选择保持为界面临时状态，不写入 `editorDraft`。

## 任务 3：改造步骤 4 渲染

- 批量模式开启时，数量表格最左侧显示选择列。
- 表头显示全选复选框；行内显示目标复选框。
- 批量操作条显示已选数量、全选、清空、数量输入及三个批量动作。
- 未选择目标时禁用批量动作。
- 批量按钮在开启后显示“取消批量设置”。
- 按菜品和按分类规则都使用 `targetsForLine` 渲染与选择。

## 任务 4：改造事件与数据更新

- 行复选框与表头全选只更新临时选择状态。
- 全选、清空与 indeterminate 状态同步。
- 应用数量校验非负整数。
- 三个批量动作只更新有效已选目标；未选目标保持不变。
- 成功后保存草稿、退出批量模式并清空。
- 取消、切换人数/轮次/产线、离开步骤 4 时退出并清空，不修改业务数据。

## 任务 5：样式

修改 `dist/Configuration center/assets/order-limit-flow.css`：

- 增加紧凑选择列、复选框标签、批量工具条和选中计数样式。
- 操作条允许换行，保持小屏可用。
- 复用现有颜色、按钮、输入与焦点反馈。

## 任务 7：浏览器验证

通过真实新增规则流程进入步骤 4，验证：

- 批量模式默认不选。
- 可选多个菜品，仅选中项被修改。
- 全选、部分选中和清空状态正确。
- 无选择时应用按钮禁用。
- 成功后自动退出并清空。
- 取消及切换人数、轮次、产线后清空且不改业务数据。
- 分类规则同样支持多选分类。
- 单行编辑与返回列表无回归，控制台无错误。
