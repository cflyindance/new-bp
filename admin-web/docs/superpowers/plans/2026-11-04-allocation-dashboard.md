# 小费分配看板实施计划

基线：main@b5da1188（包含已合入未推送业务提交）。目标：看板承接自动分配，门店汇总独立全屏。

1. 复用现有分配保存接口和逐日队列，任务单位为门店与日期，只处理未分配且可分配日期。
2. 默认看板：日期、进度、规则关联、失败事项、门店列表；任务中所有看板交互禁用，禁止重复启动。
3. 门店汇总使用screen=store上下文，全屏、返回看板；保留页签、筛选、导出、人工调整和发放保护，不自动触发任务。
4. 任务结束展示结果，失败重试只执行失败项；保存结果不被刷新或切换范围覆盖。
5. 实际页面验收运行中、失败、重试、成功、无任务、未关联规则、全屏门店页、日期员工视角和返回；同步三份文档与真实截图。
6. 按提供三张图对照视觉，标准图标及独立生成插图，design-qa记录并完成复核。
