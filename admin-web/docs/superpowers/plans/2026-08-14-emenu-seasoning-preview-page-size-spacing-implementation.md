# eMenu 调味预览每页数量控件间距实施计划

## 目标

将批量关联预览分页左侧的“每页 / 数量 / 个商品”调整为稳定的一行布局，扩大元素间距并固定下拉框宽度。

## 步骤

1. 修改 `seasoning-batch-wizard-ui.ts`
   - 为控件组增加不可换行和防压缩布局。
   - 将两段文字拆为独立 `span`。
   - 使用 12px 间距并把下拉框固定为 80px。
   - 保持分页栏可整体换行。

2. 修改 `verify-emenu-local-seasoning-settings.mjs`
   - 验证控件组具备不可换行、12px 间距和 80px 下拉框。
   - 保留既有分页功能标记验证。

3. 验证
   - 运行调味专项验证。
   - 运行生产构建。
   - 在本地批量关联预览页面检查桌面布局。

## 完成标准

- “每页 5 个商品”横向单行展示。
- 分页数量切换与页码按钮功能不变。
- 本次只提交对应页面和验证文件。
