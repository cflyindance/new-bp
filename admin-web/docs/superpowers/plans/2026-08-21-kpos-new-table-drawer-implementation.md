# KPOS 新增桌子侧滑面板实施计划

1. 新增独立的桌台布局模块，提供名称规范化、字段校验、矩形碰撞和确定性空位扫描。
2. 扩展餐位平面图状态，使新增草稿记录目标区域，并将新增模式渲染为右侧侧滑面板。
3. 在目标区域画布渲染虚线预览桌台；表单输入、区域切换及拖动实时更新预览，取消时清理。
4. 创建时校验名称、人数、尺寸、边界与重叠；重叠要求二次确认，创建后显示未同步状态。
5. 保存区域继续使用 KPOS 整区域快照协议；保存成功后回读并以唯一签名认领临时桌台真实 ID。
6. 为纯布局和校验逻辑补充可执行测试，运行 TypeScript 检查与 Vite 生产构建。

真实 KPOS 写入仅在用户指定测试区域后执行，本计划默认只做本地模拟与只读验证。
