# 品牌、门店与账号菜单权限实施计划

**Goal:** 实现已确认的品牌菜单上限、门店双入口开通、品牌 Admin 与逐角色门店授权，优化相关交互。

**Architecture:** 沿用 enterprise-merchant 主数据和菜单路由树；复用 center-domain 的角色及绑定语义。新增品牌隔离的账号角色状态和共用工作台，在商家运行时叠加授权上限，不迁移或重写既有账号授权。

**Tech Stack:** TypeScript、Vite、现有 Tailwind 与原生 DOM、localStorage 演示存储。

**Spec:** 本聊天用户确认的四层模型；产品权威入口为 `docs/项目文档/M平台-入驻商户管理中心设计方案.md`，同任务补齐研发、个人规范文档。
