## 连带缺陷修复

- 已取消的申请流程默认requests为空，读取不再以空列表为由重复补种并触发写入事件；历史非空记录保留。
- store代登录的范围写入只在值改变时广播，避免同步mount递归、闪烁和回到顶部。
- 显式品牌菜单不经过旧免费/收费分桶推算门店上限，保持原始授权键；仍经过原门店视角过滤，不扩大员工权限。
