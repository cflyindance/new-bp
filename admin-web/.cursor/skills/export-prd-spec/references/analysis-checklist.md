# 分析清单（从代码挖证据）

按优先级扫描范围内文件；每项记下路径与符号，供 SPEC/DIFF 引用。

## 1. 类型与枚举

- [ ] `type` / `interface` / `enum` / 常量对象
- [ ] 字段含义、可选/必填、联合类型分支
- [ ] 默认值、魔法数字、文案 key

## 2. 存储与数据流

- [ ] store / factory / localStorage / session / mock 数据
- [ ] 读写时机（加载、保存、下发、切换视角）
- [ ] 实体关系（一对多、聚合来源）

## 3. UI 与交互（`*-ui.ts`、页面组件）

- [ ] 入口、路由、导航注册
- [ ] 筛选 / 表单 / 表格列 / 按钮
- [ ] 禁用、只读、显隐条件
- [ ] 空态、加载态、错误提示
- [ ] 联动刷新（改 A 重算 B）

## 4. 业务规则（隐式）

- [ ] `if` / `switch` / 早期 return 中的业务判断
- [ ] 校验规则与失败反馈
- [ ] 状态流转与非法操作处理
- [ ] 产线 / 业态 / 集团·品牌·门店视角差异

## 5. 权限与作用域

- [ ] RBAC、permission registry、scope 过滤
- [ ] 可见 vs 可编辑边界

## 6. 接口与契约

- [ ] 真实 API 调用（有则记录请求/响应形状）
- [ ] 仅 mock / 本地：标「原型存储」，SPEC 中写「建议契约」并进 DIFF（推测）
- [ ] **禁止**无证据编造表结构或端点

## 7. 既有文档

- [ ] `docs/项目文档/*` 相关设计
- [ ] `docs/superpowers/specs/*`
- [ ] 模块内既有 PRD（如 `dist/TipOut/docs/`）

## 输出前核对

- [ ] 每个需求编号至少有一处代码或「原型未实现」标注
- [ ] 复杂流程有 Mermaid（主流程或序列图）
- [ ] 开放问题与 DIFF 不重复堆砌（DIFF 偏对照，PRD 偏待决）
