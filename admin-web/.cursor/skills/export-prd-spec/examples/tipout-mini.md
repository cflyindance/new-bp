# TipOut 导出样例（精简）

> **源 PRD（风格参考）**：`dist/TipOut/docs/PRD_产品需求文档.md`  
> **说明**：下列编号使用设计约定的 `TIP-xx`（非源文档的 `P1-01`）。仅演示粒度与三件套写法，非完整导出。

## PRD 片段 — 功能需求清单

| 编号 | 需求类型 | 需求描述 | 关联编号 |
|------|----------|----------|----------|
| TIP-01 | 筛选 | 日期范围选择器（起止日期），必填 | → TIP-03, TIP-04 |
| TIP-02 | 筛选 | 门店下拉单选，选项从规则 store 聚合 | → TIP-03 |
| TIP-03 | 展示 | 按日期范围生成日期标签（M/D） | 依赖 TIP-01, TIP-02 |
| TIP-04 | 展示 | 日期标签状态：已分配 / 待分配 | 依赖 tipout_allocated |
| TIP-05 | 操作 | 「分配小费」：无规则→提示并引导规则页；有规则→标记已分配 | 依赖规则存在 |
| TIP-06 | 空状态 | 无分配结果时提示先执行分配 | 依赖 TIP-04 |

### 验收示例（TIP-05）

- Given 当前门店无任何规则 When 点击「分配小费」 Then 提示并引导至规则配置，不写入已分配状态  
- Given 存在至少一条适用规则 When 点击「分配小费」 Then 日期范围内对应日期标记为已分配

## SPEC 片段 — 状态与逻辑

### 枚举 tipout_allocated（示意）

| 值 | 含义 |
|----|------|
| allocated | 已分配 |
| pending | 待分配 |

### 功能：分配小费（TIP-05）

**输入**：门店、日期范围  
**步骤**：1) 查规则是否存在 2) 无→提示 3) 有→写入分配状态  
**异常**：无规则、日期非法  

证据：以实际导出时扫描的 TipOut 源码路径为准。
