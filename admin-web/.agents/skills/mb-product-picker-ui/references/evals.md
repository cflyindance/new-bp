# 行为评估

## 应触发

1. “商品选择按这个四列设计稿优化”：复用选择器，产线／组／类／商品四列，左关闭右确认，不新增业务。
2. “给另一个后台的优惠规则增加商品范围选择”：沿用同一视觉，使用目标项目商品范围及权限，不能复制admin-web演示树。
3. “只读查看已选商品”：保持层级和数量样式，无法改勾选，关闭不写入。

## 不应触发

- “顾客在eMenu里点菜”：不是后台范围选择器。
- “写商品重复参与规则的优先级”：纯业务规则，不能用样式规范代替产品决策。
- “普通表单增加一个下拉框”：没有层级商品选择。

## 回归

- 选中一条产线的商品后切另一条，再返回，选择与数量不丢失。
- 勾选父层部分子项，显示半选；搜索无结果时原勾选仍存在。
- 编辑选择但取消，宿主数据与打开前相同；确认进入正确草稿／保存路径。
- 含时间设置时同时显示分、秒，1分30秒保存为90秒；旧分钟数据读取不丢失时长。
- 1000px视口无整页横向溢出；小视口选择区可滚动，关闭和确认始终可达。
- 不虚报本地预览、模拟保存为真实终端验收。
