# 设计与交互契约

## 布局与尺度

- 参考稿为 2 倍像素截图，按逻辑尺寸实现，不能把截图像素直接当 CSS px。
- 宽弹框建议逻辑宽约1200px，最大宽为视口减48px，最大高90vh；窄屏减小外边距，不裁掉关闭或确认按钮。
- 外层浅灰、圆角约18px，内边距16px；内容白色、圆角12px、内边距16px。业务区间距24px。
- 左上关闭为48×48px浅灰方形、12px圆角，与20px标题相邻；右上确认高48px、12px圆角，主色#1677FF。文案采用当前项目语言，不强制复制截图的英文Confirm。
- 可选业务设置标题16px，设置行浅灰、约14px圆角。时间分秒为两个各自带外部可访问标签的数字输入，单位“分”“秒”同时显示；不在通用规范中定义时长上限、最小值或业务授权后果。
- 搜索高48px、建议宽360px、不超过容器宽度，圆角胶囊，白底细灰边；placeholder“搜索商品”，必须有可访问名称，不能依赖placeholder作唯一标签。
- 选择容器细灰边、16px圆角；有产线时四列等宽，否则按实际层级三列。列标题“产线（或渠道）／组／类／商品”。层级和名称以项目领域定义为准。
- 列标题及行内边距12–16px，普通行至少48px，选中行12px圆角。列间细分隔，纵向内容各列可滚动；窄屏可在选择区内部横向滚动，整页不溢出。
- 正文14px，说明及数量12px；长名称换行或提供完整可访问文本，不挤压勾选框或数量徽标。
- 用项目语义Token定义白面、灰底、文字、分隔与暗色模式；主交互蓝使用单点Token，不在各业务页面散落色值。

## 状态模型

| 状态 | 行为 |
| --- | --- |
| 浏览某行 | 更新下一列内容；浏览与勾选互相独立。行背景灰、文字蓝表示当前浏览项，不能只靠复选框表达位置。 |
| 勾选父层 | 沿用所属项目已确认的级联选择规则；支持半选，禁止把半选画成全选。 |
| 切换产线 | 保留各产线独立选择；显示对应商品树。实际可用产线由业务输入，截图中的Kiosk/eMenu/SDI不是全局白名单。 |
| 数量 | 明确数的是商品、去重商品还是商品与产线组合；徽标与总数保持一致，继承当前业务。分组／分类节点数量不得当作已选商品数。 |
| 搜索 | 在可见的明确范围中搜索（当前项目为当前产线），匹配商品与可解释的上层名称；说明搜索范围。清空恢复原分层浏览，搜索及切换不重置已选值。 |
| 空及无结果 | 区分无商品树、未选父层与搜索无结果，给出准确可见提示。 |
| 只读 | 可浏览但无法修改勾选；关闭不写入。不得为视觉演示解除真实权限。 |
| 确认 | 调用宿主原确认回调；若宿主采用页头统一保存，弹框确认只写页面草稿，不冒充持久化或下发完成。 |
| 取消 | 关闭、Esc及遮罩按宿主已确认契约处理；编辑使用临时选择，取消不改打开前数据。 |

## 键盘与验证

- 原生button/input语义，可访问名称与字段关联；所有可交互控件有可见focus。
- 弹框开启后聚焦相关字段或关闭按钮；Tab保持在弹框内，关闭恢复到触发控件。勾选及搜索重绘后保留有意义的焦点。
- 验证长名称、无结果、无可访问产线、只读、半选、跨产线选择和窄屏。保留草稿时不得强制刷新丢弃用户输入。
- 最低验收证据：实际选择弹框截图、搜索状态截图、一个跨产线选择保留操作、确认／取消结果与明确未验证项。

## 不可推广的业务

不从设计稿推广11分钟、默认勾选两个商品、具体菜单树、订单／商品规则优先级、是否必须选商品、可否跨规则重复选择、授权或下发规则。发现不确定性时保留现有行为并登记待确认项。
