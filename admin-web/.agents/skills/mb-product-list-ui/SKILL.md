# 后台商品列表规范

## Purpose / 目标

复现用户确认的商品列表视觉与可浏览行为，复用项目组件；只读查看与可编辑配置共享外观，但操作能力由实际任务决定。

## 输入与边界

先核对目标页面、真实数据字段、只读或编辑模式、已选范围、已有搜索和分页契约。缺失信息只在影响结果时询问；不能从参考图推断配置权限或业务字段。

- 用户最新明确设计优先。与 `mb-admin-ui-guidelines` 配合；层级勾选交给 `mb-product-picker-ui`。
- 只读查看：仅显示当前已选商品；不加勾选、状态编辑、行操作箭头、保存或批量修改。右上“确定”仅关闭。
- 管理／配置：只保留业务已有或用户授权的选择、状态、操作；不能仅因参考稿有就新增。
- 不自动批量迁移其他页面，不公开或分发参考图，不自动提交、合并、推送或同步其他Agent。

## Workflow / 实现流程

1. 读取 [布局契约](references/design-contract.md)，映射项目Token和现有表格；没有字段不伪造门店、编号、图片、场景和状态。
2. 弹框浅灰外层，白色列表内容；页头左侧48px关闭、标题与对象统计，右侧48px主操作。只保留一处页面级操作，不在底部重复。
3. 工具栏为胶囊搜索、浅灰胶囊筛选和无底色图标加文字重置。筛选必须工作，不能放装饰控件；只读场景只能筛选已选范围。
4. 表头48px、行64px；商品格为缩略图和名称。无图片用中性占位图标，不捏造商品图片；长名称可换行或提供完整信息。列按业务裁剪，横向滚动限于表格内。
5. 底部总数左，页码与每页数量右。搜索／筛选／每页数量变化返回第一页，重置只清搜索筛选。计数和列表用同一数据范围，跨产线计数沿用业务口径。
6. 验证正常、空选、无匹配、重置、组合筛选、分页边界、只读不写入、关闭与键盘、窄屏；报告实际截图和未验证项。

## 复用入口

当前admin-web：`src/config/product-list-ui.ts` 与 `product-list.css`，通过 `mountProductList(container, rows)` 挂载只读列表；调用者提供已选范围、弹框与关闭行为。接口仅接收实际名称、产线、组、类，其他项目不得照搬此项目存储键和演示商品。需要可编辑配置时复用外观和状态原则，不冒用只读组件实现写入。

## Evaluation / Definition of Done

结构及控件对齐参考；数据范围不扩大，全部搜索筛选分页可操作，查看不改配置；无选择器误用、无重复主操作、无伪造图片或业务列。[验证用例](references/evals.md)用于后续修改回归；[来源](references/provenance.md)说明维护源和安装范围。交付实际页面、预览或文件、检查结果与缺口。

## Output / Deliverable

交付实际代码与样式、可访问的预览或页面截图、验证结果及未验证项；说明只读或编辑模式以及数据范围。规范使用[受限参考图](assets/reference.png)，不得公开分发；本机安装时给出实际路径和同步范围。

当前项目证据见[本机验证记录](references/validation.md)，不代表其他项目或Agent已通过。
