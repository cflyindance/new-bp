# 布局与交互契约

- 参考图：`../assets/reference.png`。只确认布局、层级和样式；图中门店、人数、轮次、共享额度、状态不是通用业务规则。
- 弹框宽度按现有桌面容器适配，推荐最大1200px、视口两侧24px；最大90vh，浅灰底16px内边距、18px圆角。移动窄屏缩小外边距，内容内部滚动。
- 页头48px关闭方块、20px标题、12px统计、48px蓝色主操作；关闭有aria-label和键盘焦点。只读确定=关闭，不触发保存。
- 白色列表区16px内边距、14px圆角。工具栏搜索48px高、宽280–360px；筛选48px浅灰胶囊。只读已选商品按名称搜索；真实编码存在时才能扩展名称或编码搜索。
- 重置是无边框无底色的图标＋文字；清搜索筛选、页码回1，不更改每页数量和已选商品。
- 表头48px、数据行64px；商品缩略图40–44px圆角，缺图灰色图标占位。只用横向细分隔线，不加厚重全网格。表头随内部列表滚动固定。
- 同名商品跨产线按业务口径分行，显示真实所属组类；不能仅按名称去重影响配置范围。已选叶子数量与入口计数一致。
- 底部分页32px控件，20/50/100条作为当前原型默认；已有服务端分页必须沿用其契约，不擅自下载全量或改成前端分页。
- 筛选后总数、页码、行集合保持一致；组合筛选取交集；无匹配明确提示。重置恢复初始范围而非全部未选商品。
- 长表内部滚动，分页常驻；窄屏表格内横向滚动，不让整页溢出。焦点圈可见，分页新页激活后焦点转到当前页码；搜索输入更新列表不能丢焦点。
