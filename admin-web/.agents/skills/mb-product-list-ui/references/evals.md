# 验证用例

正向触发：按截图优化后台商品表格；已选商品只读列表加搜索筛选；商品配置列表采用相同样式。
反向边界：产线→组→类勾选选择器使用picker Skill；顾客点餐页、普通员工表格不应用本规范。

回归：
1. 仅选3项时恰好3行，未选商品不出现；跨产线不错误合并。
2. 搜索命中／零结果、产线＋组＋类交集、重置后回全部已选范围；无编辑写入。
3. 20条边界、超20条下一页、首尾禁用、切换每页数量回1；过滤缩小页数不出现空白越界。
4. 关闭、遮罩和Esc回到入口；只读确定只关闭。空规则和未知商品按所属业务处理，不伪造数据。
5. 1000px和窄屏内部滚动、分页可达；多次打开不重复触发监听；编辑仍使用原选择器。

这些是维护用例，不代表已执行跨项目或独立Agent评估。实际本次结果记录于项目配套验证文档。
